# 米雇用統計を見込んだロングが一晩で剥がれ$84,000台へ ― 上げも下げも先物が運び、現物の買い手は動かず

**2026年10月3日**

金曜日は、昼から夜にかけて上げた分を、未明までに全部戻した日です。

* **価格**：米雇用統計の直後に$87,249まで上げ、未明に$83,850まで下げて、朝7時5分の時点で約$84,471（24時間前より−0.3%）
* **きっかけ**：米9月の雇用統計が予想を大きく下回り、10月のFOMC（＝米国の金利を決める会合）で利上げするという見方がさらに後退した。ただし上げの大半は米雇用統計の前に起きている
* **先物**：上げも下げも運んだ。昼の上げでは売り持ち（ショート）の多数が清算（＝証拠金不足で強制的に閉じられた取引）され、買い持ち（ロング）が積まれた。未明の下げでは、そのロングが清算を伴って手仕舞われた
* **需給の土台**：米国の買い手は往復に加わらず、長期保有者の利益確定の売りは続いているが強まっていない
* **オプションの見方**：米雇用統計をまたぐ満期だけに乗っていた、ほかの満期に対する上乗せは剥がれた。来週の満期はコールが高く、下げへの備えは10月16日から先にある。いちばん厚いのは10月末のFOMCをまたぐ満期

証券市場は金曜10月2日、S&P500が+0.73%の7,722、金が−0.72%の$4,172、原油が−1.73%の$91.26でした。米10年債利回りは米雇用統計の直後にいったん下げたあと上げに転じ、5.28%で終えています。

* 建玉は昼の上げで約3.5%増え、23時台から未明の下げで約4.4%減った。
* 資金調達率はプラスが7回連続（約2日）。

金曜日にビットコインが$87,249まで上げて一晩で戻したのは、米雇用統計を見込んで昼に積まれた先物のロングが、米雇用統計が出たあとに手仕舞われたからです。

1. きっかけ：外部環境の出来事です。金曜21時30分の米9月の雇用統計は、雇用者数の増加が2.9万人と事前の予想（8万人台）を大きく下回り、失業率は4.2%へ上がりました。10月27〜28日のFOMCで利上げする織り込みは、1週間前の約6割から約2割へ下がっています。ただし、ビットコインの上げの大半は米雇用統計が出る前の昼に起きていて、株が米雇用統計のあとも上げて終えたのに、ビットコインは未明に下げました。未明の下げは、株と共通のきっかけではありません。ビットコインが下げ始めた23時台は、米10年債利回りが米雇用統計の直後の下げから上げへ転じた時間と重なります。
2. 伝わり方：先物です。昼の上げでは、ショートが清算されると同時に建玉（＝先物の未決済残高。証拠金で張っている人の量）が増え、新しいロングが積まれました。米雇用統計のあとの23時台から未明にかけては、価格が下げながら建玉が昼に増えた分とほぼ同じだけ減りました。米雇用統計を見込んで積まれたロングが、米雇用統計のあとに手仕舞われたということです。資金調達率（＝ロングが払う金利。プラス＝ロングがショートより多い）はプラスのままですが、短期金利（＝ドルを米国の短期国債で持つだけで受け取れる金利）を引いた上乗せは、直近1か月の平均より小さくなりました。現物は上げにも下げにも加わっていません。アメリカ側だけが高く買われた形は出ておらず（図①-1）、長期保有者も10月1日時点で減り方を前の週より小さくしています（図②-1）。

前日は「利上げの見方が後退したことをきっかけに、ショートの清算と新しいロングを通って上げた」と説明しました。金曜も昼は同じ道で上げましたが、米雇用統計で利上げの見方がさらに後退したのに上げは残らず、積まれたロングの手仕舞いで戻しました。きっかけと通り道は前日と同じで、違いは、積まれたロングが一晩で剥がれたことです。

イランをめぐっては、ホルムズ海峡の再開案に対する米国の回答が9月30日にカタールを介してイランへ渡り、協議が続いています。原油は金曜に下げました。どちらも、金曜のビットコインの値動きに効いた形跡はありません。

## まとめ：金曜日の動きは何だったか

金曜日は、米雇用統計を見込んで昼に積まれた先物のロングが、米雇用統計のあとに手仕舞われて、$87,249まで上げた分を$84,000台へ戻した日でした。動いたのは先物の持ち高までで、アメリカの買い手は上げにも下げにも加わらず、長期保有者の利益確定の売りも減り方が小さいままです。先物のロングは残っていますが、米雇用統計の前の傾きは消えました。オプションの参加者は米雇用統計を通過してこの先を怖がっておらず、下げへの備えは10月末のFOMCをまたぐ満期に置いたままです。
