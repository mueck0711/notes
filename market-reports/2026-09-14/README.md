**2026年9月14日**

日曜日も、ほとんど動かなかった日です。24時間の値幅は$76,457〜$77,425で、上下1.3%。前の週に5%の往復があり、そのとき証拠金で買い持ち（ロング）にしていた人の一部が清算（＝証拠金不足で強制的に閉じられた取引）されましたが、週末2日目はロングの量が減るどころか、わずかに増えました。証券市場は閉まったままで、ビットコイン自身の需給は前日と同じ姿です。前日から変わったことは一つで、**9月25日満期のプットが再びコールより高くなり、価格が下がったときの備えが、米国と日本の会合の結果が出たあとの満期すべてに並びました**。今週は法案の手続き投票・米国の利上げ判断・日銀の会合が3日続きます。

（数値は9月14日7時5分（日本時間）までのデータに基づきます。価格・先物・オプションはその時点の値、市場心理は9月13日の確定値、オンチェーン（＝ブロックチェーン上の記録）は9月12日時点、ETF資金フローは9月11日分までです。証券市場の終値は9月11日時点で、週末のため更新がありません。オンチェーンの長期保有者の数値には、ETFや取引所が預かっている分も含まれます。オプションはDeribit（BTCオプションの大半を占める取引所）の全銘柄です。）

## 2. なぜ動いたか：ビットコイン自身の需給か、外部環境か

**図2-1 ビットコインと株・金・原油の相対推移（起点＝100）**

![](macro_relative.png)

*図の見方: 同じ起点から何%動いたかで重ねたもの。線が同じ向きなら「一緒に動いた」、ビットコインだけ別の向きなら「自身の理由で動いた」と読みます。*

日曜日に価格が動かなかった理由は2つです。

1. 証券市場が2日続けて閉まっていて、原油と金利からの影響が止まっていた。この1週間の下げは原油高と金利上昇と並んで起きていたので、それが止まればビットコインも止まる。
2. 前の週の清算で減ったロングを、週明けを前にわずかに積み直した人がいた。建玉は土曜から増え、資金調達率はプラスのまま上乗せが広がった。

前日は「減ったロングはそのまま残っていて、手仕舞いは一巡した」と説明し、「もし静かに手仕舞いが続いているのなら、建玉が減り続け、資金調達率がマイナスに沈む」と書きました。日曜日は建玉が増え、資金調達率はプラスのまま広がったので、前日の説明は今日の数値と合っています。市場の多数は、前の週の往復を「流れが変わった」ではなく「一時的な押し」と見たままで、会合の週を前に少しだけ買い持ちを戻しています。

|---|---:|
| ビットコイン | −4.1% |
| 金 | −1.8% |
| 米国株（S&P500） | −1.2% |
| 原油 | +9.6% |

* 証券市場が閉まっている24時間で、ビットコインも1.3%しか動かなかった。
* 建玉（＝先物の未決済残高。証拠金で張っている人の量）は104,582BTC。前日の103,218BTCから+1.3%で、1週間では−2.8%。前日の−4.2%から縮んだ。
* 資金調達率（＝ロングが払う金利。プラス＝ロングがショートより多い）はプラスのまま。1日をならした年率は+6.07%で、短期金利（13週Tビル 3.91%）を引いた上乗せは+2.16pt。前日の+1.78ptより広がった。

原油は金曜に−2.4%で$100ちょうどまで下げましたが、$100の水準は変わらず、リスク資産全体の重しになりうる状況は続いています。ホルムズ海峡の航行をめぐるイランと湾岸6か国の外相会合が、9月14日にオマーンのサラーラで開かれます。2月の開戦以来、双方の高官が一堂に会するのは初めてです。

### ④ オプション：9月25日のプットは再び高くなり、備えは会合のあとの満期すべてに並んだ

オプションには2種類あります。コール（＝決めた価格で買う権利）とプット（＝決めた価格で売る権利）で、価格が上がればコールの価値が上がり、価格が下がればプットの価値が上がります。プットは「価格が下がったときの保険」として買われます。

**図④-1 満期ごとのIV（年率%）**

![](options_iv_term.png)

*図の見方: IV（＝オプション価格から逆算した、この先の値動きの幅の予想）を満期（＝権利の期限）ごとに並べたもの。点線は実現ボラティリティ（＝直近30日に実際に起きた値動きの幅）。IVが点線より下なら、市場はこの先の値動きを過去の値動きより小さいと見ています。*

市場はこの先の値動きを、過去の値動きより小さいと見ています。守りを固めている状態ではなく、怖がってもいません。会合の結果が出た直後の満期がいちばん高く値付けされていますが、それでも過去1か月の値動きの幅には届きません。

* IVは全体で37.0。実現ボラティリティ47.6より10.6pt低い。過去1年で下から24%の位置で、恐怖の水準ではない。
* 満期ごとに見ると、手前が低く先が高い形。FOMC（＝米国の金利を決める会合）の結果が出た直後の9月17日・18日の満期が39台でいちばん高いものの、9月25日との差は3pt。どの満期も実現ボラティリティより低い。

## まとめ：日曜日の動きは何だったか

日曜日は、証券市場が止まったまま、ビットコインを張っている人たちが週明けに向けて少しだけ動いた日でした。ロングはわずかに積み直され、清算は大口1件、長期保有者は前日と同じ姿。ビットコイン自身の需給は変わっていません。前日の「手仕舞いは一巡した」という説明は、建玉が増えたことで裏づけられました。変わったのは一つ、**9月25日のプットが再びコールより高くなり、備えが会合の結果が出たあとの満期すべてに並んだ**こと。参加者は「投票とFOMCの結果までは荒れない、そのあとは分からない」と値付けし、コールの持ち高はそのまま残しています。アメリカの買い手は「手を止めている」が続き、「逃げた」とは言えません。需給が変わっていない日は、何もしなくてよい日です。今週動くのは外部環境のほうで、それを移動平均の並び・アメリカの買い・ETF・市場心理の同じ物差しで見ます。
