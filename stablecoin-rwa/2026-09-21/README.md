## 今週のニュース

### 🏛️ SEC、トークン化米国株のAMM取引を5年間免除

SEC は9月17日、トークン化された NMS 株式（米国上場株）のオンチェーン取引を認める「革新免除（Innovation Exemption）」を出しました。対象は許可制の取引環境を運営する「トークン化証券取引所（TSV）」と、AMM の流動性プールに資金を出す流動性提供者で、それぞれ1934年証券取引所法の「取引所」「ディーラー」の定義から除外されます。これまで AMM 型の取引の場や流動性提供者がこれらの定義に当たるかは曖昧で、トークン化株を米国内で取引する法的な足場がありませんでした。条件は細かく、銘柄数と出来高に上限を設けること、トークンが原株と同一の権利を保有者に与えること、第三者が発行するトークン化株を上場する前に原株の発行体へ通知すること、スマートコントラクトを公開チェーン上に監査可能な形で置くこと、主市場の売買停止に連動して取引を止めること、運営と取引実態を公開することです。免除は公表から5年で失効する暫定措置で、Atkins 委員長は「資本市場をデジタル時代へ運ぶ」一方、恒久的なルール作りは今後の検討に委ねると述べています。同時に修正点と次の段階について意見募集が始まりました。

[出典: SEC](https://www.sec.gov/newsroom/press-releases/2026-90-sec-issues-innovation-exemption-facilitate-trading-tokenized-nms-stock-request-comment)

### 🏛️ 米上院、CLARITY法を49対50で否決 市場構造法は次期議会へ

米上院は9月15日、暗号資産の市場構造を定める Digital Asset Market Clarity Act（CLARITY 法）の審議入りを問うクローチャー動議を49対50で否決しました。通過には60票が必要で、共和党は53議席のため民主党側から7票以上の賛成が要りましたが、出席した民主党議員は全員反対し、共和党からも Susan Collins、Josh Hawley、Jerry Moran の3氏が反対に回りました。法案は SEC と CFTC の役割を法律で切り分け、CFTC に暗号資産の現物市場を監督する新しい権限を与えるものでした。争点の一つがステーブルコインで、発行体が顧客に利回りを払える条項に対し、銀行側は同じ規制を負わずに預金を奪い合う競争になると反発していました。今期の議会で再び取り上げられる見込みは薄く、包括的な市場構造法は次期議会以降に持ち越されます。焦点は SEC と CFTC の規則作りへ移り、SEC は資金調達を簡素化する Reg Crypto を提案済みですが、Atkins 委員長は立法の裏付けなしには規則は持続しないと述べています。業界の政治団体 Fairshake は11月3日の選挙に向けて反対票を投じた議員への対応を決める構えです。Castle Island の週次番組（第740回）はこの否決を「最後のハードルで転んだ」として取り上げ、なぜ転んだかを論じています。

[出典: Castle Island](https://castleisland.vc/weekly-roundup-09-18-26-clarity-fails-to-advance-caroline-ellisons-new-job-ai-leaking-mnpi-polands-oil-snafu-ep-740/) ・ [参考: coindesk.com](https://www.coindesk.com/policy/2026/09/15/crypto-clarity-act-flames-out-in-failed-u-s-senate-vote)

### 🏗️ Ondo、DTCCのFund/SERVに初のトークン化会員として加入

Ondo Finance は9月16日、子会社 Oasis Pro Markets が DTCC の Fund/SERV に加入し、同網で初の「トークン化会員」になったと発表しました。Fund/SERV は米国の投資信託の売買・分配を処理するネットワークで、業界の取引の85%超が通る事実上の基幹インフラです。これまでトークン化ファンドはブロックチェーン上では移転できても、運用会社・ウェルスプラットフォーム・サービス提供者が使う既存の事務処理網とは切り離されており、販売と事務が別建てでした。今回の加入により、Ondo のトークン化ファンドは口座データ、約定確認、照合、分配、規制報告を Fund/SERV の標準接続1本で従来の参加者とやり取りでき、伝統的なファンドの販売経路にそのまま載せられるようになります。DTCC の Talia Klein 氏は伝統インフラとデジタル資産の相互運用が規模拡大の鍵だと述べ、Ondo の Ian De Bode 氏は「トークン化ファンドが主流に広がるための基盤の一つが整った」としています。どのファンドから配信を始めるかや今後の日程は発表に含まれておらず、実際の流通量が次の注目点になります。

[出典: Ondo Finance](https://ondo.finance/blog/ondo-joins-dtcc-fund-serv)

### 🔗 Circle、L1「Arc」メインネット稼働 ガス代はUSDC建て

Circle は9月16日、レイヤー1ブロックチェーン Arc のメインネットを稼働させました。Circle はこれを「インターネットの経済 OS」と呼び、金融市場、リアルタイムの資金移動、AI エージェントの経済活動を想定した設計だとしています。特徴は、手数料を USDC などのステーブルコインで払い専用のガストークンを要らなくすること、1秒未満の決定的な確定、21以上の現地通貨ステーブルコインを24時間交換できる StableFX、開発中のオプトイン型の秘匿取引、耐量子署名への対応です。テストネットは1年弱で1,200超のプロジェクトと7億件超の取引を積み、ジェネシスで100億 ARC が発行されました。創設バリデータは BlackRock、DTCC、Galaxy、ICE、Mastercard、MoneyGram、SBI グループ、Standard Chartered、住友商事、Visa、Global Payments で、初日から BNY・HSBC などの銀行、Coinbase・Kraken・Binance などの取引所、Aave・Uniswap・Morpho などの DeFi、MetaMask・Ledger などのウォレットを含む100超のアプリが稼働します。これまで USDC は他社のチェーン上で流通してきましたが、発行体が自前の決済基盤を持つ形になり、流通残高740億ドルの置き場が一段広がります。今後は Privacy・Payment・Agent の各セクターへの展開と、2027年のプルーフ・オブ・ステークへの移行が予定されています。

[出典: Circle](https://investor.circle.com/news/news-details/2026/Circle-Launches-Arc-Mainnet-an-Economic-Operating-System-for-the-Internet/default.aspx)

### 🪙 GHO、Horizon金利上げとGSM手数料改定でペッグ防衛

Aave の GHO Stewards（TokenLogic）は9月15日、9月分の GHO パラメータ更新を公表しました。内容は3つで、RWA 担保市場 Horizon の GHO 基準借入金利を3.00%から3.25%へ引き上げること、GHO Stability Module（GSM）の償還手数料を USDC 側（Ethereum・Monad・Arbitrum）で10bps から15bps へ上げ、Ethereum の USDT 側で15bps から10bps へ下げること、Monad の USDC GSM で GhoReserve の上限を2,500万から4,900万へ、USDC のエクスポージャー上限を4,000万から5,000万へ広げることです。ミント手数料はすべてゼロのままです。背景には GHO のペッグの弱さがあります。GHO/USD は直近30日でパリティを6.7〜13.6bps 下回って推移し、足元は USDC 比で約10.5bps 安です。同じ期間に Horizon の GHO 債務は2,320万から3,900万へ68%増えており、借り手が RWA 担保でレバレッジを積む過程で GHO が売られていることと相関しています。金利を上げても Horizon は Prime（3.84%）や Core（4.25%）より安い最安の借入先にとどまります。発行体が金利と償還手数料の両方を動かして供給と裏付けの均衡を取り直す典型例で、RWA 担保の伸びがステーブルコインのペッグ管理に直結していることを示しています。

[出典: Aave Governance](https://governance.aave.com/t/gho-stewards-september-2026-gho-parameter-update/25644)

### 🪙 Aave V4のArc展開へUSDC審査 Circleへの権限集中を指摘

Aave のガバナンスフォーラムに9月15〜18日、Arc 上の USDC に関するリスク評価と技術評価を一箇所に集めるスレッドが立ちました。Aave V4 を Circle の新チェーン Arc（チェーン ID 5042）へ展開する ARFC に伴う上場前評価で、上場後の監視報告や再評価もここに積まれます。Arc は9月16日にメインネットが稼働し、Aave は初日から動く DeFi プロトコルの一つとして名を連ねています。Aave Labs の技術評価は「中」で、特権的な権限がコールドストレージの EOA に置かれオンチェーンの遅延なしに行使できること、その権限をすべて Circle が保有しタイムロックが無いこと、USDC が Arc のガス通貨を兼ねる独自構造であること、Arc 固有の NativeFiatToken V2.2 の実装に公開された監査が無いことを挙げています。LlamaRisk は CCTP の証明の閾値が2/2 で鍵2本とも Circle 管理である点を問題視し、Circle の証明者鍵が侵害されれば実際の焼却を伴わないミントが承認されうるとして、証明者を3者以上へ増やすよう推奨しました。9月17日時点で Arc 上の USDC 供給は6億4,775万で、LTV や供給・借入上限はまだ示されていません。発行体が自前チェーンを持つことで、USDC の裏付けの信頼が Circle 一社の鍵管理に一段と集中する構図が、貸し手側の審査で明文化された形です。
