### 💳 Visa Direct、ステーブルコインでの事前入金が本番稼働へ

Visa は、Visa Direct のステーブルコイン機能を試験段階から本番運用へ移すと発表し、これをステーブルコイン戦略の次の段階と位置づけました。最初に本番へ載せたのは Inyo Global です。Visa Direct の「事前入金」、つまり送金に先立って Visa 側へ資金を積んでおく工程をステーブルコインで行えるようになり、Visa Direct で国際送金を扱う企業がステーブルコインで資金を動かせます。これまで Visa のステーブルコインの取り組みは試験の発表が中心で、実際の資金の流れに組み込まれた例は限られていました。国際送金の事前入金は、時差や銀行の営業時間のせいで資金が寝やすい工程です。ここをステーブルコインに置き換えられるかどうかは、カード網がステーブルコインを決済の裏側の基盤として使うかどうかを測る試金石になります。今後は、Inyo Global に続いて本番へ移る事業者が出てくるかが注目点です。

[出典: Visa](https://investor.visa.com/news/news-details/2026/Visa-Direct-Launches-Stablecoin-Powered-Money-Movement-as-Pilots-Move-to-Production/default.aspx)

### 💳 Stripe、ステーブルコインカードの対応国を拡大

Stripe は、フィンテック事業者が商品を立ち上げ、海外へ広げやすくするための3つの更新を発表しました。1つ目は Stripe Global Payouts による支払い管理の簡素化、2つ目はステーブルコインカードの対応国の拡大、3つ目は国をまたぐ金融商品を作るための統一 API です。ステーブルコインカードは、ステーブルコインの残高をそのまま既存のカード網での支払いに使えるようにするもので、ステーブルコインを持つ人が日常の決済に使うときの入り口になります。今回の発表は、その発行基盤を提供できる国を広げるものです。決済事業者の Stripe がフィンテック向けの標準部品として提供する国を増やすことで、各フィンテックが自前で発行体やカード網と交渉しなくてもステーブルコインカードを出せる範囲が広がります。発表には具体的な対応国名や数は示されていません。

[出典: Stripe](https://stripe.com/blog/new-ways-for-fintechs-to-move-money-and-expand-globally)

### 🏛️ ECB、CBDC の保有上限が行動に与える影響を実験で検証

ECB が、個人向けの中央銀行デジタル通貨（CBDC）の保有上限が利用者の行動にどう影響するかを調べたワーキングペーパーを公表しました。保有上限は、提案されている個人向け CBDC の中心的な設計要素です。一人あたりの残高を機械的に抑える効果はありますが、それとは別に、利用者の行動にどちらの方向へ働くかは事前には分かりません。研究では、ユーロ圏4か国の参加者を対象に報酬を伴うオンライン実験を行い、上限の有無を研究者の側で変えて比べています。保有上限は、銀行預金が CBDC へ一気に流れ出すのを防ぐための仕組みとして、デジタルユーロの議論で繰り返し取り上げられてきました。民間のステーブルコインと公的なデジタル通貨の棲み分けにも関わる論点で、実験の結果は上限の水準や是非を詰める材料になります。

[出典: ECB 刊行物](https://www.ecb.europa.eu//pub/pdf/scpwps/ecb.wp3300~0277bae3af.en.pdf)

### 🔬 a16z crypto、再利用できる本人確認の設計を提案

a16z crypto が「KYC を考え直す」と題した論考を公開しました。主張は、銀行は本人確認（KYC）を避けたいのではなく、同じ顧客に何度も繰り返す重複した KYC を避けたいのだ、というものです。そのうえで、一度確認した結果を使い回せる資格情報、中身を明かさずに条件を満たすことだけを示すゼロ知識証明、オンチェーンのコンプライアンスの道具を組み合わせて、重複をなくす道筋を描いています。ステーブルコインやトークン化資産を金融機関が扱うとき、相手方の確認は避けて通れません。取引のたびに確認をやり直す負担は、オンチェーンの決済が速くても、実務が遅くなる原因になります。再利用できる本人確認が実装されるかどうかは、機関がステーブルコインやトークン化資産を使うときの費用に直接効く論点です。

[出典: a16z crypto](https://a16zcrypto.com/posts/article/rethinking-kyc)
