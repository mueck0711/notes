# 【2026/09/14】今週のステーブルコイン & RWA

## 今週のニュース

### 🏗️ Tether、Fasanara と4億ドルの私募信用ファンド

Tether とプライベートクレジット運用の Fasanara Capital が2026年9月9日、常設型の私募信用ファンド「StableFund」を立ち上げました。両者の共同出資4億ドルを元本に据え、外部の機関投資家から最大30億ドルを集める構想です。運用は Fasanara が担い、同社の金融技術企業の網を通じて60か国を超える市場で、中小企業向けの短期・資産担保型の融資に配分します。Tether は共同出資者であると同時に案件の組成元・助言役として、USD₮ 建ての資金供給、法定通貨との出入り口、資金移動の基盤を受け持ちます。背景にあるのは、従来の銀行融資では埋まらない5.7兆ドル規模とされる中小企業の資金需要です。Tether はこれまで自己資金による直接投資が目立ちましたが、今回は外部の機関投資家を募る運用商品の形を取りました。ステーブルコインが決済手段にとどまらず、実体経済への与信を運ぶ配管として使われる事例であり、今後は30億ドルの外部調達がどこまで積み上がるかが試金石になります。

[出典: Tether](https://tether.io/news/tether-and-fasanara-capital-launch-400-million-private-credit-fund-to-expand-stablecoin-enabled-real-economy-lending/)

### 💳 Circle、シンガポールの越境決済 Tazapay を買収

Circle が2026年9月8日、シンガポールの越境決済基盤 Tazapay を買収する合意に達したと発表しました。取得額は非開示で、シンガポール金融管理局をはじめとする当局の承認を条件に、2027年中の完了を見込みます。Tazapay は2026年7月31日時点で年換算250億ドルの決済量を扱い、そのうち約6割が既にステーブルコインを含む取引です。銀行・金融技術企業60社超との接続と、100を超える市場に届く現地の支払い網を持ち、アジア太平洋と新興国に強みがあります。ステーブルコイン関連の業務は Tazapay Canada Corp が担い、カナダの金融取引報告分析センターに送金業者として登録済みで、業務は決済の仲介と法定通貨との交換に限られています。Circle は自社の清算基盤に Tazapay の銀行関係と現地の着金経路を組み合わせ、24時間ほぼ即時の越境送金を実現して USDC を既定の決済経路に据えると説明しています。焦点は当局審査の通過と、買収後に現地の着金網がどこまで USDC の受け皿になるかです。

[出典: Circle](https://investor.circle.com/news/news-details/2026/Circle-Expands-Global-Payments-Infrastructure-with-Agreement-to-Acquire-Singapore-Based-Cross-Border-Payments-Platform-Tazapay/default.aspx)

### 💳 Visa、オンチェーン融資をカードの運転資金へ

Visa が、VisaNet の清算データとオンチェーンの融資基盤を組み合わせ、ステーブルコイン連動のカード事業者や金融技術企業が運転資金を調達できる仕組みを発表しました。名前が挙がっている提携先は Credit Coop の1社です。利用者の同意を得たうえで Visa の清算データとオンチェーンの取引履歴を突き合わせ、与信の実績を評価して立替資金の貸付と返済を自動で回します。Credit Coop はこの仕組みを2023年から動かしており、累計25億ドルの清算資金を融通して貸倒れはゼロ、借入3,000件超・返済9,000件超を自動処理した実績があります。Visa の網には既に160を超えるステーブルコイン連動のカード事業があり、決済額は前年比で約2倍、年換算200億ドルの規模です。カード事業者は加盟店への支払いと資金の回収に時差があるため運転資金を必要としますが、その調達先としてオンチェーンの貸出市場がカード網の側から正面に据えられた形になります。拡大の時期や他の提携先は明らかにされていません。

[出典: Visa](https://investor.visa.com/news/news-details/2026/Visa-Brings-Onchain-Lending-into-Everyday-Payments/default.aspx)

### 💳 Wirex、法人カードの清算基盤に Tempo を採用

決済特化チェーンの Tempo 上で、Wirex の法人向けステーブルコインカード事業が稼働しました。Wirex は Visa と Mastercard の主要会員としてカードを発行する事業者で、今回の対応により、提携先は自社のカード事業の清算層として Tempo を選べるようになります。Tempo 側が利点として挙げるのは、1秒未満で確定すること、Tempo Zones による取引内容の秘匿、そして手数料をステーブルコイン建てで払えること——別建てのガス用通貨を用意しなくてよい点です。Wirex は今回の対応に先立ち、開始から131日で年換算10億ドルのオンチェーン取引量に達し、その110日後に倍増したと公表しています。Tempo は DoorDash、Deel、Klarna、Felix、ARQ といった企業との取り組みを挙げていますが、これらが Wirex 経由で Tempo を使うかは明らかにしていません。カード決済の清算をどのチェーンで行うかという選択肢が増え、カード発行側の事業者がそれを選べる形になった点が変化です。

[出典: Tempo](https://tempo.xyz/blog/wirex-is-now-live-on-tempo)

### 🔗 Circle、Noble 上の USDC と CCTP V1 を終了

Circle が、Noble 上の USDC と旧世代の相互転送規格 CCTP V1 の提供を終えると発表しました。2026年10月13日に Circle Mint 経由の新規発行を止め、2027年1月12日に Noble 上の USDC を全面的に停止して転送経路も閉じます。翌1月13日からは手動の償還窓口を開きます。Noble は Cosmos 圏で USDC を発行してきた専用チェーンですが、Circle は「Noble に CCTP V2 は提供しない」と明言しました。理由として挙げているのは、確定の速さと安全性で勝る CCTP V2 への移行です。発行の顧客は期日までに償還し、自己保管の利用者は取引所か分散型取引所での交換、あるいは CCTP V1 経由で他のチェーンへ移す必要があります。開発者は対応経路から Noble を外すことになります。Circle は Injective をはじめとする IBC 接続のチェーンとの提携は続くとしており、Cosmos 圏から引き上げるわけではありません。発行体の判断ひとつで特定のチェーン上の USDC が期限付きで消えるという、預託型ステーブルコインの構造がはっきり出た事例です。

[出典: Circle Blog](https://www.circle.com/blog/circle-is-discontinuing-support-for-usdc-and-cctp-v1-on-noble)
