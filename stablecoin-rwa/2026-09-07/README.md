# 【2026/09/07】今週のステーブルコイン & RWA

## 今週のニュース

### 🏛️ Ondo、無期限先物と証拠金の規則見直しを当局へ要請

Ondo Finance が9月2日、SEC と CFTC へ提出した3通の意見書を公表しました。第一は商品定義で、無期限先物は限月を待たずとも資金調達率と時価評価によって価格が連続的に収斂するため、既存の証券先物法の枠内でこの設計を認めうると論じています。第二はポートフォリオ・マージンで、証拠金規則は決済に日数を要した時代の枠組みではなく、実際に存在するリスクと、それを実時間で測る手段の向上に合わせるべきだとしています。第三はデータ報告で、当局が別建ての報告体系を維持するのではなく、取引そのものに埋め込まれたオンチェーンの記録と証明を第一次の記録として使えると提案しました。同社はトークン化した米国債や株式の発行体として知られ、公開チェーン上で無期限先物の Ondo Perps を運営しています。自社の商品が既存の分類のどこに収まるかを、規則の側から動かそうとする動きであり、当局の応答は RWA 全体の扱いに跳ね返ります。

[出典: Ondo Finance](https://ondo.finance/blog/open-markets-by-design)

### 🪙 USDe、Aave V4 の Avalanche 版へ追加提案

Aave Labs が9月1日、Ethena の合成ドル USDe を Avalanche 上の Aave V4 Core インスタンスへ追加する提案を公開しました。USDe は預け入れた担保に無期限先物の売り持ちを組み合わせて1ドルを保つ設計で、法定通貨の準備金を積む USDC や USDT とは裏付けの作りが異なります。すでに複数の Aave インスタンスで取り扱いがあり、今回は Ethena が USDe を Avalanche へ広げる動きに合わせたものです。提案は事前審議の段階を飛ばして投票へ進む Direct to AIP の経路を採っており、担保掛目や供給上限といったリスク指標はリスク審査事業者が後から確定して提案へ反映されます。同じ週には Aave V3 側で USDe の基準金利を引き上げる提案も出ており、合成ドルという第三の作りが主要な貸借市場にどこまで受け入れられるかが、追加と価格付けの両面から同時に問われる形になっています。

[出典: Aave Governance](https://governance.aave.com/t/direct-to-aip-onboard-usde-to-aave-v4-core-instance-on-avalanche/25576)

### 🪙 Aave、USDe の基準金利を100bp 引き上げ提案

LlamaRisk が9月2日、Aave V3 のステーブルコイン金利モデルの変更を提案しました。中心は USDe で、これを扱う5つの配備すべてで基準金利を100ベーシスポイント引き上げ、目標とする5.25%へ近づけます。V3 Core と Avalanche では基準金利を2.00%から3.00%へ上げる一方、金利曲線の第1勾配にあたる slope1 を4.00%から3.00%へ同幅下げ、実際の借入金利は5.25〜5.5%の帯に収まるよう調整しました。狙いは、借入コストを Ethena のステーキング利回りに揃えることです。もう一つの変更は範囲が広く、11の配備にまたがる15のステーブルコイン準備金で slope1 を4.10%から4.30%へ引き上げます。基準金利と最適利用率は動かさないため、平時の金利はほとんど変わらず、利用率が上がったときの立ち上がりだけが速くなります。流動性が細る局面で貸し手が戻る動機を残す設計で、根拠は利用者の行動・オンチェーンの流動性・ポジションの健全性の観察に置かれています。

[出典: Aave Governance](https://governance.aave.com/t/risk-stewards-stablecoin-irm-changes-on-aave-v3-2026-09-02/25586)

### 🪙 Spark の8月、預金10.9%増も純収益26%減

Sky のフォーラムに、Spark 一家（SparkLend・Liquidity Layer・Savings）の2026年8月分の独立レビューが掲載されました。総預金は平均70.1億ドルで前月比10.9%増、ただし前年同月比では22.6%減です。SparkLend 単体でも10.7%伸びましたが、レビューは「ドル建ての伸びの大半は担保の値上がり」だと注記しており、供給の75.8%を ETH と BTC に連動する資産が占めます。収益側はより厳しく、純収益は26%減の124万ドルでした。総利回りの低下が4.1%にすぎない以上、差を作ったのは調達コストです。資産の利回りが28ベーシスポイント下がる間に調達コストは12ベーシスポイント上がり、Liquidity Layer の取り分は6.7%から3.8%へ半減、利鞘は8月1日の46.2ベーシスポイントから月末には6ベーシスポイントまで縮みました。この水準が続けば、27.2億ドルの資産から年160万ドルしか得られない計算です。商いの量は動いていないのに、その上に乗る利鞘だけが消えつつあります。

[出典: Sky Governance](https://forum.skyeco.com/t/spark-august-2026-deposits-up-10-9-net-revenue-down-26-0-liquidity-layer-spread-at-6-bps/28213)

### 🔗 Tempo で Chainlink の価格フィード稼働

Tempo が9月3日、Chainlink の価格フィードが同チェーン上で稼働したと発表しました。Tempo は Stripe と Paradigm が作ったステーブルコイン決済向けの基盤で、2026年3月20日に本番網を立ち上げ、機械同士の支払いのための規格 Machine Payments Protocol を同時に公開しています。設計の段階から Visa、Mastercard、Deutsche Bank、Standard Chartered、Revolut、Nubank、Shopify、OpenAI、Anthropic、Ramp、DoorDash が関わってきました。今回の追加で、担保の評価と借入上限の管理、資金管理や決済の流れで使う為替の参照レートと滑り値の上限、ステーブルコインの時価を見ながら担保を積み増したり配分を組み替えたりする自動制御が、独自の価格供給の仕組みを自前で用意せずに書けるようになります。送金を通すだけの決済チェーンから、その上に信用と資金管理の機能を載せる段階へ進んだことを示す一歩です。

[出典: Tempo](https://tempo.xyz/blog/chainlink-data-feeds-on-tempo) ・ [参考: ledgerinsights.com](https://www.ledgerinsights.com/stripe-paradigm-launch-tempo-blockchain-alongside-machine-payments-standard/)

### 🔬 Ethena 創業者、利回り資産とトークン化を巡る対談

Castle Island が配信する番組の第737回で、Ethena の創業者 Guy Young 氏が3度目の出演をしました。扱っているのは、Ethena の成功と持続性を支えてきたもの、合成ドル以外の利回り資産にどれだけ需要があるか、その資金がどこから来ているか、オンチェーンだけで資産配分を組み立てることが今日可能か、そもそもなぜ金融商品をトークン化するのか、そして誰が勝ち残り Ethena はどこに位置するのか、という論点です。同社の USDe は法定通貨の準備金ではなく、担保と無期限先物の売り持ちの組み合わせで1ドルを保つ設計で、準備金型の発行体ともトークン化した国債とも異なる第三の作りにあたります。今週は Aave で V4 の Avalanche 版へ USDe を追加する提案と、USDe の基準金利を引き上げる提案が並んで出ており、この設計を主要な貸借市場がどう値付けするかが同時に問われています。

[出典: Castle Island](https://castleisland.vc/guy-young-ethena-on-digital-financial-markets-ep-737/)
