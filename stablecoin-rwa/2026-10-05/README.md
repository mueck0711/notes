### 🏛️ ECBシュナーベル理事、中銀マネーのオンチェーン化を提唱

ECB は理事イザベル・シュナーベル氏の講演「Central banks on-chain」の資料を公開しました。同氏は8月28日のジャクソンホール会議でも同じ題で講演し、「恩恵を得るには中央銀行もオンチェーンに出る必要がある」と述べています。論点は、トークン化された欧州の市場で決済資産の席を誰が取るかです。ステーブルコインは金融が逼迫したときに流動性を素早く広げられず、中銀準備ほどの強さが無いため、支払手段として規制すべきだとしています。一方で、中銀が場に出なければドル建てのトークンが空白を埋めると警告しました。背景にあるのが ECB の2本立ての取り組みです。DLT 基盤と TARGET をつなぐ卸売決済の Pontes は9月21日に稼働を始め、スマートコントラクトや24時間運用は後の段階で入ります。長期の技術標準と法的枠組みを描く Appia は、2028年に全体の設計図をまとめる予定です。対象はレポ・担保・公開市場操作といった銀行間の決済で、個人向けのデジタルユーロとは別の話です。

[出典: ECB](https://www.ecb.europa.eu//press/key/date/2026/html/ecb.sp261001_1~a0be67193b.en.pdf) ・ [参考: tftc.io](https://www.tftc.io/ecb-schnabel-central-bank-money-onchain-pontes-jackson-hole-2026)

### 🏛️ Circle、MiCA見直しで銀行預金30〜60%規定の撤廃要求

Circle は10月1日、欧州委員会が進める MiCA 見直しの対象別協議に回答を提出しました。要望は5点です。1つ目は、EU で認可を受けた法人と域外で規制される法人が同じステーブルコインを共同で発行する「マルチイシュアンス」の維持です。世界で流通する流動性を MiCA の規制の内側で動かすための仕組みで、無くなれば利用者が域外の無規制なトークンへ流れると主張しています。2つ目は、EMIR・CSDR・MiFIR にならった同等性・承認の枠組みです。域外の発行体は本国の監督を主にしたまま、EU の認可機関を通じて流通させられるようにします。残る3点は準備金の規定です。30〜60%を商業銀行の預金で持つ義務を、より柔軟な最低流動性の要件に置き換えること、単一国の国債を35%までとする上限を外すこと、銀行1行あたり総資産の1.5%までという集中の上限を外すことを求めました。いずれも、ドル建ての発行体が米国債を中心に準備金を組めるかどうかに関わります。

[出典: Circle Blog](https://www.circle.com/blog/circles-response-to-the-european-commissions-mica-review-consultation) ・ [参考: circle.com](https://www.circle.com/blog/circles-response-to-the-european-commissions-mica-review-consultation)

### 🏛️ Tether、イラン関連のUSDT約5.5億ドルを凍結

Tether は9月28日、米財務省がイランへの制裁を広げるなかで、2026年にイラン関連の USDT を約5億5,000万ドル凍結したと公表しました。内訳は、4月に2アドレスで3億4,400万ドル、7月に TRON 上の4ウォレットで1億3,000万ドルです。4月には OFAC がこの2アドレスをイラン中央銀行のデジタル通貨の識別子として正式に指定し、7月には TRON の4アドレスを追加しました。Tether はウォレットの凍結方針を OFAC の SDN リストにそろえています。凍結の累計は世界で50億ドルを超え、うち24億ドルが米当局との協力によるものです。支援した捜査は世界で2,900件超、うち1,600件超が米国の法執行機関の案件で、70か国の340超の機関と連携しているとしています。発行体がアドレスを凍結できること自体が、ステーブルコインを制裁の網に組み込む手段になっています。ドル建てステーブルコインの最大手が当局との協力をこれだけの数字で示したことは、米国でのステーブルコイン規制の議論にも材料を与えます。

### 💳 Stripe、新ステーブルコインOUSDを既定に採用

Stripe は9月30日、新しいステーブルコイン Open USD（OUSD）を Treasury・Issuing・Global Payouts・Crypto Onramp・Payments の各製品で使えるようにし、Tempo 上の OUSD を既定の設定にしました。ほかのステーブルコインも引き続き選べ、既存の残高を OUSD に替える必要はありません。発行するのは Open Standard で、Coinbase・Mastercard・Shopify・Stripe・Visa と200超の提携先が立ち上げた団体です。OUSD は Base・Ethereum・Solana・Tempo で動き、発行と償還に手数料がかかりません。提携先には利用量に応じた報酬があります。Tempo の発表によると、ローンチ時の流動性は分散型取引所・スワップ・ブリッジで計4億ドル超で、無料の発行・償還は Coinbase・Stripe・Visa が担い、Mastercard も加わる予定です。これまで企業向けのドル建てステーブルコインは Circle の USDC と Tether の USDT が中心でした。カード網と決済事業者が自ら持つ発行体が、その間に割って入った形です。準備金の構成は今回の発表には書かれていません。

[出典: Stripe](https://stripe.com/blog/ousd-now-live-on-stripe) ・ [参考: tempo.xyz](https://tempo.xyz/blog/ousd-is-live-on-tempo)

### 💳 Visa、ステーブルコイン連動カードの17%が法人向け

Visa は10月1日、ステーブルコインの企業利用に関するデータを公表しました。2026年度の年初来で、ステーブルコインに連動するカードの取扱高の約17%が法人・商用カードのプログラムで生じています（Visa 社内のプログラム分類による）。連動カードの取扱高は前年比で約200%伸び、Visa が支えるプログラムは個人・法人・商用を合わせて160を超えました。業界全体については Allium の調査を引用し、ステーブルコインによる支払いは年4,010億〜5,270億ドルと推計しています。主な内訳はサービス料560億ドル、給与430億ドル、仕入先への支払い280億ドルで、分析した企業間の支払いの43%が国境をまたいでいました。これまでステーブルコインのカードは、暗号資産の保有者が個人で使うものと見られがちでした。今回の数字は、精算・資金管理・越境の商取引という企業の業務に入り始めていることを示します。新しいプログラムの発表は無く、決済・資金移動・加盟店での受け入れという既存の機能を広げていく方針です。

[出典: Visa](https://investor.visa.com/news/news-details/2026/Visa-Data-Shows-Stablecoins-Gaining-Traction-in-Business-Payments/default.aspx)

### 🏗️ Ondo、カカオペイ証券と韓国株のトークン化で提携

Ondo Finance とカカオペイ証券は9月28日、韓国の上場株へのエクスポージャーを海外に届けるための覚書を結びました。役割は分かれていて、カカオペイ証券は外国人投資家向けの統合口座（オムニバス口座）を運営し、裏付けとなる株式の調達・保管・管理を担います。Ondo は「世界最大のトークン化株のプラットフォーム」として、海外の個人と機関投資家への流通を担います。最初の段階では、株式を調達・保管する基盤づくりに重点を置きます。両社は2026年内に共同のタスクフォースを立ち上げますが、商品化するかどうか、いつするかは、各法域の法規制、監督当局の指針、投資家保護の原則を踏まえて協議するとしています。商品化の日付は示していません。これまで Ondo のトークン化株は米国株が中心でした。韓国株は海外投資家がアクセスしにくい市場として知られ、現地の証券会社が裏付け資産の保管を引き受けることで、トークン化株の対象が米国の外へ広がる可能性があります。

[出典: Ondo Finance](https://ondo.finance/blog/ondo-and-kakaopay-securities-partner)

### 🪙 Aave、GHOの借入金利を4.50%へ引き上げ提案

TokenLogic が10月2日、GHO Stewards の枠組みで10月の金利改定案を出しました。Aave V3 Ethereum Core での GHO の借入金利を年4.25%から4.50%へ、Ethereum Prime の基準金利を2.75%から3.00%へ、それぞれ25bp 引き上げます。Core の借入金利は Aave Savings Rate と同じ水準にそろいます。Prime は、8月に決めた「最適な利用率で Core より25bp 低い」という差を保ちます。GHO は Aave が自ら発行するステーブルコインで、借入金利は供給量と価格の安定を調整するいちばん直接的な手段です。借入金利と貯蓄金利を一致させると、GHO を借りて Savings Rate で運用する裁定の余地が小さくなります。Stewards は月ごとに金利を見直しているため、今回の改定がその後の GHO の供給と借入の動きにどう表れるかが、次回の判断材料になります。

[出典: Aave Governance](https://governance.aave.com/t/gho-stewards-october-2026-gho-borrow-rate-update/25754)
