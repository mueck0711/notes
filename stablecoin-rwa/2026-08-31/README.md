## 今週のニュース

### 🏛️ ECB シュナーベル、中銀準備金のオンチェーン発行を提唱

ECB 理事のイザベル・シュナーベル氏が8月28日、ジャクソンホール会議での講演「Central banks on-chain」で、中央銀行が分散型台帳上にネイティブなプログラム可能準備金を発行する構想を示しました。Eurosystem はこれまで既存の TARGET と外部の DLT を橋渡しする形で実験を重ねてきましたが、同氏はブリッジや民間の仲介に依存する設計そのものを問題視します。ステーブルコインについては、1913年以前の国法銀行制度を引き合いに、危機時に流動性を弾力的に拡張できるのは中央銀行だけだとして決済資産の代替を否定しました。スマートコントラクトによってレポ取引や担保管理、政策の調整を即時に自動化できる一方、アトミック性を最大化する統一台帳と、耐障害性と革新を高める相互接続網のどちらを採るかは相互運用の設計次第だとしています。Eurosystem の Pontes は来月始動し、当初は TARGET と DLT の同期から入り、決済ファイナリティは最終的に自前の DLT へ移して、スマートコントラクトと24時間稼働を後から加える予定です。

[出典: ECB](https://www.ecb.europa.eu//press/key/date/2026/html/ecb.sp260828~fe9afc86e8.en.html)

### 🏛️ ECB、トークン化市場の基盤 Pontes を年内に始動

ECB 理事のピエロ・チポローネ氏が8月26日、ドイツ連銀の「決済の未来」シンポジウムで、欧州のトークン化金融市場を実装段階へ進める道筋を示しました。背景にあるのは市場の急拡大です。公開チェーン上のトークン化された伝統資産は2025年3月の47億ユーロから2026年3月に233億ユーロへ約5倍に増え、米国のある民間プラットフォームは2026年3月にトークン化レポを日次3540億ドル（前年比4倍）処理しました。一方で欧州は証券保管機関31社・清算機関14社・取引所323という分断を抱え、2023年の取引の95%超が個別の保管機関の中で完結しています。同氏は断片化、民間の決済資産への依存による通貨アンカーの喪失、非欧州インフラへの依存の3つをリスクに挙げました。市場の DLT 基盤を TARGET へ接ぐ Pontes は当初オンボーディング手数料のみで開始し、2027年末に22.5時間稼働、2028年半ばに24時間・多通貨へ拡張。標準と法制度を扱う Appia は2028年までに統合された青写真を出します。

[出典: ECB](https://www.ecb.europa.eu//press/key/date/2026/html/ecb.sp260826~3641116314.en.html)

### 🔗 Circle、USDC と EURC を決済特化 L1 の Plasma へ

Circle は8月28日、USDC と EURC、チェーン間転送規格の CCTP、そして Bridge Kit の Plasma 対応を開始しました。Plasma は決済・清算・送金といったステーブルコインの高スループット用途を狙って設計された EVM 互換の L1 です。発行体の対応が無いチェーンでは第三者ブリッジ経由の合成トークンに頼ることになり、裏付けと償還の経路が発行体から切れますが、今回の対応で開発者は規制下にある全額準備型のドル・ユーロ建て通貨をそのまま扱えます。あわせて Circle Mint による機関向けの法定通貨オン/オフランプ、少ないコード量で組み込める CCTP でのチェーン間移転、Plasma のステーブルコインアプリである Plasma One との接続点も得られます。ユーロ建ての EURC が同時に載る点も特徴で、MiCA 準拠を前提にした欧州向けの決済・B2B 清算・FX・資金管理をこのチェーン上で組み立てられる形になりました。

[出典: Circle Blog](https://www.circle.com/blog/now-available-usdc-eurc-cctp-and-bridge-kit-on-plasma)

### 🔗 Circle、CCTP V1 を12月1日に完全停止

Circle が USDC のチェーン間転送規格 CCTP について、V1（Legacy）の廃止日程を明示しました。2026年10月31日に廃止が始まってバーン上限が縮小し性能が段階的に落ち、12月1日にはコントラクトが停止して V1 を経由する実装は動かなくなります。CCTP は送り元のチェーンで USDC をバーンし送り先でミントする発行体公式の経路で、資産をロックした保管庫を作らないため担保付きブリッジのような攻撃対象を持たない点が採用の理由でした。V2 は標準転送と高速転送の2モード、着金時に宛先チェーンで処理を自動実行するプログラム可能なフック、27チェーンへの対応を備えます。ただしコントラクトと API が別系統で後方互換は無く、Circle は移行を「推奨ではなく必須」と明記しています。USDC を跨チェーンで扱うウォレット・ブリッジ・取引所は、10月末の性能低下が始まる前に切り替えを終える必要があります。

[出典: Circle Blog](https://www.circle.com/blog/migrate-to-cctp-v2-ahead-of-cctp-v1-legacy-deprecation)

### 🪙 Aave、GHO の借入金利を 4.25% へ二段階で引き上げ

Aave の GHO Stewards（起案は TokenLogic）が8月27日、GHO のバランスシートの両側を動かす金利更新を出しました。借入側は Ethereum Core が 3.75% から25bp ずつ二段階で 4.25%、Ethereum Prime の基準金利が 2.00% から 2.75%（現在の利用率では実効 3.16%→3.91%）、Monad の Slope1 が 4.00% から 4.50% へ上がります。貯蓄側の sGHO は 4.25% から 4.50% へ一度に引き上げます。理由は二つあります。ひとつはペッグで、USDT の不調と GSM を通じた裁定により、8月25日までの30日のうち29日で GHO の割引が GSM の償還手数料10bp を超えていました。もうひとつは競合で、Sky Savings Rate が約 4.75%、Ethena のステーキングが 5.3% 近くにある中、sGHO は主要なオンチェーン貯蓄商品で最も低い水準に落ちていました。実行は各市場で約1週間おきの二段階、同時期に出ている Aave V3 のステーブルコイン金利カーブ調整と歩調を合わせます。

[出典: Aave Governance](https://governance.aave.com/t/gho-stewards-august-2026-gho-borrow-rate-and-aave-savings-rate-update/25534)

### 🏗️ Ondo の国債トークン USDY、Stripe の Tempo へ

Ondo Finance は8月27日、米短期国債を裏付けとする利回りトークン USDY を Tempo で公開しました。Tempo は Stripe と Paradigm が手がける決済向けの L1 で、1秒未満のファイナリティ、変動するガス通貨ではなくドル建てステーブルコインでの手数料支払い、決済用に確保した専用ブロックスペースを備えます。トークン化国債はこれまで許可されたアドレス間でしか移転できない設計が主流でしたが、USDY は非米国の適格な事業者やプロトコルであれば自由に移転できる設計を採っており、決済レイヤーに載せやすい性質があります。この統合により、Tempo 上の開発者はウォレットやネオバンク、給与システムで取引と取引の間に滞留する残高へ利回りを付ける原資として、また貸借や取引の担保、加盟店向けツールの資金管理資産として USDY を組み込めます。米国の個人・法人は対象外です。

[出典: Ondo Finance](https://ondo.finance/blog/usdy-is-live-on-tempo)

### 💳 アフリカ決済の Daya、Tempo で越境送金を拡張

アフリカ向けの決済インフラ Daya が8月27日、越境決済に Tempo のブロックチェーンを組み込むと発表しました。Daya はナイジェリアの企業を中心に、NGN・ZAR・GHS・KSH などのアフリカ通貨での集金と、USD・EUR・CNY・HKD・GBP を含む国際通貨での支払い、リアルタイムの両替、複数通貨での残高管理を一つの基盤で提供しています。今回、その裏側にあるステーブルコインの移動を、1秒未満のファイナリティとステーブルコイン建ての固定手数料を持つ決済特化チェーンへ寄せます。創業者兼 CEO の Aleph L 氏は、アフリカの企業が下のインフラを自分で運用することなく現地通貨とステーブルコインの間を行き来できるようにしたい、と述べています。取引量や手数料、settlement の所要時間、対応する具体的な送金回廊の数字は今回の発表では公表されていません。

[出典: Tempo](https://tempo.xyz/blog/daya-expands-cross-border-payments-for-african-businesses-with-tempo)

### 🔬 a16z、アルゼンチンのステーブルコイン定着を5図で分析

a16z crypto が、アルゼンチンのステーブルコイン利用を5つの図でまとめました。同国では5人に1人が暗号資産を使い中南米で最も高い水準にあり、主要15アプリのダウンロードは2024年に前年比93%増えています。ペソ建て取引の94%がステーブルコインへ向かうのは Artemis が追う主要通貨で最も高く、ペソで暗号資産を買うことが事実上ドルを買うことと同義になっています。Deel のデータでは、USDC で報酬を受け取るアルゼンチン在住の業務委託者の比率が前年比インフレ率と連動し、インフレが289%に達した2024年4月ごろにともに山を打った後、2026年7月にはピークの約5分の1まで下がりました。デジタルドルのプレミアムも2023年の100%超から、2025年4月の規制緩和を経て2026年8月には約4%へ縮小しています。それでもウォレット Lemon のダウンロードは月次インフレが25.5%から2.1%へ下がる間も四半期ごとに伸び続けており、危機対応の手段から定着した習慣へ移ったと結論づけています。
