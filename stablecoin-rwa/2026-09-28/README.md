### 🏛️ ユーロシステム、中銀マネーでトークン化資産を決済する「Pontes」始動

欧州中央銀行（ECB）とユーロシステムは2026年9月21日、DLT 上で取引されるトークン化資産の卸売取引を中央銀行マネーで決済できる「Pontes」を稼働させました。初期の参加者は ABANCA、BayernLB、CDC、Cecabank、Deutsche Bank、Deka Bank、DZ Bank、EIB、KfW、Memo Bank、NRW.BANK、Santander、Société Générale の13行と、Axiology・Cashlink・Clearstream・SWIAT の4つの DLT 事業者です。Deutsche Bundesbank も市場参加者として加わりました。これまでトークン化証券の資金側は、民間のステーブルコインや預金トークンか、チェーン外の既存決済に頼るしかありませんでした。当局が最も安全な決済資産を DLT につないだことで、ユーロ圏の機関がトークン化資産を扱う際の決済リスクが一段下がります。機能と稼働時間は段階的に広げ、2028年までに全面展開する計画です。並行して、Danmarks Nationalbank も加わる「Appia」が、2028年までに DLT ベースの金融サービスの青写真をまとめます。

[出典: ECB](https://www.ecb.europa.eu//press/pr/date/2026/html/ecb.pr260921~e754847a7b.en.html)

### 🏛️ ECB、自己資金でトークン化国債等に投資へ　決済はPontes

ECB は2026年9月21日、自己資金のごく一部をトークン化証券に投資すると発表しました。金融市場で分散型台帳技術（DLT）を使う実務の経験を積むことが目的です。当初の対象は、ユーロ圏の中央政府・地方政府・政府機関と欧州の超国家機関が発行するユーロ建て証券に絞ります。決済は、同じ日に稼働したユーロシステムの Pontes を通じて中央銀行マネーで行います。当局はこれまで、決済インフラの提供者としてトークン化の実験に関わってきましたが、今回は投資家として自ら発行市場に入ります。公的部門の債券のトークン化発行はまだ件数が限られているため、中央銀行という確かな買い手が見えることは発行体にとって後押しになります。ただし、現段階は準備作業を始めたところで、投資額は開示されていません。運用の詳細と時期は、準備作業が終わった後、役員会がトークン化発行と市場全体の動きを見て決めるとしています。

[出典: ECB](https://www.ecb.europa.eu//press/pr/date/2026/html/ecb.pr260921_1~5a011ecbea.en.html)

### 🏢 Binance、Circleに1億ドル出資　USDC提携を5年更新

Circle は2026年9月22日、Binance から1億ドルの出資を受けると発表しました。形態はクラスA普通株の私募で、価格はクロージング前の市場価格から5%割り引き、クロージングから最長2年のロックアップが付きます。同時に両社は戦略提携を広げ、商業契約を5年間更新しました。新しい契約の主眼は新興国市場での USDC の利用拡大です。Binance が自社プラットフォームで USDC の宣伝と組み込みを加速し、Circle がそれを支えるインフラを提供します。Binance の Richard Teng CEO は「安定したデジタルドルは、電話を持つ誰にでも使えるべきだ」と述べました。同社はこの出資を、USDC や Arc を含む発行体としての Circle の立場への長期的な確信だと位置づけています。USDC の流通経路のなかでも最大級の販路が、契約に加えて資本関係でも結ばれたことになります。

[出典: Circle](https://investor.circle.com/news/news-details/2026/Binance-Invests-100-Million-in-Circle-Expands-Strategic-Partnership-and-Renews-Commercial-Agreement-for-Five-Years/default.aspx)

### 🏗️ Ondo Stocks、保有株式から現物でトークン化株へ転換可能に

Ondo Finance は2026年9月21日、トークン化株式・ETF「Ondo Stocks」に、原株からの現物転換の経路を加えました。機関投資家が発行を依頼すると、Alpaca の口座にある株式が Ondo の口座へ帳簿上で振り替えられ、それに見合うトークンが Ethereum か BNB Chain 上で発行されます。償還では逆に、株式が機関の Alpaca 口座へ戻ります。仕組みには Alpaca の Instant Tokenization Network を使います。これまでの発行は現金払込型だけでした。株式をすでに持っている機関も、トークンを得るには別途資金を用意する必要があり、調達コストや時間差が生じていました。新しい経路では、マーケットメーカーが手元の株式のままトークン側との裁定に入れるため、取引所間のスプレッドを縮めて流動性を深める効果が見込まれます。利用できるのは Alpaca 上の承認済み機関に限られ、個別の審査で認められます。

[出典: Ondo Finance](https://ondo.finance/blog/convert-shares-to-tokenized-stocks)

### 💳 Tempo、Knovaと提携　銀行のトークン化預金の発行を支援

決済向けブロックチェーンの Tempo は2026年9月21日、金融機関向けの業務基盤を提供する Knova との提携を発表しました。Knova は、金融機関の既存システム・資産データ・取引の流れをつなぎ、従来型資産とデジタル資産の処理をまとめて調整する事業者です。この提携で銀行などは、Knova の Transaction Workflow Engine を通じて、Tempo 上でトークン化預金、ステーブルコイン決済、資産をまたぐ決済処理を立ち上げられます。対象は Tempo の TIP-20 規格の資産で、チェーン上の更新は webhook で受け取ります。重要なのは、カストディと署名を機関の側に残す設計です。Knova は顧客資産を持たず、署名に使うウォレット事業者は銀行が選び、資産は機関自身か機関が選んだカストディ事業者が保管します。基盤を作り直さずに済むため、銀行がトークン化マネーに踏み出す際の障壁が下がります。標準的なトークン送金の手数料は0.1セント未満です。私的な実行環境の Tempo Zones は、まだテストネットでしか提供されていません。

[出典: Tempo](https://tempo.xyz/blog/knova-tempo-tokenized-products)

### 💳 Visa調査、保護策があればステーブルコイン利用意向は56%に

Visa は2026年9月23日、国際送金に関する調査「Money Travels 2026」の結果を公表しました。調査は2026年2月24日〜3月2日に20市場の45,445人を対象に行い、うち米国は成人2,192人です。米国でステーブルコインを使う意向がある人は36%でした。これが、銀行並みの不正対策と預金保険が付くと仮定すると56%へ、20ポイント上がりました。既存の金融機関を通じて提供される場合は45%です。また、64%が「信頼は技術より提供者で決まる」と答えました。信頼できる提供者としては、商業銀行が61%、国際決済ネットワークが60%でした。他方、56%はステーブルコインという言葉を聞いたこともありません。送金の安全面では、36%が国際送金で詐欺に遭ったことがあり、44%が家族を装う AI ディープフェイクを心配しています。利用の壁は技術よりも、保護の仕組みと提供者への信頼にあるという結果です。

[出典: Visa](https://investor.visa.com/news/news-details/2026/Safeguards-Could-Boost-Stablecoin-Use-Among-Americans-Finds-Visa-Study/default.aspx)

### 🔗 Ondo Stocks、NEARへ展開　トークン化株など20銘柄

Ondo Finance は2026年9月22日、トークン化株式の基盤「Ondo Stocks」を near.com と NEAR Intents で使えるようにしました。near.com は、30以上のネットワークにまたがって資産の保有・交換・運用・支払いができる暗号資産口座です。NEAR Intents はチェーンをまたいで取引を振り分ける実行層で、非公開で決済するオプションも持ちます。提供は20銘柄から始まり、Tesla や NVIDIA などの米国株、QQQ などの ETF、SLV・IAU といった貴金属連動の商品が含まれます。利用できるのは、対応する法域に住む適格な near.com 利用者です。Ondo Stocks は TVL 10億ドル超、取引高260億ドル超、保有者数万人で、トークン化証券の基盤として世界最大をうたっています。これまでは Solana・Ethereum・BNB Chain で展開してきました。今回、チェーンをまたぐ実行層に入ったことで、利用者は特定のチェーンを意識せずにトークン化株を扱えるようになります。同じ週には原株からの現物転換も始めており、発行と流通の両面で経路を広げています。

[出典: Ondo Finance](https://ondo.finance/blog/ondo-stocks-go-live-on-near)
