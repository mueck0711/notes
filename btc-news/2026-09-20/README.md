# 【2026/09/20】きのうのビットコイン

## きのうのニュース

### 🇺🇸 Clarity法案が上院で頓挫、規制の主役はSECとCFTCへ

暗号資産の市場構造を定める Clarity 法案が米上院で前進せず、業界にとって厳しい1週間となりました。Crypto in America によれば、法案の停滞を受けて業界の関心は議会から規制当局へ移り、SEC と CFTC による新たな一連の動きが焦点になっています。立法による線引きが遠のいたことで、当面のルール作りは行政側の裁量に委ねられる形です。ビットコインを含む暗号資産の取り扱いが、法律ではなく当局の判断で決まる局面が続くことになり、次の一手は議会ではなく規制当局の発表を追う必要があります。

[出典: Crypto in America](https://www.cryptoinamerica.com/p/after-cryptos-bruising-week-on-capitol)

### 🇺🇸 OFAC、イラン取引所BitBankを制裁 革命防衛隊へBTC送金

米財務省の外国資産管理局（OFAC）は2026年9月17日、イランの暗号資産取引所 BitBank を制裁対象に指定しました。同社は OFAC 指定済みのイラン人金融家 Babak Zanjani が支配する事業で、6月から7月にかけて数億ドル相当のビットコインを革命防衛隊（IRGC）へ送金したとされています。措置はトランプ政権の「Operation Economic Outcast」の一環で、イランのデジタル資産部門全体を対象とする初のセクター指定も含まれます。ビットコインが国家レベルの制裁回避に使われたと米当局が公式に認定した事例で、取引所や送金経路への監視が一段と強まる可能性があります。

[出典: TFTC](https://www.tftc.io/ofac-sanctions-bitbank-iranian-crypto-exchange-irgc-operation-economic-outcast)

### 🇪🇺 ラガルドECB総裁がBinanceのEU参入を阻止と報道

Bitcoin Magazine は Wall Street Journal の報道として、欧州中央銀行（ECB）の Christine Lagarde 総裁が Binance の EU 進出を阻止したと伝えました。Lagarde 氏はかねてビットコインを批判し、中央銀行デジタル通貨（CBDC）を支持する立場で知られています。世界最大級の暗号資産取引所が EU 域内で足場を築くのを中銀トップが直接止めたという内容で、欧州では規制の枠組みだけでなく中銀首脳の姿勢そのものが業界の参入可否を左右していることを示しています。CBDC を推す中銀と民間の暗号資産事業者の緊張関係が、具体的な行政判断として表面化した形です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/eu-central-bank-president-blocked-binance)

### 🏢 Hyperliquid、BTC担保のレンディング機能を開始

Wu Blockchain の週次まとめによると、Hyperliquid が手動のレンディング・借入機能を開始しました。利用者は HYPE と BTC を担保に、USDC や USDT などの資産を借り入れることができ、借入残高に対して利息が課されます。ビットコインを担保資産として受け入れる貸借市場が、中央集権型の取引所や銀行だけでなくオンチェーンのデリバティブ取引所にも広がった形です。BTC を売らずにステーブルコインの流動性を得る手段が一つ増えたことになり、担保としてのビットコインの用途がさらに広がる動きとして注目されます。

[出典: Wu Blockchain](https://wublock.substack.com/p/weekly-project-updates-hyperliquid-33d)

### 🚨 Blinkが不正アクセスでサービス停止、預かり口座から流出

ビットコイン・ウォレット Blink は、セキュリティ事案の調査のためサービスを一時停止したと X で発表しました。攻撃者が一部のカストディアル（預かり型）口座にアクセスし、資金を引き出したとしています。同社は資金の大部分は安全で、非カストディアルのウォレットは影響を受けていないと説明しています。被害額や侵入経路は公表されておらず、調査結果の続報待ちです。預かり型の口座だけが被害に遭った点は、鍵を自分で持つ自己保管と第三者に預ける保管の違いが、被害の有無をそのまま分けた事例といえます。

[出典: x.com](https://x.com/blinkbtc/status/2101290680584695956)

### ⚡ Delving Bitcoinに「Depots」提案、盗難耐性の自己保管

Delving Bitcoin で JohnLaw 氏が「Depots」と題した提案を投稿しました。数十億人規模の利用者が盗難に強い形でビットコインを自己保管できるようにすることを目指した仕組みで、Lightning 開発者の Roasbeef 氏の助力にも謝意が示されています。投稿は分量が大きく当初は表示が崩れたため、整形し直した1本にまとめられています。カストディアンに預けずに大量の利用者が安全に鍵を持つ方法は、ビットコインの普及における中心的な課題の一つで、プロトコル研究の場での議論が続いています。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/depots-theft-proof-self-custodial-bitcoin-for-billions-of-users/2892/9)

### ⚡ bitcoin-devでハッシュ署名方式SHRINCSの議論続く

bitcoin-dev メーリングリストで、ビットコイン向けの効率的なハッシュベース署名方式「SHRINCS」の初稿をめぐる返信が続いています。提案は「効率的」を掲げた第一稿の段階で、メーリングリスト上で設計の検討が進んでいる状況です。議論の具体的な中身はスレッドを参照する必要がありますが、署名方式の刷新はビットコインの基盤に関わる変更を伴うため、短期に結論が出るものではなく、長期的なテーマとして開発者コミュニティの動向を追う価値があります。初稿への反応がどう収束するかが次の焦点です。
