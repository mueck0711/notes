### ⚠️ FRB・ECB・日銀が今週そろって金利決定、大手決算も集中

Wu Blockchain の週次展望（10月24日時点、対象期間は10月26日〜11月1日）によると、今週は米連邦準備制度理事会（FRB）、欧州中央銀行（ECB）、日本銀行の3つの中銀が相次いで政策金利を発表します。同じ週には Microsoft、Alphabet、Amazon の決算発表も重なります。日米欧の金融政策と米大手テック企業の業績が1週間に集まるため、投資家の関心はこれらの結果に向いています。ビットコイン市場でも今週の FRB の判断を待つ動きが伝えられており、暗号資産を含むリスク資産全体の方向を左右しうる週になります。

[出典: Wu Blockchain](https://wublock.substack.com/p/wublockchain-weekly-outlook-microsoft)

### 📈 Galaxy、ビットコインの弱気相場は6月安値で終了と分析

暗号資産の金融サービス企業 Galaxy の調査部門 Galaxy Research は、ビットコインの弱気相場が6月の安値で終わったとの見方を示しました。Bitcoin Magazine が Micah Zimmerman 記者の記事で伝えています。大手の調査部門が相場の局面について「弱気相場は終わった」とはっきり判断を示した点が注目されます。今週は FRB の金利決定を控えて市場の様子見が続いているため、その中で出たこの強気寄りの見方がどこまで支持を集めるかが焦点になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoins-bear-market-is-over-galaxy-says)

### 🏛️ 韓国、暗号資産課税の4度目の延期を検討 2029年開始案

韓国が、22%の暗号資産課税について4度目の延期を検討しています。開始時期を2027年1月から2029年へずらす案で、その理由は米国が OECD の暗号資産の報告の枠組みに加わったあと、韓国当局が米国の取引データを入手できるようにするためとされます。韓国の暗号資産課税はこれまでに3度延期されてきました。国外の取引所を使う投資家の取引を把握できないまま課税を始めると、税の公平性を保てないという事情が背景にあります。課税の開始を国際的な情報共有の進み具合に合わせるという考え方が、改めて示された形です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/south-korea-weighs-fourth-delay-crypto-tax)

### 🏛️ イスラエル中銀、首相の暗号資産による制裁回避案に反対

イスラエル銀行（中央銀行）は、欧米の銀行制裁を回避するために暗号資産を使うというネタニヤフ首相の計画を公に退けました。元総裁 Jacob Frenkel を含む109人の経済学者も、この計画は取り返しのつかない経済的損害をもたらすと警告しています。この反対表明は国政選挙の2日前に出されました。国家が制裁回避の手段として暗号資産を使う構想に、自国の中銀がはっきり反対したことになります。暗号資産と国際的な金融制裁の関係をめぐる議論に影響しうる動きです。

[出典: TFTC](https://www.tftc.io/bank-of-israel-rebukes-netanyahu-crypto-sanctions-evasion-plan)

### 🏢 Strategy、BTC購入を休止し優先株を2億ドル買い戻し

ビットコインを大量に保有する Strategy（MSTR）は、10月19日〜25日の週にビットコインを購入しませんでした。代わりに約2億490万ドルを使って、自社の優先株 STRC を買い戻しました。これまで毎週のようにビットコインを買い増してきた同社が購入を見送り、資金を優先株の買い戻しに回したことになります。企業によるビットコイン保有の代表例である同社の資金の使い方の変化は、ほかのビットコイン保有企業の動きや市場の需給を読むうえでも注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strategy-mstr-pauses-bitcoin-buying-205)

### 🚨 Electrumに悪用済みの手数料引き上げ詐取の欠陥、4.8.3で修正

ビットコインウォレットの Electrum は10月24日、すでに実際に悪用されていた深刻度の高い脆弱性をバージョン4.8.3で修正しました。悪意あるサーバーが未承認の送金を偽装し、利用者が Replace-by-Fee（RBF）で手数料を引き上げて送金を急がせる際に、送金を気づかれないうちに差し替えて資金を攻撃者のアドレスへ送らせる手口です。日常的な操作の途中で資金が奪われるため、利用者は気づきにくくなります。Electrum の利用者は早めに4.8.3へ更新する必要があります。

[出典: TFTC](https://www.tftc.io/electrum-4-8-3-rbf-fee-bump-exploit-patch)

### 🚨 Keystone、デバイス鍵の流出で約1万9000台のウォレットを廃棄へ

ハードウェアウォレットを製造する Keystone が、デバイスの鍵の流出を受けて、約1万9000台のウォレットを廃棄する方針を示しました。Protos によると、ハードウェアウォレットの製造元では最近、顧客データの流出が複数起きています。こうした流出は、利用者を狙ったフィッシングメールや標的型の詐欺、さらに深刻な被害につながるおそれがあります。自分で鍵を管理するための機器でも、製造元の情報管理が弱点になりうることを示した事例です。

[出典: Protos](https://protos.com/keystone-to-destroy-almost-19000-wallets-after-device-key-leak/)

### ⚡ BTCPay Server 2.4.6公開、API権限などのセキュリティを強化

オープンソースのビットコイン決済サーバー BTCPay Server がバージョン2.4.6を公開しました。今回の更新では、API の権限、外部から渡される信頼できない入力、生成されるリンク、ブラウザ上の操作について、セキュリティを幅広く強化しています。互換性に影響する変更もあり、請求書の電子メール通知では、請求書ごとに設定していた従来の方式が削除されました。BTCPay Server は、加盟店が第三者を介さずに自分でビットコイン決済を受け付けるための基盤です。運用している事業者は、更新の前に変更点を確認する必要があります。

[出典: github.com](https://github.com/btcpayserver/btcpayserver/releases/tag/v2.4.6)
