# 【2026/11/15】きのうのビットコイン

## きのうのニュース

### 📈 ビットコイン週間14%安、週末の売りで金曜安値割れ

Bitcoin Magazineによると、ビットコイン価格は過去1週間でおよそ13〜14%下がり、土曜日には6万5600ドル付近で取引されました。週末に入っても売りが続き、金曜日につけた安値を下回ったことで下げが加速しました。週末は参加者が少なく、注文の厚みも薄くなりがちです。そのため、節目の安値を割り込むと追加の売りを呼びやすくなります。1週間で2桁の下落は、ここ最近の相場の流れを大きく揺さぶる規模です。直近の安値を下回ったことで、どこで下げ止まるかが週明けの焦点になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-crashes-13-percent-65600)

### ⛏️ パラグアイ、マイナー向け電力契約を打ち切りAIへ15年供給

パラグアイの国営電力会社ANDEは、ビットコインのマイナー向けに結んでいた特別電力契約を、2027年12月31日より先には延長しないと表明しました。対象はおよそ944MWで、世界のハッシュレートの推定4%に当たります。ANDEは同時に、Founders Fundが出資するAI向け施設と15年間の電力供給契約を結びました。安い電力でマイナーを集めてきた国が、電力の行き先をAIへ切り替える動きです。期限までに移転先を見つけられない事業者が出れば、ハッシュレートの地理的な分布にも影響が及びます。

[出典: TFTC](https://www.tftc.io/paraguay-ande-bitcoin-miner-power-contracts-end-ai-campus)

### ⛏️ P2Poolv2がtestnet4で稼働、許可不要の分散マイニング

P2Poolv2は、許可不要のマイニングを掲げる新しいプール方式で、現在はテストネットのtestnet4上で動いています。プールが確かめるのは参加者の身元ではなく、提出された仕事そのものです。すべてのノードが全シェアを再生して配分を検算できる「監査可能な会計」も備えています。報酬は参加者が自分で持つ鍵へ直接届き、運営者が預かる仕組みではありません。運営者を信頼しなくても参加できるプールの選択肢を広げる試みで、本番のネットワークで動く前の試験段階にあります。

[出典: p2poolv2.org](https://p2poolv2.org/)

### 🚨 Core LightningにDoS脆弱性、v26.06.8で修正

Core Lightningのチャネル開設処理に、サービス妨害（DoS）攻撃を受ける脆弱性が見つかり、v26.06.8で修正されました。識別番号はLNF-2026-0004です。v0.12.0からv26.06.7までの版は、資金出力（funding outpoint）を重複して使う funding_created メッセージを受け入れてしまう問題を抱えていました。開示はDelving Bitcoinで行われ、ノード運営者には最新版への更新が呼びかけられています。Core LightningはLightningの主要な実装の一つで、影響を受ける版の幅が広いため、運営者は自分の版を確かめる必要があります。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/disclosure-dos-vulnerability-fixed-in-core-lightning-v26-06-8/3072)

### ⚡ 耐量子アドレス「bc1z」のBIP草案、開発者MLで議論

ビットコイン開発者のメーリングリストで、量子計算機への耐性を持つ新しいアドレス形式「bc1z」を定めるBIP草案に返信が寄せられました。草案は署名方式にML-DSA-65を使う案で、返信はMurch氏のドメインから送られています。ML-DSAは、米国立標準技術研究所（NIST）が標準化した耐量子署名方式の一つです。量子計算機が実用化されれば現行の署名方式が破られるおそれがあるため、移行先のアドレス形式をどう設計するかは長期的な課題として議論が続いています。議論の具体的な中身は投稿本文で確認できます。

[出典: bitcoin-dev](https://gnusha.org/pi/bitcoindev/274e5242-4654-4f7c-b56f-609a3f2ee132@murch.one/)

### ⚡ 開発者メーリングリストでTestnet5の立ち上げ告知

ビットコイン開発者のメーリングリスト（bitcoindev）に、新しいテストネット「Testnet5」の立ち上げを告げる投稿がありました。テストネットは、本物の資金を使わずにソフトウェアや新機能を試すための公開ネットワークです。開発者やウォレット、マイニングの事業者が動作確認に使います。いまのtestnet4は、新しいプール方式P2Poolv2の試験運用にも使われています。新しいテストネットができると、試験環境を移すのか併用するのかが論点になります。仕様の変更点や移行の時期は、告知本文で確かめる必要があります。
