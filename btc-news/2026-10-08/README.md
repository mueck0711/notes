# 【2026/10/08】きのうのビットコイン

## きのうのニュース

### ⚠️ 原油高と米金利上昇で全面安、ビットコインも下落

Bitcoin Magazine によると、原油価格の急騰と米国の借入コスト上昇を受けて多くの資産が売られ、ビットコインも1日で4%近く下げて8万3,000ドルを割り込みました。今回の下げは暗号資産だけの材料ではなく、株式なども含めた幅広い売りの中で起きています。原油と米金利という外部のマクロ要因が、そのままビットコインの値動きに響いた形です。エネルギー価格と金利の先行きが、当面の相場を左右する材料として意識されそうです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-falls-under-83000)

### ⚠️ 米10年債入札、2000年以来の高利回り5.3%

米財務省は10月7日、390億ドル分の10年債を入札し、落札利回りは5.300%でした。これは2000年11月以来の高さです。海外勢を含む間接入札者の落札比率は80.3%と過去最高に迫り、プライマリー・ディーラーの引き受けは2.5%と、この年限で記録上最も低くなりました。米国の長期金利がここまで上がると、借入コストの上昇を通じてリスク資産全般の重しになります。同じ日に起きたビットコインの下落の背景として押さえておきたい動きです。

[出典: TFTC](https://www.tftc.io/10-year-treasury-auction-5-300-yield-record-foreign-demand-2026)

### 🏦 米投資家は暗号資産の買い増し志向、Schwab調査

Charles Schwab が公表した新しい調査によると、暗号資産を保有する米国の投資家は、今後1年間も保有を増やし続けたいと考えています。米国最大級の証券会社が自社の調査として個人投資家の買い増し意欲を示した点に意味があります。相場が下げている局面でも、既存の保有者が投資を続ける姿勢を持っているかどうかは、需要の底堅さを測る手がかりになります。伝統的な金融機関の顧客層で暗号資産が定着しつつあることを示す材料の一つです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/charles-schwab-says-investors-want-crypto)

### 🇺🇸 CFTC委員長、新ルールでFTX型破綻を防ぐと表明

米商品先物取引委員会（CFTC）の Mike Selig 委員長は、暗号資産の分野に厳格な規制を導入したいと述べ、新たに進める規則づくりで FTX のような破綻の再発を防ぐ考えを示しました。CFTC はビットコインを商品として扱う立場にあり、デリバティブ市場や取引業者の監督で中心的な役割を担います。委員長が規則づくりの狙いを FTX 型の破綻防止と明言したことで、今後の取引所や仲介業者への監督がどこまで厳しくなるかが注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/cftc-boss-says-rules-will-stop-another-ftx)

### 🏛️ ロシア中銀、ズベルバンクをビットコイン管理業者に承認

ロシア銀行（中央銀行）は10月6日、新しい暗号資産法のもとで、国営のズベルバンクを含む5つの機関をビットコインのカストディ業者として承認しました。ズベルバンクは12月1日から、既存のアプリを通じてビットコイン、イーサリアム、USDT の保管サービスを始める計画です。すべての取引に本人確認とマネーロンダリング対策の報告が義務づけられます。ロシア最大の銀行が国の認可を得てビットコインを扱うことになり、ロシアの暗号資産政策の転換を示しています。

[出典: TFTC](https://www.tftc.io/sberbank-bitcoin-custodian-russia-crypto-law-2026)

### 🏢 Robinhood、自社資金でビットコイン2,500万ドル保有

Robinhood は2026年10月7日、自社資金で2,500万ドル分のビットコインを貸借対照表に載せました。これにより同社は、暗号資産の売買サービスを提供する立場から、ビットコインを自ら保有する企業へと一歩踏み出しました。保有額そのものは小さいものの、多くの個人投資家を抱える大手証券アプリが企業財務にビットコインを組み入れた前例として意味があります。ほかのフィンテック企業や証券会社が後に続くかどうかが今後の注目点です。

[出典: TFTC](https://www.tftc.io/robinhood-25-million-bitcoin-balance-sheet-corporate-treasury)

### ⛏️ エチオピアが採掘業者への電力削減、9月の採掘動向

Wu Blockchain が9月の世界の採掘ニュースをまとめました。エチオピアがビットコイン採掘業者への電力供給を大幅に削ったことや、スウェーデンが暗号資産企業に5億4,000万クローナの追徴課税を求めていることが取り上げられています。また CoinShares の2026年第2四半期の採掘レポートによると、上場マイナーは電力やデータセンターの資源を AI と高性能計算（HPC）へ振り向け続けています。安い電力の確保と事業の多角化が、採掘業の大きな課題になっています。

[出典: Wu Blockchain](https://wublock.substack.com/p/global-crypto-mining-news-in-september-42a)

### ⚡ OpenSats、Bitcoin Core 基盤開発に新規助成4件

非営利団体 OpenSats は、Bitcoin Core の基盤となる開発を支えるため、新規の助成4件と更新1件を決めたと発表しました。Bitcoin Core はネットワークの大半のノードが使う基準の実装で、その保守や改良は特定の企業に属さない開発者が担う部分が多くあります。こうした開発者が継続して働ける資金の手当ては、プロトコルの安全性と持続性に直結します。寄付をもとにした助成が開発を支える仕組みとして続いていることを示す発表です。

[出典: opensats.org](https://opensats.org/blog/supporting-the-foundations-of-bitcoin-development)
