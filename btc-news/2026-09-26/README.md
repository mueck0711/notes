# 【2026/09/26】きのうのビットコイン

## きのうのニュース

### 🇺🇸 SEC ピアース委員、退任前にKYCの「監視社会」終結を訴え

米証券取引委員会（SEC）のヘスター・ピアース委員が、任期最後の数週間に入るなかで、暗号資産の本人確認（KYC）が生み出す「パノプティコン（一望監視施設）」を終わらせるよう呼びかけました。ピアース氏は、規制当局が積み上げる「データの干し草の山」が、守るべきはずの人々をかえって危険にさらしていると指摘しています。背景には、最近相次いだKYC情報の流出で、暗号資産の保有者が襲撃などの標的にされている問題があります。規制する側の内部から、本人確認データを大量に集めること自体の危うさが指摘された点で、今後のプライバシーをめぐる議論に影響しうる発言です。

[出典: Decrypt](https://decrypt.co/379217/sec-peirce-end-kyc-panopticon-zero-knowledge-proofs?amp=1)

### 🏛️ ブラジル中銀、1万ドル以上の自己管理ウォレット送金に報告義務

ブラジル中央銀行は9月24日に決議588号と589号を公表し、認可を受けた暗号資産取引所に対して、自己管理ウォレットとの間の送金のうち1万ドル以上のものをすべて、同国のマネーロンダリング監視当局へ報告するよう義務づけました。新しいルールは10月1日に施行されます。取引所から利用者自身が鍵を管理するウォレットへ資産を移す行為が、金額によっては当局に把握される対象になる点が特徴です。自己管理はビットコインの基本的な使い方であり、中南米の主要経済国が取引所の出入口に報告義務を課したことは、他国の規制の設計にも影響しうる動きとして注目されます。

[出典: TFTC](https://www.tftc.io/brazil-self-custody-reporting-resolution-588-589-bcb)

### 🏢 Strategy、優先株4銘柄の配当を日次払いへ提案

ビットコインを財務資産として保有する Strategy が、優先株 STRF、STRC、STRK、STRD の4銘柄について、配当を毎日支払う形に改める案を示しました。株主に対しては、この案を承認するための会合への出席を求めています。配当の支払いを日次にまで細かくするのは異例の設計で、利回りを求める投資家にとって優先株の魅力を高めるねらいがあるとみられます。同社はビットコインの保有を事業の中心に据えた企業の代表格であり、その資金調達の仕組みがどう変わるかは、同じ戦略をとる他の企業にも参照されやすい動きです。実現するかどうかは株主の判断に委ねられます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strategy-proposes-daily-dividends)

### 🚨 Bitget で約3.5億ドル流出、北朝鮮ラザルスの関与か

暗号資産取引所 Bitget は、9月24日18時31分（UTC）に一部のホットウォレットから不正な送金を検知したと発表しました。影響額は約3億5160万ドルにのぼり、出金は一時停止されています。CEO のグレイシー・チェン氏は、北朝鮮のラザルス・グループが関与しているとみられると述べました。攻撃の手口はまだ明らかになっていません。同社は4億6400万ドル規模の保護基金を掲げていますが、その中身は検証されていないとの指摘もあります。取引所のホットウォレットに預けた資産がまとめて狙われうることを、あらためて示した事件です。

[出典: Protos](https://protos.com/bitgets-eighth-birthday-ends-with-a-352m-hack/)

### ⚡ Optech 第424号、Lightning の耐量子化提案を紹介

Bitcoin Optech の週刊ニュースレター第424号は、Lightning Network のオフチェーンプロトコルを、量子計算機に耐えられる安全性へ引き上げる提案を取り上げました。あわせて、Bitcoin Stack Exchange から選んだ質疑応答や、新しいリリースとリリース候補の告知など、恒例の欄も掲載しています。量子計算機が将来ビットコインの署名を破りうるという懸念については、これまでオンチェーンの議論が中心でした。Lightning のような上位の仕組みでも備えを検討する動きが出てきたことは、対策がプロトコル全体に広がり始めたことを示しています。

[出典: Bitcoin Optech](https://bitcoinops.org/en/newsletters/2026/09/25/)

### ⚡ Eclair v0.14.0、DoS 脆弱性2件の修正を開示

Lightning の実装の一つである Eclair について、v0.13.1 以前にあったサービス妨害（DoS）の脆弱性2件が v0.14.0 で修正されたことが、Delving Bitcoin で開示されました。そのうち LNF-2026-0001 は機能ビットの解析に関するもので、旧版は機能ベクトルを1ビットずつ解析し、ビットごとに複数のヒープオブジェクトを確保していました。この処理が攻撃に悪用されうるものでした。開発側は、ノードを守るため v0.14.0 以降へ更新するよう利用者に呼びかけています。Eclair でノードを運営している人には、すぐに対応が必要な告知です。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/disclosure-dos-vulnerabilities-fixed-in-eclair-v0-14-0/2914)
