# 【2026/11/25】きのうのビットコイン

## きのうのニュース

### ⚠️ 米が16経済圏へ新関税準備、11月のETF流出は過去最大

TFTCによると、トランプ政権は16の国・地域を対象とする新たな関税の準備を進めています。ビットコインは月曜日の高値からおよそ8%下げ、5万9,380ドル前後まで売られました。米国の現物ETFからの資金流出は11月に47.1億ドルへ膨らみ、ETFの時代が始まって以来で最大になったとしています。Decryptも、エヌビディアを手がかりにした反発の勢いが薄れ、投資家が金利の上昇に身構えるなかで、株式と暗号資産の双方に警戒感が広がっていると伝えました。関税と金利という外部要因に、ETFからの資金流出が重なっている点が今回の下落の特徴です。

[出典: TFTC](https://www.tftc.io/trump-tariffs-bitcoin-drops-etf-outflows-record-november-2026)

### 🏦 機関のBTC ETF保有、投資助言業者が最高の40.5%に

米国の保有報告書「13F」の2026年第3四半期分で、機関投資家が持つビットコインETFのうち、資産運用の助言業者とそのプラットフォームの割合が過去最高の40.5%に達したとTFTCが報じました。1年前の24.3%から大きく伸びています。助言業者の買い越しは9四半期連続です。単独の最大保有者も入れ替わり、ウェルズ・ファーゴがミレニアムを抜いて首位に立ちました。足元では現物ETFからの資金流出が続いていますが、四半期単位で見ると、顧客の資産を預かる助言業者が継続して保有を積み増し、機関投資家の中で存在感を強めてきたことが分かります。

[出典: TFTC](https://www.tftc.io/wealth-advisors-record-40-percent-institutional-bitcoin-etf-holdings-q3-2026)

### 🏦 アンカレッジ、BTC建て利回りを狙う運用子会社を設立

Anchorage Digitalが、資産運用を手がける子会社「61st Parallel Asset Management」を立ち上げます。Bitcoin Magazineによると、12月上旬までに業務を始める見込みで、ビットコイン建てのファンドを用意します。Anchorageに資産を預けている顧客は、このファンドを通じてビットコインから利回りを得られるようになります。ドルではなくビットコインを単位とする設計のため、保有枚数を基準に運用の成果を測れる点が特徴です。保管を担ってきた企業が運用まで自社グループで引き受け、預かり資産を運用につなげる動きとして注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/anchorage-digital-bitcoin-yield-asset-manager)

### 🇺🇸 CFTC、清算機関の運営準備金にビットコイン算入を容認

米商品先物取引委員会(CFTC)の職員が、スワップの取引施設や清算機関の準備資産に関する指針を示しました。Decryptによると、12カ月分の運営費をまかなうための備えに、ビットコイン、イーサリアム、ステーブルコインを算入できるようになります。Decryptは、この指針には見落とせない条件があるとして、何が認められ、何が認められないのかを整理しています。対象は運営費の備えであり、職員による指針という位置づけです。それでも、規制下にある市場の基盤を担う事業者が、財務上の備えとしてビットコインを数えられることになる点に意味があります。

[出典: Decrypt](https://decrypt.co/383906/cftc-new-crypto-reserves-guidance-actually-allows-what-it-doesnt)

### 🐋 「失われた」BTCウォレット、1割超が2018年以降に移動

匿名の開発者Quickben22氏が、2018年に作られた休眠ビットコインウォレット9万2,076件の一覧を改めて調べました。TFTCによると、このうち10.8%にあたる9,990件で、その後に資金が動いていたことが分かりました。動いた量は約24万5,000BTC、金額にして147億ドル相当です。長く動いていないコインは永久に失われたとみなされることが多く、その前提は供給の希少性を語る際の根拠にもなってきました。今回の結果はこの前提に正面から疑問を投げかけるもので、休眠期間の長さだけでは、失われたコインかどうかを判断できないことを示しています。

[出典: TFTC](https://www.tftc.io/dormant-bitcoin-wallets-245000-btc-moved-supply-scarcity)

### 🚨 Coldcard盗難の事後報告、原因は5年続いたシードの欠陥

ハードウェアウォレット「Coldcard」を手がけるCoinkiteが、シード生成の不具合に関する事後報告の全文を公開しました。Keylabsによる独立したソースコードとバイナリの検証結果も併せて示しています。Bitcoin Magazineによると、盗難の原因は機器への侵入ではなく、5年にわたるファームウェアの欠陥でシードが弱くなっていたことで、約242の顧客アカウントが被害を届け出ています。TFTCは、2021年3月の設定ミスで乱数の強度が128ビットから最小40ビットに落ち、8,600超のアドレスから約1,779BTCが盗まれたと伝えました。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/coldcard-postmortem-seed-flaw)

### 🚨 Chainflip、流出122BTCの9割返還を攻撃者に要求

Chainflipの開発元であるChainflip Labsが、保管庫から資金を持ち出した攻撃者に向けて声明を公開しました。資金が奪われたのは2026年11月21日で、流出額は122.86BTCです。声明は、このうち90%を返還するよう求め、応じない場合には法的措置を取ると警告しています。裏を返せば、残りの10%を攻撃者の手元に残す形での決着を提示したことになります。盗まれた資産の回収を、まず攻撃者との直接の交渉に委ねる対応であり、返還に応じるのか、それとも法的な追及へ進むのかが、今後の焦点になります。

[出典: chainflip.io](https://chainflip.io/return)

### ⚡ Electrumの中継サーバー、11月中旬に相次ぎ出現

ビットコインのウォレットが接続するElectrumサーバーについて、2026年11月中旬に中継用とみられるサーバーが相次いで立ち上がったとの観測結果が、bnoc.xyzに投稿されました。投稿者はElectrumサーバーの監視ツールを開発している途中で、ここ1週間に新しく登録されたドメインが、Electrumサーバーとして多数ネットワークに告知されていることに気付いたとしています。このツールは、Chainalysisが運営する公開の監視用サーバーを見分けられるか、という研究課題に取り組むなかで作られたものです。接続先の選び方が利用者のプライバシーに関わることを示す報告です。

[出典: bnoc.xyz](https://bnoc.xyz/t/electrum-proxy-servers-spun-up-in-mid-november-2026/215)
