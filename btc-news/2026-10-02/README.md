# 【2026/10/02】きのうのビットコイン

## きのうのニュース

### 📈 Darius Dale氏、2027年の流動性回帰でBTC大幅高を予想

Bitcoin Magazine の動画番組で、Darius Dale 氏が世界の流動性とビットコイン価格の見通しを語りました。同氏は、目先は流動性が引き締まるため、ビットコインが方向感のないもみ合いに陥るおそれがあると警告しています。一方で、2027年に流動性が戻れば、12〜18か月にわたる大きな上昇局面が来ると見込んでいます。短期は慎重、中期は強気という見立てを、世界の流動性という一つの軸で結びつけています。足元の相場が上昇の途中なのか、その前の足踏みなのかを考える材料になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/videos/darius-dale-will-global-liquidity-send-bitcoin-higher-in-2027)

### 🇺🇸 SEC、ファンドの暗号資産カストディ新規則を提案

米証券取引委員会（SEC）が、投資ファンドによる暗号資産の保管（カストディ）を律する新たな規則案を公表しました。SEC は、この規則案がファンドによる暗号資産の保管を管理するのに役立つと説明しています。ビットコインを組み入れるファンドにとって、資産をどこにどう預けるかは運用の前提そのものです。まだ規則案の段階ですが、保管のルールが明確になれば、ファンドを通じてビットコインを扱う際の制度上の不確実性が一つ減ることになります。今後の意見募集と最終規則の中身が焦点です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/sec-proposes-crypto-custody-rules)

### 🇺🇸 ダインズ上院議員、暗号資産税制法案の条文を公表

共和党の Steve Daines 上院議員が、暗号資産の課税に関する法案の条文を公表しました。同議員は、この法案によってステーブルコインなどの資産について、より明確なルールが設けられると説明しています。暗号資産を税務上どう扱うかは、ビットコインを保有する人にも、支払いに使う人にも直接関わる問題です。条文の公表は議論の出発点にすぎず、成立までの道のりはこれからです。それでも、米議会での税制の議論が具体的な文言の段階に入ったことを示す動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/republican-releases-crypto-tax-plan)

### 🏢 Strategy、STRC救済資金の64%を10週間で消化

Protos によると、Strategy は STRC を下支えするために用意した20億ドルの救済資金のうち、すでに64%を使い切りました。10週間にわたって買い戻しを続けた結果で、残りは7億2400万ドルを下回っています。Strategy の資金繰りは、同社のビットコイン保有戦略と直結しています。買い戻しの原資がこの速さで減っていることから、資金が尽きる前に STRC を支えきれるのか、あるいは別の手当てが必要になるのかが、今後の同社の資金調達を見るうえでの注目点になります。

[出典: Protos](https://protos.com/strategy-has-burned-through-64-of-its-strc-rescue-fund/)

### 🏢 Block、初の消費者向けビットコイン広告を開始

Jack Dorsey 氏が率いる Block が、同社として初めての一般消費者向けビットコイン広告キャンペーン「Bitcoin Does」を始めました。Block の説明によれば、うまく機能しないものもある世の中で、なぜビットコインが理にかなうのかを伝える内容です。Bitcoin Magazine は、人々にビットコインを使ってもらい、ビットコイン本位の暮らしへ導く狙いがあると報じています。保有を勧めるのではなく、支払いでの利用を促しているのが特徴です。決済事業を持つ大手企業が、日常での利用拡大に向けて自ら旗を振る動きです。

[出典: block.xyz](https://block.xyz/bitcoin/does)

### ⛏️ Peter Todd氏、MARA財団で私設メンプールを主導

Bitcoin Core の古参貢献者である Peter Todd 氏が MARA Foundation に加わり、マイナーの MARA が運営する私設メンプール（未承認取引の待機所）サービス「Slipstream」の主任メンテナーに就きました。財団が木曜日に発表したもので、Todd 氏が Slipstream の開発と保守を担います。マイニング大手が運営する私設メンプールの責任者に、Core の開発に長く関わってきた人物が就く人事です。取引がマイナーへどう届くかをめぐる議論にも影響しうる動きとして注目されます。

[出典: x.com](https://x.com/MARAFoundation_/status/2105659425054748922)

### ⚡ Eclair、DoS脆弱性2件をv0.14.1で修正

Lightning 実装の Eclair で、チャネル開設の処理にサービス拒否（DoS）脆弱性が2件見つかり、v0.14.1 で修正されたことが Delving Bitcoin で開示されました。うち1件（LNF-2026-0003）は open_channel の競合状態に起因するものです。v0.14.0 以前は、重複した temporary_channel_id を拒否する際に、相手側のチャネル情報を参照する作りになっていました。利用者には v0.14.1 以降への更新が呼びかけられています。Eclair でノードを運用している事業者や個人は、更新の要否をすぐに確認すべき情報です。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/disclosure-dos-vulnerabilities-fixed-in-eclair-v0-14-1/2928)
