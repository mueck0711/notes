# 【2026/09/29】きのうのビットコイン

## きのうのニュース

### 🏢 Strategy・Strive、1週間で計2,700BTC超を買い増し

ビットコインを財務に組み入れる企業の上位2社、StrategyとStriveが先週、合わせて2,700BTCを超えるビットコインを買い増したと、Bitcoin Magazineが報じました。2社が1週間で投じた金額は合計2億3,250万ドルにのぼります。財務戦略としてビットコインを保有する企業の中でも規模の大きい2社が、同じ週にそろって購入を続けたことになります。企業による継続的な買いは需給を支える要因として注目されています。上位の保有企業が買いの手を緩めていないことは、企業財務の分野の勢いを測るひとつの目安になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strategy-strive-buy-more-bitcoin)

### 🏛️ 英財務相、ファラージ氏の「ビットコイン口座」を批判

英国の財務相が、ビットコイン支持を打ち出している政党Reform UKのナイジェル・ファラージ党首が掲げる「ビットコイン口座」を批判したと、Bitcoin Magazineが報じました。国の財政を預かる閣僚が、野党指導者のビットコイン政策を名指しで批判した形です。Reform UKはビットコインに好意的な姿勢を示してきた政党です。その党首の構想に政府の財政責任者が反応したことは、英国でビットコインが政治の争点として扱われ始めていることを示しています。英国の政策論争がどちらへ向かうかを占う材料として注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/uk-finance-ministe-nigel-farage-bitcoin)

### ⛏️ カザフスタン、フレアガスでの採掘を大統領令で解禁

カザフスタンのトカエフ大統領が2026年7月に出した大統領令により、石油会社が油田で燃やして捨てていた余剰ガス（フレアガス）を、市場価格より安くビットコインのマイナーへ直接売る法的な道筋ができたと、TFTCが報じました。国の送電網を通さない仕組みで、40〜60の油田で推定1.2〜1.3TWhの電力が使えるようになるとされています。捨てられていたエネルギーを採掘に回す仕組みが、国の制度として整えられた点が重要です。送電網への負荷を避けつつマイニングの電力源を広げる例として、他の産油国の政策にも影響しうる動きです。

[出典: TFTC](https://www.tftc.io/kazakhstan-flare-gas-bitcoin-mining-decree-2026)

### ⛏️ River、採掘サービス巡りBlockstreamカナダ法人を提訴

Riverが、ビットコインのマイニングサービスをめぐってBlockstream Services Canadaを提訴したと、Protosが報じました。Riverの主張によると、Blockstream Services Canadaは23万9,000ドルの返済を6か月分にわたって滞らせており、Riverは陪審による裁判を求めています。ビットコイン業界で名の知られた企業同士が、マイニング事業の契約をめぐって法廷で争うことになりました。採掘サービスの取引で支払いの遅れが起きていることは、マイニング業界の資金繰りや企業間契約の実態をうかがわせるものとして注目されます。

[出典: Protos](https://protos.com/river-has-sued-blockstream-services-canada-over-bitcoin-mining-services/)

### 🚨 D'CENTウォレット鍵流出、被害がBTC・ETHへ波及

暗号資産ウォレットD'CENTの鍵が漏えいし、攻撃者が1,800万ドルを超えるXRPを盗み出したと、Protosが報じました。被害はXRPにとどまらず、Stellarやイーサリアム、ビットコインなど他のブロックチェーンにも広がっています。今年2番目に大きいXRPのハッキングとされています。ひとつのウォレット製品の鍵が破られたことで、複数のチェーンの資産にまで被害が及んだ点が重要です。同じウォレットでビットコインを保管している利用者も影響を受けうるため、自己管理であってもウォレットの選び方と鍵の扱いが資産の安全を左右することを改めて示しています。

[出典: Protos](https://protos.com/the-years-second-largest-xrp-hack-is-spilling-over-to-bitcoin-and-ethereum/)

### ⚡ Rust製の独立フルノード「bitcoin-rs」が公開

開発者向けフォーラムDelving Bitcoinで、Rustで書かれた独立したビットコインのフルノード実装「bitcoin-rs」の初期の成果が共有されました。btcdと同じくBitcoin Coreとは別の独立した実装です。Bitcoin Coreの中では進めにくい設計や性能面の変更を試すことを目的とし、外部から検証できる状態を保つことを目指しています。別の言語・設計によるノード実装が増えれば、ソフトウェアの多様性が高まります。特定の実装の不具合がネットワーク全体に及ぶリスクを下げる試みとして意味を持ち、今後の開発の進み具合が注目されます。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/bitcoin-rs-an-independent-bitcoin-full-node-written-in-rust/2918)

### ⚡ Breez SDK、ステーブルコイン対応の新機能を公開

Breez SDKがステーブルコインに関する新機能を公開したと、Bitcoin Magazineが報じました。記事は「ドルで入れて、ビットコインで出す」とうたっています。記事によると、ステーブルコインは「デジタルドル」と呼ばれながら、必ずしも使いやすいものではありません。さまざまな暗号資産ネットワーク上で動くため、それぞれに別のウォレットが必要になるからです。この手間は暗号資産の初心者だけでなく、経験を積んだビットコイン利用者にとっても障壁になっています。ドル建ての価値とビットコインの間の出し入れを開発キットの側でまとめる動きは、ウォレットやアプリの使い勝手を左右するものとして注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/breez-debuts-stablecoin-feature)
