# 【2026/11/28】きのうのビットコイン

## きのうのニュース

### ⚠️ Nvidia製チップの中国発見報道、BTCは6万ドル割れ

Protosによると、ビットコインが6万ドルを割り込みました。きっかけとして挙げられたのは、Nvidiaの最新チップ「Blackwell」が中国のデータセンターで見つかったという報道です。このデータセンターは、同社CEOのジェンスン・フアン氏が不倫関係にあったとされる女性の一人と関係があると伝えられています。この報道で米ハイテク株をめぐる不安が広がり、ビットコインの相場にも及んだとみられます。ビットコインが株式市場、とりわけ半導体や人工知能の関連銘柄の材料に左右されやすくなっていることを示す一件です。

[出典: Protos](https://protos.com/bitcoin-falls-below-60000-after-nvidia-chips-found-in-china/)

### 📈 70億ドルのBTCオプション満期、4万ドルへの備えも

Decryptによると、約70億ドル分のビットコインのオプションが満期を迎えました。今月で最大の満期です。トレーダーの間ではこれ以上の下落に備える動きが強まっており、年末までに4万ドルまで下がる場合に備えたヘッジも出ているといいます。大きな満期の前後は値動きが荒くなりやすいとされます。また、下落に備えるオプションの需要が高いことは、市場参加者の多くがまだ底打ちを確信していないことを表しています。今後の値動きを読むうえで、市場の構えが分かる材料になります。

[出典: Decrypt](https://decrypt.co/384154/7-billion-bitcoin-options-just-expired-what-it-means)

### 📈 K33「AIはまだビットコインの暗号を破れない」

人工知能の助けを借りて書かれたリーマン予想の証明の草稿が出回り、ビットコインの安全性を支える数学が崩れるのではないかという懸念が再び持ち上がりました。これに対し、調査会社K33は、暗号が実際に破られた例はまだ示されていないとの見解を出しました。Decryptが伝えています。人工知能の急速な進歩が、ビットコインの署名や暗号の土台を脅かすのではないかという不安は、繰り返し話題になります。専門の調査会社が「現時点では破られていない」と線を引いた点が、この話の要です。

[出典: Decrypt](https://decrypt.co/384218/could-ai-break-bitcoin-not-yet-research-firm-k33-says)

### 🏛️ ロシアVTBがBTC取引開始、中銀は知識テスト承認

ロシアの大手銀行VTBが金曜日、適格投資家を対象に、自社アプリでビットコインの売買を始めました。その前日には、ロシア中央銀行が、暗号資産を買う人全員に受験を義務づける知識テストを承認しています。SPB取引所も現物取引を始める計画を示しています。ロシアでは、中央銀行の枠組みのもとで大手銀行や取引所がビットコインの取引を扱い始めた形です。国が管理する経路を通じて個人投資家の参入が進む段階に入ったことを示す動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/russia-vtb-bitcoin-trading-crypto-test)

### 🇪🇺 スペイン、令状なしで暗号資産口座を凍結可能に

スペインで王令が出され、同国の金融情報機関Sepblacが、裁判所の命令なしに暗号資産・銀行・決済の口座を最長5営業日凍結できるようになりました。資金洗浄対策の名目で、司法の審査を経ずに行政機関が個人の資産を一時的に動かせなくする権限です。暗号資産の口座が銀行口座と同じ枠で扱われた点も目を引きます。取引所に資産を預ける利用者にとって、自分で鍵を管理することの意味が改めて問われる制度変更です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/spain-sepblac-freeze-crypto-accounts)

### 🚨 Binance、63億ドル流出から1か月で出金停止を全面解除

Binanceは、10月29日に起きた63億ドル規模のハッキングを受けて続けていた出金停止を、全面的に解除したと発表しました。出金の復旧作業が完了したためです。一方、研究者らは、盗まれた資金を北朝鮮の資金洗浄役が動かしている様子を追跡しています。世界最大級の取引所で起きた大規模な流出から約1か月で、利用者の出金がようやく元に戻ったことになります。ただし盗まれた資金の行方は追跡が続いており、事件はまだ終わっていません。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/binance-lifts-withdrawal-suspension-hack)

### ⚡ 旧版Bitcoin Coreに脆弱性、CLNのDoSも開示

Bitcoin Optechのニュースレター第433号が公開されました。今号は、Bitcoin Coreの古いバージョンに影響する脆弱性と、Lightningの実装の一つであるCore Lightningで見つかったサービス妨害（DoS）の脆弱性の開示を取り上げています。あわせて、BIPの編集者チームを入れ替えるかどうかの議論も紹介しています。古いバージョンのノードを動かし続けている運用者にとっては、更新を検討するきっかけになります。BIPの管理体制をめぐる議論は、プロトコル改善の進め方そのものに関わる話です。

[出典: Bitcoin Optech](https://bitcoinops.org/en/newsletters/2026/11/27/)

### ⚡ 量子耐性署名を見据え、Coreのスタック処理改善案

開発者のconduition氏がDelving Bitcoinに投稿し、自ら出したBitcoin Coreへの変更提案（PR #36721）について説明しました。スクリプトを実行するときにスタックへ積む要素を、参照カウント付きのオブジェクトとして持たせる内容です。大きなスタック要素を効率よく扱うための最適化の第一歩と位置づけています。主な動機は、量子耐性（PQ）署名への対応です。量子耐性署名はいまの署名よりデータがずっと大きいため、将来の導入に向けた下準備として注目されます。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/handling-pq-signatures-on-the-stack/3128)
