# 【2026/11/21】きのうのビットコイン

## きのうのニュース

### ⚠️ ベッセント財務長官、FRBの大幅利上げに異論

米国のスコット・ベッセント財務長官が、FRBに対して大幅な利上げを採らないよう求めました。シティや市場参加者は、12月に0.25ポイントの利上げがあるとの見方を変えていません。発言が出たのは、ビットコインが6万ドルを割り込んだ時期と重なります。財務長官が中央銀行の利上げ幅に公の場で注文を付けるのは珍しいことです。金融引き締めの強さは、ビットコインを含むリスク資産全体の資金の流れを左右します。12月の会合でFRBがどこまで引き締めるのかに、改めて注目が集まっています。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bessent-fed-bigger-rate-hike-bitcoin)

### ⚠️ Anthropic上場後にAI株が急落、暗号資産にも波及

Claude を開発する Anthropic がナスダックに上場した直後、AI関連株が大きく売られました。Decrypt によると、この売りに押されて暗号資産市場の心理は急速に冷え込み、ビットコインは金曜日に6万ドルを割り込みました。TFTC は、上場から24時間もたたずに「噂で買って事実で売る」展開になったと伝えています。売りは半導体、銅、世界の株価指数にも広がり、2020年3月のコロナ急落以来で最悪の週になりました。AI相場の巻き戻しが、ビットコインにも重しとしてのしかかっています。

[出典: Decrypt](https://decrypt.co/383702/bitcoin-breaks-below-60k-crypto-fear-greed-index-lowest)

### 🏦 IBIT、1日の流出額が過去最大の5.4億ドル

11月19日、BlackRock のビットコイン現物ETF「IBIT」から、1日としては過去最大となる5億4110万ドルが流出しました。同じ日の米国の現物ビットコインETF全体の流出額は5億8230万ドルで、その大半を IBIT が占めたことになります。一方、香港に上場している MSTR の逆連動商品は、11月の上昇率が120%を超えました。ETFが機関投資家をビットコインへ呼び込む入り口になる、という見立てが本格的に試されています。

[出典: TFTC](https://www.tftc.io/ibit-record-541m-outflow-bitcoin-etf-november-2026)

### 🏢 セイラー氏、STRC縮小へ　ビットコイン売却にも言及

Strategy のマイケル・セイラー氏は11月19日、投資家向けの説明で優先株 STRC の配当を12%に据え置くと述べました。あわせて、自社買いで STRC の流通量を50億ドル規模まで減らす方針を示しました。MSTR の株価が自身の mNAV 基準を下回る場合は、買い戻しの資金をビットコインの売却で賄う可能性にも触れています。ビットコインの価格は Strategy の平均取得価格を下回っています。買い増しを続けてきた最大の保有企業が売却の可能性を口にしたことは、市場の需給を考えるうえで見逃せません。

[出典: TFTC](https://www.tftc.io/strategy-strc-5-billion-saylor-sell-bitcoin-buybacks)

### 🏢 Block初の決済報告、Squareのビットコイン決済は中央値13ドル

Block が、Square でのビットコイン決済について初めての報告書を出しました。決済額の中央値は約13ドルで、72%が飲食店での支払いでした。TFTC によると、少額の買い物、繰り返し使う顧客、外部ウォレットからの支払いが目立っています。Block はこの結果をもとに、少額決済を課税対象から外す免除措置を議会に求めています。ビットコインがコーヒーや食事のような日常の支払いに使われていることを、実際の決済データで示した点が重要です。税務処理の手間が普及を妨げているという主張の根拠にもなります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/block-square-bitcoin-payments-report)

### ⛏️ Canaan、Avalon Nano 3sのファームウェアをオープンソース化

マイニング機器メーカーの Canaan が、Avalon Nano 3s のファームウェアを MIT ライセンスで公開しました。A3197S チップのドライバまで含み、自分でビルドできる完全な形です。256 Foundation は、この公開でできるようになることを解説し、他の機器メーカーも続いてほしいと呼びかけています。ASIC メーカーが自社機のファームウェアをここまで開くのは珍しいことです。ハードウェアの中身を検証して改良できるようになれば、マイニング機器が特定メーカーの方針に縛られにくくなり、分散化の後押しになります。

[出典: 256foundation.substack.com](https://256foundation.substack.com/p/an-asic-maker-just-open-sourced-oem)

### 🚨 到達可能ノードの59%、10月のCore修正が未適用

schmidty 氏が、Bitcoin Core のセキュリティ勧告と Bitnodes の当日のノード一覧を突き合わせました。その結果、外部から到達できるノードの59%にあたる約1万2800台が、10月27日に公開された修正を適用していませんでした。この修正は、他のノードからメモリを使い果たさせられる2件の不具合を直すものです。bitcoin-dev メーリングリストには「容易に見つかる脆弱性」についての勧告も投稿され、Bitcoin Core v30.5 と v31.3 が公開されました。多くのノードが古い版のまま動いていることで、ネットワーク全体の守りの弱さが浮かび上がっています。

[出典: x.com](https://x.com/bitschmidty/status/2123828842993213912)

### ⚡ Blockstream、耐量子署名SHRINCSの安全性分析を公開

Blockstream の研究者が、ビットコイン向けの耐量子署名方式 SHRINCS について、131ページの安全性分析を公開しました。SHRINCS はハッシュ関数をもとにした署名方式で、研究者たちはコミュニティに欠陥がないか検証するよう呼びかけています。Delving Bitcoin でも、量子計算機が実現したときに、移行が済んでいないコインを救う枠組みが議論されています。IOSCO も、量子技術がもたらすリスクについて特別報告書を出しました。耐量子化の議論は、仕様案の段階から第三者による検証の段階へ進みつつあります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/blockstream-shrincs-security-shrincs)
