# 【2026/09/17】きのうのビットコイン

## きのうのニュース

### ⚠️ FRB利上げでビットコイン動揺、週間では下落

米連邦準備制度理事会（FRB）が利上げを決めた直後、ビットコイン価格は一時揺れたものの、その後は落ち着きを取り戻しました。Bitcoin Magazine によると、トレーダーが事前に中銀の利上げを織り込んで動いていたため、ビットコインは過去1週間で下落した状態にあります。利上げ自体はサプライズではなく、決定後の値動きも荒れずに収まった形ですが、週間で見れば軟調が続いています。金利上昇局面でビットコインが「利回りを持たない資産」としてどう評価されるかが改めて問われる場面であり、今後の資金の流れを見るうえで重要な節目です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/bitcoin-price-wobbles-after-rate-hike)

### ⚠️ 米20年債入札が1986年以来の最悪、ベセント発言直後

米財務省が実施した20年債の入札が、1986年以来で最も悪い結果に終わりました。Protos によると、Scott Bessent 財務長官が直前に2件の国債入札を「成功」と称賛してから、わずか数時間後の出来事でした。長期国債に対する需要の弱さが、米国の財政と債券市場への不安を改めて浮き彫りにしています。国債利回りの上昇はリスク資産全般の逆風となる一方、ドル建て債務への不信が強まる局面ではビットコインが代替資産として語られやすく、マクロ環境がビットコイン相場に及ぼす影響を測るうえで注目される材料です。

[出典: Protos](https://protos.com/us-20-year-bond-auction-just-had-its-worst-showing-ever/)

### 🇺🇸 上院でCLARITY法案の審議入り否決、米暗号資産立法に打撃

米上院は9月15日午後3時（東部時間）、デジタル資産市場の構造を定める H.R. 3633「Digital Asset Market Clarity Act」（CLARITY 法案）について、審議入りの動議に対するクローチャー（討論終結）の点呼投票を行い、これが否決されました。Wu Blockchain によると、投票は上院の日次発表では午後2時18分ごろに始まっています。同法案は下院を通過した後、上院での扱いが焦点となっていましたが、今回の否決で米国の暗号資産立法は大きな後退を強いられる形です。市場構造法の成立を前提に動いていた業界にとって、規制の空白が長引く可能性が高まりました。

[出典: Wu Blockchain](https://wublock.substack.com/p/clarity-act-fails-in-the-senate-a)

### 🇺🇸 CFTC委員長、法案否決受け独自に暗号資産規則を策定へ

米商品先物取引委員会（CFTC）の Mike Selig 委員長は、CLARITY 法案の上院での採決が失敗したことを受け、CFTC が自ら暗号資産に関する規則を策定する方針を示しました。Bitcoin Magazine によると、Selig 氏はトランプ大統領と協力して暗号資産の規則整備を前進させるとしています。議会による立法が頓挫したことで、規制当局が自らの権限で市場のルールを整える動きに重心が移ることになります。法律ではなく規則による整備は、政権交代や訴訟で覆されやすい面もあり、業界が求めてきた「恒久的な明確さ」とは異なる道筋となります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/cftc-chair-will-write-rules-clarity-fail)

### 🏛️ 戦略的ビットコイン準備金、議会の法案は「存在せず」と扱う

The Rage は、この日マークアップ（委員会での条文審査）に付された法案の内容から、米議会が戦略的ビットコイン準備金（Strategic Bitcoin Reserve）を事実上「存在しないもの」として扱っていると指摘しました。大統領令で創設が宣言されたものの、議会側の立法作業ではその存在が前提とされていないという読みです。準備金は政府が保有するビットコインの位置づけを大きく変える構想として注目されてきましたが、法的裏付けや実際の積み増しが伴っているのかは以前から疑問視されており、今回の法案の扱いはその疑念を強める材料となっています。

[出典: The Rage](https://www.therage.co/the-strategic-reserve-of-fugazi/)

### 🏦 ドイツ銀行、機関投資家向けビットコイン保管サービス開始へ

ドイツ銀行が、機関投資家向けのビットコイン・カストディ（保管）サービスを開始する見通しです。Bitcoin Magazine の Mathew Di Salvo 記者によると、同行はビットコインの保管ソリューションに取り組む大手銀行として最新の事例となります。欧州最大級の銀行が機関投資家にビットコインの保管を提供することは、伝統的な金融機関がビットコインを扱うことへの心理的な垣根が下がっていることを示します。大手行が相次いで保管業務に参入することで、機関投資家が既存の取引銀行を通じてビットコインを保有できる環境が整いつつあります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/deutsche-bank-to-debut-bitcoin-custody)

### 🏢 Strategy の STRC、額面割れから4カ月経ても100ドル回復せず

Strategy（旧 MicroStrategy）が発行する優先株 STRC が額面の100ドルを割り込んでから4カ月が経ちましたが、依然として100ドルへの回復（パリティ）を達成できていません。Protos によると、同社の経営陣は STRC を100ドルの目安に戻すことを最優先課題に掲げてきました。STRC は同社がビットコイン購入資金を調達する手段のひとつであり、額面割れが続けば新規発行による資金調達の魅力が薄れます。ビットコインを大量保有する企業の資金調達モデルがどこまで持続するかを測るうえで、STRC の価格は重要な指標となっています。

[出典: Protos](https://protos.com/strategy-still-cant-get-strc-back-to-parity/)

### ⛏️ エチオピア、干ばつでマイナー電力を契約量の23%に削減

エチオピアの国営電力会社 Ethiopian Electric Power が、ビットコインのマイナーへの電力供給を契約量の23%まで削減しました。TFTC によると、エルニーニョ現象の影響で貯水池への流入量が少なくとも20%減少したことが原因です。同国は豊富な水力発電を背景にマイニング拠点として注目されてきましたが、今回の措置は国家の水力発電をマイニングのエネルギー基盤とすることの構造的な脆弱さを露呈しました。気候要因で供給が急減する地域に依存するマイナーにとって、電力の安定性が事業の前提を左右することを示す事例です。

[出典: TFTC](https://www.tftc.io/ethiopia-bitcoin-mining-power-cut-drought-2026)
