# 【2026/09/06】きのうのビットコイン

## きのうのニュース

### ⚠️ ステーブルコインは新ペトロダラー、Every氏が主張

マクロストラテジストの Michael Every 氏が TFTC の番組に出演し、ステーブルコインは暗号資産の話ではなく、米国がペトロダラーの後継を狙う一手だと論じました。番組では中国が実際に握っているレバレッジ、イラン情勢の一時停止、そして米国がいま通そうとしている針の穴がほとんど不可能なほど細いことも扱われています。ドル基軸の維持にステーブルコインが組み込まれるという見方は、ビットコインを取り巻く通貨秩序の議論に直接つながる論点です。

[出典: TFTC](https://www.tftc.io/stablecoins-replacing-petrodollar-michael-every)

### 📈 Tone Vays氏「ドルは2030年までに基軸通貨の座失う」

アナリストの Tone Vays 氏が Bitcoin Club Malta の招きで単独インタビューに応じ、ドルが2030年までに世界の準備通貨としての地位を失う可能性を語りました。地政学と経済が絡む情勢の変化、ドルの地位、そしてビットコインとの対比が主題です。基軸通貨の行方はビットコインの長期的な位置づけを左右する論点で、前項の Every 氏の議論と合わせて読むと、ドル体制の先行きをめぐる見方の幅が分かります。動画は YouTube で公開されています。

[出典: youtube.com](https://www.youtube.com/watch?v=PmpoG0SH7SE)

### 🇺🇸 Geyser、制裁順守でCuba Bitcoinの募金を拒否

ビットコインのクラウドファンディング基盤 Geyser が、米国の制裁順守を理由に Cuba Bitcoin の資金調達の取り組みを拒否しました。TFTC は、この一件が「ノンカストディアル（顧客資産を預からない）」と「本当に許可不要（パーミッションレス）」の間にある決定的な溝を露わにしたと指摘します。資金を預からない設計でも、運営者が米国法の対象である限り OFAC の制裁対象国のコミュニティは排除され得るということで、金融から排除された人々にこそ届くはずのインフラの限界を示す事例です。

[出典: TFTC](https://www.tftc.io/geyser-cuba-bitcoin-ofac-sanctions-non-custodial-permissionless)

### ⛏️ Hyperscale Data、ミシガンのBTC採掘を停止しAIへ転換

NYSE 上場の Hyperscale Data（GPUS）が、2026年9月1日にミシガン州 Dowagiac のキャンパスにあるビットコインマイナーをすべて停止し、61万7000平方フィートの敷地を12億ドル規模の AI コロケーション契約へ転換しました。TFTC は、この動きが AI 向け設備投資によってどのマイナーが最初に押し出されるかを示す事例だと見ています。電力と敷地を持つマイニング拠点が AI 需要に置き換わる流れが、部分的な併用ではなく全面停止という形で現れた一件です。

[出典: TFTC](https://www.tftc.io/hyperscale-data-bitcoin-mining-shutdown-dowagiac-ai-data-center)

### ⚡ Utreexo IBDの暗黙削除と改善案、Delvingで議論

Delving Bitcoin に、Utreexo の初期ブロックダウンロード（IBD）における暗黙的な削除と改善に関する投稿が出ました。Utreexo は全 TXO 集合をわずか数個のハッシュで表現できる動的アキュムレータで、データを完全な Merkle 木の森として構造化し、ノードは上部だけを保持すればよいため必要なハッシュ数は O(log n) で済みます。ビットコインでは n が TXO の総数に当たり、その規模をどう扱うかが同期の効率を決めます。フルノードの軽量化に関わるプロトコル開発の議論です。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/implicit-deletions-and-improvements-in-utreexo-ibd/2881)

### ⚡ Rust製の自己ホスト型Spark事業者「open-ssp」公開

開発者の benthecarman 氏が、Rust で書かれた自己ホスト型の Spark Service Provider「open-ssp」を GitHub で公開しました。Spark のサービスプロバイダーを自分のサーバーで動かせる実装で、特定の事業者に依存せずに Spark のサービス提供側を担えるようにするものです。リポジトリの説明はこの一文にとどまり、対応機能や開発段階の詳細は示されていませんが、ビットコイン周辺の基盤ソフトウェアがオープンソースで自前運用できる形で出てきた点が注目点です。

[出典: github.com](https://github.com/benthecarman/open-ssp)
