# 【2026/11/26】きのうのビットコイン

## きのうのニュース

### ⚠️ 物価・関税・AI株安が重なりBTC一時5.8万ドル割れ

ビットコインの価格が5万8,000ドルを下回る場面がありました。Decryptは背景として、米国経済の成長の強まり、インフレの加速、トランプ関税の新たな提案に、AI関連株の売り再燃が重なったことを挙げています。市場では12月以降の金利上昇を見込む取引も出ています。重要なのは、下落の要因が暗号資産業界の内部ではなく、マクロ経済と株式市場の側に並んでいる点です。景気の強さは通常なら好材料ですが、物価の加速と同時に示されると金利の先高観につながり、利息を生まないビットコインには逆風になりやすくなります。関税案と12月の金融政策の行方が当面の焦点です。

[出典: Decrypt](https://decrypt.co/383967/bitcoin-sinks-inflation-trump-tariffs-ai-selloff)

### 🏛️ 戦略的ビットコイン準備金法案、下院委を通過し本会議へ

米下院の委員会が、ニック・ベギッチ議員の戦略的ビットコイン準備金法案を通過させ、法案は下院本会議で採決できる段階に進みました。準備金を法律として定めるもので、保有するビットコインの売却を20年間禁じる内容を含みます。重要なのは、準備金の根拠が法律の形で固まるかどうかに直接関わる点です。法律に書き込まれれば、政権や担当者の判断だけで方針を変えることは難しくなり、20年の売却禁止は政府保有分が市場に出てくる可能性を長期にわたって抑える働きを持ちます。ただし、いまは本会議での採決が可能になった段階で、成立したわけではありません。採決の行方が次の焦点になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strategic-bitcoin-reserve-bill-house-floor)

### 🇪🇺 仏上院、10万ユーロ以上の自己管理ウォレット申告を否決

フランス上院が、10万ユーロ以上の自己管理型ウォレットについて、ビットコインの保有者に申告を義務づける規定を否決しました。あわせて、ステーブルコインに関する措置と出国税に関する措置も退けています。自己管理型ウォレットは、取引所などの業者に預けず、利用者が自分で秘密鍵を管理する仕組みです。申告が義務になると、誰がどれだけ持っているかという情報が行政に集まるため、プライバシーと、情報が漏れた場合の安全の両面で影響が大きくなります。今回の否決は、自分で鍵を管理する保有者の負担を広げる動きに上院が歯止めをかけた形です。上院としての判断であり、最終的な扱いとは分けて見る必要があります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/france-senate-rejects-self-custody)

### 🇪🇺 ウクライナ議会、暗号資産の合法化・課税法案を可決

ウクライナの議会が、暗号資産の取引を合法化し、課税の枠組みを定める法案を可決しました。Decryptによると2027年7月からの適用で、利益には18%の税に加えて5%の軍事税がかかります。以前から保有する資産には税率の軽減があり、ステーブルコインは中央銀行の管轄に置かれます。Protosは、年間3億3,000万ドルの税収につながると伝えています。重要なのは、取引の合法化と税のルールが同じ法律で示された点です。事業者と利用者にとっては、適用開始までに何を準備すべきかが見えやすくなります。国の側から見れば取引を税収に結びつける仕組みであり、軍事税の上乗せが特徴です。

[出典: Decrypt](https://decrypt.co/383962/ukraine-passes-law-to-legalize-and-tax-its-crypto-market-from-july-2027)

### ⛏️ CleanSpark、採掘量を上回るBTC売却を検討

米マイニング企業のCleanSparkが、採掘した量を上回るビットコインの売却を検討しています。同社の最高財務責任者が、2026会計年度に9億8,710万ドルの損失を計上したことを受け、リスクを減らすために採掘量を超えて売る可能性があると述べました。株価は52週安値を更新しています。重要なのは、採掘量を超える売却が、手元に積み上げてきた保有分の取り崩しを意味する点です。採掘した分を売って費用に充てるだけなら保有量は減りませんが、それを超えれば保有量そのものが減っていきます。価格の下落局面で、採掘企業が保有を続ける方針と財務の健全さのどちらを優先するかを示す事例になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/cleanspark-987-million-loss-fiscal-2026)

### ⛏️ Braiins、採掘報酬を横取りする経路乗っ取り攻撃を報告

マイニング企業のBraiinsが、採掘の計算力を乗っ取り、報酬の行き先を付け替える攻撃を報告しました。同社によると、攻撃者は暗号化されていない通信規格Stratum V1の弱点と、インターネットの経路の乗っ取りを組み合わせ、マイニングプールになりすましました。わずか1秒の間に1,000を超える拠点が狙われたとしています。同様の攻撃への注意喚起は、別の採掘企業に続くものです。重要なのは、採掘機そのものに侵入しなくても、通信の途中で接続先を偽れば報酬を奪えてしまう点です。広い範囲の拠点が同時に影響を受けうるため、採掘事業者とプールには通信の暗号化と接続先の確認が課題になります。

[出典: Decrypt](https://decrypt.co/383999/another-bitcoin-mining-firm-hashrate-hijacking-attacks)

### 🚨 バイナンス両CEO、63.4億ドル流出の経緯と対応を説明

バイナンスの共同CEOであるイー・ホー氏とリチャード・テン氏が、最高セキュリティ責任者のジミー・シュー氏とともに公開の音声配信に登場し、10月30日に起きた大規模な侵害について説明しました。Wu Blockchainがその内容を伝えています。被害額は63億4,000万ドルとされ、偽の採用面接、ウォレットを突いた攻撃、資産の回収に向けた取り組みが話題に上りました。重要なのは、被害の大きさに加えて、偽の面接という人を狙う手口が論点に挙がった点です。システムの防御を固めても、働く人への接触が侵入の糸口になりうることを示しており、顧客資産を預かるほかの取引所にとっても対策を見直す材料になります。

[出典: Wu Blockchain](https://wublock.substack.com/p/binance-co-ceos-address-634b-hack)

### ⚡ ウォレットの再送信からIPとアドレスを紐付ける手法

開発者向け掲示板のDelving Bitcoinに、ウォレットが取引を再送信する動作を利用し、ビットコインのアドレスとノードのIPアドレスなどを結びつける手法についての投稿が載りました。投稿によると、取引の発信元を推定することは可能ですが、確率的なものにとどまります。Bitcoin Coreは取引を知らせる間隔を、外向きの接続先には約2秒、内向きの接続元には共通の約5秒のタイマーで管理しており、観測者が得るのは雑音を含む推測です。重要なのは、題名が示すように、再送信という通常の動作がその推測の手がかりになりうる点です。自分でノードを動かす利用者のプライバシーに直接関わる論点です。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/exploiting-wallet-rebroadcast-to-link-addresses-to-node-ips-and-more/3123)
