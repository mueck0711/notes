# 【2026/11/01】きのうのビットコイン

## きのうのニュース

### 📈 Log Scale CEO、次の強気相場でMSTR「大幅上振れ」

Bitcoin Magazineの番組に、Log ScaleのCEOであるMike Flaum氏が出演しました。氏は、次のビットコイン強気相場ではStrategy（MSTR）の値動きが「大幅に」上振れするとの見方を示しています。番組では、Strategyの優先株Stretch、日々支払われる配当、退職者にとってのビットコイン連動の優先株と米国債の比較も話題になりました。値動きの大きさと本当のリスクを分けて考えるべきだ、というのが氏の主張です。ビットコインを裏付けにした金融商品を、利回り目当ての投資家にどう位置づけるかという議論が広がっていることがうかがえます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/videos/mike-flaum-mstr-performance-massively-to-the-upside-during-next-btc-bull-run)

### 🏢 Strategy決算説明会、STRCや優先株で質疑

Strategy（MSTR）が2026年第3四半期の決算説明会を開き、アナリストとの質疑応答をBitcoin Magazineが伝えました。Michael Saylor氏とPhong Le氏が、同社の掲げる「デジタル・クレジット」、優先株Stretch（STRC）を額面近くに保つ方針、優先株全般、ビットコインの金融商品化について質問に答えています。Strategyは保有するビットコインを裏付けに優先株を出して資金を集め、さらに買い増す手法を続けています。今回の質疑は、その資金調達の仕組みが今後も回るのかを市場が見極める材料になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/videos/mstr-q3-2026-earnings-call-analyst-qa)

### 🚨 バイナンスで63億ドル流出、30億ドルを凍結

世界最大の暗号資産取引所バイナンスで約63億ドルが盗まれ、うち約30億ドルを凍結したとWu Blockchainが報じました。バイナンスの初期調査では、開発運用を担うエンジニアのコンピューターが侵害され、そこが侵入口になった疑いが浮かびました。その後ほかの侵入点も見つかり、同社は複数の要因が重なったと説明しています。攻撃経路の全容はまだ分かっていません。Decryptは北朝鮮との関連を伝え、Bitcoin Magazineは未回収額を33億ドルとしています。暗号資産の歴史でも最大級の盗難で、取引所に資産を預けることのリスクと、取引所の運用体制があらためて問われています。

[出典: Wu Blockchain](https://wublock.substack.com/p/binance-hit-by-63-billion-theft-3)

### 🚨 Linuxカーネルに重大脆弱性、ノード運用者に更新呼びかけ

Linuxサーバーやノード、リレーを運用する人に向けて、Linuxカーネルの重大な脆弱性CVE-2026-98432への注意を促す投稿がStacker Newsで共有されました。深刻度はCVSS 9.8です。細工したTCPパケットを送られるだけで、ログインなしにネット越しで機械を乗っ取られるおそれがあるといいます。投稿によると、UbuntuとRed Hatはまだ修正版のカーネルを出しておらず、Debian、SUSE、Oracle、Amazonは対応を進めています。ビットコインのノードを自前で動かす人に直接関わる話で、使っているディストリビューションの更新状況を確かめる必要があります。

[出典: primal.net](https://primal.net/e/nevent1qqsxq6exy862gs9m59yf95mw30t6ravj9eekau2k06d4czv27cx7hnszr662z)

### ⚡ BIP54のタイムワープ修正、前方ブロック案の欠陥を議論

ビットコイン開発者のメーリングリストbitcoin-devに、BIP54をめぐる新しいスレッドが立ちました。題は「タイムワープの修正と、前方ブロック案の（不）健全性について」です。タイムワープは、ブロックの時刻を操作して採掘難易度の調整をゆがめる手口のことで、BIP54はその修正を含む提案です。今回の投稿は、別のアプローチである「前方ブロック」案には健全性の面で問題があると論じています。ソフトフォークの中身をどう設計するかの議論が、いまも続いていることを示しています。

[出典: bitcoin-dev](https://gnusha.org/pi/bitcoindev/CALZpt+EL_JwYP7iFFWCeVihVV5in7aBOVSc9WcEP6A+DYUALzQ@mail.gmail.com/)

### ⚡ Lexe、静的サイトからLightningチップ受付可能に

LightningウォレットのLexeが、どんな静的サイトからでも自分のLexeウォレットへLightningのチップを受け取れる方法を公開し、Stacker Newsで紹介されました。公式ドキュメントでは、サイトに埋め込める支払いウィジェットとして案内されています。サーバー側の処理を持たない個人ブログや作品サイトでも、ページにウィジェットを置くだけでビットコインの少額送金を受け取れるのが利点です。Lightningを使った投げ銭の入り口を広げる取り組みといえます。

[出典: docs.lexe.tech](https://docs.lexe.tech/platforms/static-sites/#embeddable-payment-widget)
