# 【2026/10/01】きのうのビットコイン

## きのうのニュース

### ⚠️ 米8月PCE物価が予想下振れ、BTCは8.5万ドル超え

米国の8月の個人消費支出（PCE）物価指数が市場予想を下回り、これを受けてビットコイン価格は8万5,000ドルを上回りました。ただし Bitcoin Magazine は、上昇は「わずか」だったと伝えています。物価の鈍化を示すデータが出ても、価格の反応は小幅にとどまったということです。米国の物価指標がビットコインの値動きのきっかけになっている一方で、その効き方は限られていることがうかがえます。相場が材料をどの程度織り込みにいくのかを見るうえで、今後の米国の経済指標の発表が一つの手がかりになりそうです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/bitcoin-price-jumps-on-inflation-data)

### ⚠️ 原油高と米国債売り、ホルムズ膠着が暗号資産の逆風に

デリバティブ分析の BlockScholes が Deribit Insights に寄せた第40週の週次リポートは、暗号資産を含むリスク資産が悪化するマクロ環境のなかで取引されていると指摘しました。挙げられた要因は、原油価格の上昇、ホルムズ海峡をめぐる米国とイランの膠着の長期化、そして米国債の売りの深まりの3つです。いずれもビットコイン固有の材料ではありませんが、リスク資産全体の地合いを左右する外部要因として、暗号資産市場にも重くのしかかっています。エネルギー価格と金利の動きが今後の相場の前提になることを示す内容です。

[出典: Deribit Insights](https://insights.deribit.com/industry/crypto-derivatives-analytics-report-week-40-2026/)

### 🇺🇸 OFAC、ATM不正引き出し網の暗号資産洗浄役らを制裁

米財務省外国資産管理局（OFAC）は、ベネズエラの犯罪組織 Tren de Aragua が関わる ATM の不正引き出し事件をめぐり、計10の対象を制裁指定しました。この手口では少なくとも4,073万ドルが盗まれ、その資金の洗浄に暗号資産が使われていたとされます。指定には、この洗浄に関わった逃亡中の人物も含まれています。Chainalysis が報じたもので、暗号資産が組織犯罪の資金の流れに組み込まれている実態と、米当局がその経路を狙い撃ちにする姿勢をあらためて示しました。業界にとっては、規制強化の論拠として使われうる事例でもあります。

[出典: Chainalysis](https://www.chainalysis.com/blog/ofac-sanctions-tren-de-aragua-crypto-laundering-september-2026/)

### 🇪🇺 英FCA、暗号資産業者の申請受付を開始 初の全面監督へ

英国の金融行動監視機構（FCA）が、暗号資産企業からの申請の受け付けを始めました。来年施行される新しい規制の枠組みに先立つ手続きで、英国で暗号資産が初めて FCA の全面的な監督下に置かれることになります。Bitcoin Magazine が報じました。これまで限られた範囲でしか規制されていなかった英国の暗号資産事業者にとって、事業を続けるための許認可の取得が必須になる転換点です。欧州の主要な金融市場の一つである英国がルールを固めることで、事業者の拠点選びや、英国の利用者が使えるサービスの顔ぶれにも影響が出そうです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/uk-brings-crypto-under-fca-oversight)

### 🇪🇺 オランダ、2028年から譲渡益課税 ビットコインも対象か

オランダ政府が、2028年から主要な資産に対してキャピタルゲイン課税（譲渡益課税）を導入する計画を示しました。Bitcoin Magazine によると、ビットコインもこの課税の対象に含まれる可能性があります。導入まではまだ時間がありますが、対象となればオランダの保有者は売却益に応じた税負担を意識した運用を迫られます。どの資産を対象とするかの詳細が今後の焦点で、欧州の一国の税制がビットコインをどう位置づけるかという点でも注目される動きです。他の欧州諸国の税制議論に波及するかどうかも見どころになります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/dutch-government-introduce-capital-gains)

### 🏢 Unbank、BTCPay Server財団へ2.5万ドル相当のBTC助成

現金取引を軸とするビットコイン交換業者で、ビットコイン ATM の網を広げている Unbank が、BTCPay Server Foundation に2万5,000ドルの助成金を贈りました。助成金はビットコインで直接支払われています。lightning.news が報じました。BTCPay Server は事業者が自らビットコイン決済を受け付けるためのオープンソースのソフトウェアで、その開発を支える財団への資金提供です。ATM や交換業で収益を得る企業が、決済の基盤となる開発に資金を還元する動きの一つで、オープンソース開発の持続性という点でも意味のある事例です。

[出典: lightning.news](https://lightning.news/unbank-awards-25000-to-btcpay-server-foundation/)

### 🚨 ColdCardハックは「始まりにすぎない」、2カ月の総括

TFTC の番組で Marty 氏と Erin Redwing 氏が、ハードウェアウォレット ColdCard のハック事件を振り返りました。Marty 氏はこの事件を、見出しの誇張ではなく自身の言葉として「恐ろしい」と表現しています。対談では、この2カ月で明らかになったビットコインの文化的な盲点、人工知能がもたらす新たな攻撃の入り口、効果的利他主義（EA）による規制の取り込みの動きまでを総括しました。自己保管の要であるハードウェアウォレットの事故が、技術面だけでなくコミュニティの前提そのものを問い直す契機になっていることを示す議論です。

[出典: TFTC](https://www.tftc.io/coldcard-hack-entropy-bug-bitcoin-erin-redwing)

### ⚡ シールド型ビットコインとPIPEs、12の問答で論点整理

BTC++ Insider が、ビットコインのプライバシー向上に取り組む [[alloc] init] チームによる「シールド型ビットコイン」と PIPEs についての12の問答を公開しました。取り上げられているのは、この仕組みをめぐるよくある疑問、誤解、そして今後の研究課題です。取引の中身を秘匿するシールド型の送金は、ビットコインのプライバシーをめぐる議論のなかでも関心の高い分野です。構想が広く知られる前に誤解を整理しておく試みで、提案の実現性や残された課題を開発者やユーザーが検討するための出発点になる資料です。

[出典: insider.btcpp.dev](https://insider.btcpp.dev/p/shielded-bitcoin-and-pipes-facts)
