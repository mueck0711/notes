# 【2026/09/11】きのうのビットコイン

## きのうのニュース

### ⚠️ 米イラン戦闘の再燃でビットコイン下落、中東緊張再び

Bitcoin Magazine によると、中東で米国とイランの戦闘が再燃し、ビットコインは下げに転じました。記事（Mathew Di Salvo 記者）は、中東の緊張が再び高まったことでビットコインがつまずいたと伝えています。地政学リスクが表面化すると、ビットコインは他のリスク資産と同様に売られやすく、今回もその構図が繰り返された形です。相場の材料としては、米上院の CLARITY 法採決と並んで、中東情勢の行方が短期の値動きを左右する外部要因として意識される局面です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-drops-on-us-iran-fighting)

### 📈 Coinbase CEO「底は入った」2030年40万ドル予想を再表明

Coinbase の Brian Armstrong CEO が、CLARITY 法は可決されるとの見通しを示すとともに、ビットコインの底は入ったとの見方を語りました。Bitcoin Magazine によると、Armstrong 氏は2030年までにビットコインが40万ドルに達するのは現実的だとする自身の予想も改めて繰り返しています。米国最大級の暗号資産取引所のトップが、来週に採決を控える法案の成立と相場の底入れを同時に断言した発言で、規制の追い風と価格の先行きを結びつけて語る業界側の強気姿勢を示すものです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/bitcoin-bottom-is-in-says-brian-armstrong)

### 🇺🇸 上院共和党がCLARITY法修正案を配布、15日にクローチャー採決

上院共和党が、デジタル資産市場の構造を定める CLARITY 法（Digital Asset Market Clarity Act）の修正案を提示しました。TFTC によると、9月15日のクローチャー（討論打ち切り）採決を前にした動きで、可決の見込みは16%程度にとどまるとみられています。ただ、本当の焦点は本会議で自己保管（セルフカストディ）の保護と、非カストディ型の開発者を守るセーフハーバー条項が生き残るかどうかだと同記事は指摘しています。Bitcoin Magazine も、長く待たれた法案の新しい草案が上院共和党から配布されたと報じています。

[出典: TFTC](https://www.tftc.io/clarity-act-cloture-vote-september-15-senate-revised-bill)

### 🇺🇸 ベセント財務長官、上院にCLARITY法採決で賛成を強く要請

Scott Bessent 米財務長官が X 上で、9月15日に予定される CLARITY 法のクローチャー動議に賛成するよう上院議員に強く求めました。TFTC によると、Bessent 長官は反対票を投じることは敵対国に地歩を明け渡すことだと位置づけて可決を促しています。同記事は、この法案の本当の争点は第10307条にあるとしています。Bitcoin Magazine も、財務長官が上院に対して法案の可決を「強く要請」したと報じ、上院は来週、長く待たれた暗号資産の Clarity 法を採決する予定だと伝えています。

[出典: TFTC](https://www.tftc.io/clarity-act-cloture-vote-september-15-bessent-section-10307)

### 🏢 Nasdaq、Kraken親会社に1億ドル出資 トークン化基盤を構築

Nasdaq が Kraken の親会社に1億ドルを出資すると、Bloomberg の報道を引用して Bitcoin Magazine が伝えました。報道によれば、Kraken と Nasdaq の今回の取引は、トークン化のためのインフラ構築を後押しするものだとされています。米国の主要証券取引所が暗号資産取引所の親会社へ直接資本を入れる形で、伝統的な金融市場と暗号資産のインフラの接近が一段と進むことになります。株式などの資産をブロックチェーン上で扱うトークン化が、取引所間の提携の軸になっている点が注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/nasdaq-invests-in-kraken)

### 🚨 Trezor、Brevo経由の侵害でメールドメインを停止し調査へ

ハードウェアウォレット大手の Trezor が、メール配信サービス Brevo を経由した侵害により、同社のメールドメインにハッカーがアクセスできる状態にあったことを明らかにしました。Protos によると、Trezor は当該ドメインを既に停止し、調査を開始しています。同社にとっては今夏に続くセキュリティ事案で、Protos は「Trezor のハッキングの夏が続く」と表現しています。正規ドメインから届くメールは利用者の信頼を得やすいため、これを装ったフィッシングへの警戒が求められる事態です。

[出典: Protos](https://protos.com/trezors-summer-of-hacks-continues-with-brevo-email-breach/)

### 🐋 Liquidのハッカー交渉、OP_RETURN上で進行 3,998 BTCが焦点

Liquid で起きた 3,998 BTC をめぐる事件について、ハッカーとの交渉の経過をライブチャットのように表示するウェブアプリ「OP_RETURN Messenger」が Stacker News で共有されました。発端はコンセンサスのバグで、交渉はビットコインのトランザクションに埋め込める OP_RETURN のデータを使い、1件ずつやり取りされています。オンチェーンに残るメッセージを誰でも追える形にした試みで、事件の規模と、公開台帳の上で進む交渉という異例の構図を可視化するものです。交渉の行方は資金の返還にも関わるため、引き続き注視が必要です。

[出典: liquidsaga.miguelmedeiros.dev](https://liquidsaga.miguelmedeiros.dev/)

### ⚡ 中国研究チーム、BTC攻撃に必要な量子ビットを835に引き下げ

中国の研究チームが、ビットコインの楕円曲線暗号（secp256k1）を攻撃するのに必要な量子計算資源の新たな下限を示しました。TFTC によると、必要な論理量子ビット数は835で、3年前の2,124から大きく減っています。攻撃に要する資源の見積もりが下がることは、量子コンピュータの実機がまだ到達していないとしても、耐量子化の議論を前倒しさせる材料になります。ビットコインの署名方式の移行をどう進めるかは開発コミュニティで議論が続いており、今回の結果はその緊急度を測る指標の一つとして受け止められそうです。

[出典: TFTC](https://www.tftc.io/quantum-bitcoin-attack-835-logical-qubits-secp256k1)
