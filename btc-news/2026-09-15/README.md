# 【2026/09/15】きのうのビットコイン

## きのうのニュース

### 🏦 モルガン・スタンレー、6億ドル超の現物BTC ETPを解説

モルガン・スタンレーでデジタル資産部門を率いる Amy Oldenburg が、Bitcoin Magazine の Spencer Nichols によるインタビューに応じ、同社が扱う6億ドル超の現物ビットコイン ETP と、顧客向けポートフォリオモデルへの組み入れ方を説明しました。大手ウェルスマネジメントがビットコインを投資推奨の枠組みに正面から載せた経緯を、担当責任者自身の言葉でたどる内容です。運用会社の推奨リストに入るかどうかは、個人投資家の資金がビットコインに届く経路そのものを決めます。単発の銘柄選択ではなく資産配分の設計として語られている点に、この推奨の重みがあります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/videos/morgan-stanleys-bitcoin-investment-recommendation)

### 📈 FOMC前、レバレッジ勢がBTC先物の売り建て再構築

CFTC が公表した Traders in Financial Futures によると、9月8日までの週に、レバレッジドファンドは4つのビットコイン先物市場で合わせて約1,669 BTC のネットショートを積み増しました。見出しだけを読めば弱気筋の復活に見えますが、TFTC は内訳を追ったうえで、実態は現物と先物の価格差を取るベーシス取引が大半を占めると指摘しています。FOMC を控えた局面で建玉の中身をどう読むかは、そのまま相場観の差になります。売り建ての増加を下落方向への賭けと見るか、金利裁定の副産物と見るかで、同じ数字がまったく逆の意味を持つためです。

[出典: TFTC](https://www.tftc.io/bitcoin-futures-leveraged-funds-short-cftc-fed-basis-trade)

### 🇺🇸 トランプ氏、暗号資産の倫理規則強化を受け入れ

上院共和党が民主党側に最終提案を示し、Clarity Act は火曜の重要採決へ向かいます。修正は倫理規則、ソフトウェア開発者の保護、ステーブルコインの利回りの扱いという三つの論点に及び、トランプ大統領は自身に関わる倫理規則の強化を受け入れました。上院議員の Cynthia Lummis は、この合意が米国にとってこれまでで最も厳しい倫理改革をもたらしたと評価しています。市場構造を定める法案が上院を通るかどうかは、取引所やトークン発行者がどの規制当局の下で動くかを決めます。倫理条項が譲歩点になった経緯は、可決の現実味を測る材料になります。

[出典: Crypto in America](https://www.cryptoinamerica.com/p/trump-accepts-tougher-crypto-ethics)

### 🇺🇸 CLARITY法、開発者保護は民事限定で決着

CLARITY 法案の提出者が、BRCA に基づく保護を民事に限定する形でまとめたと説明しました。法案はこのまま上院の手続き採決へ進みます。ただし TFTC は、ソフトウェアの書き手をどこまで守るのかという開発者の論点はなお詰め切れておらず、手当てが必要だと指摘しています。保護が民事に限られるということは、刑事面での不確実性が残るということでもあります。コードを書いただけの開発者が事業者として扱われうるかどうかは、ビットコインのウォレットやノードの開発を米国内で続けられるかに直結する問題であり、法案の中でも実務への影響がいちばん深い部分です。

[出典: TFTC](https://www.tftc.io/clarity-act-brca-civil-only-developer-protections)

### 🏢 Strategy、自社株買いでBTC購入を再び見送り

ビットコイン財務会社の Strategy が、新規のビットコイン購入をまたも見送り、代わりに自社株買いを実施しました。購入を飛ばすのは今回が初めてではありません。株式などの発行で調達した資金をビットコインに換えるという同社の事業モデルは、株価が保有資産に対して割高であることを前提に回ってきました。その前提が薄れた局面で自社株買いを選んだということは、資金の使い道として自社株のほうが割安だと判断したことを意味します。市場で最大級の買い手が一歩引いている事実は、企業による買いを需給の下支えと見てきた向きにとって無視できません。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strategy-again-skips-bitcoin-buy)

### 🏢 Strive買い増し、保有2万5000BTCに到達

Strive が先週もビットコインを買い増し、保有量は 25,000 BTC に達しました。金額にすると 20億ドル近くになります。Strategy が購入を見送る一方で、別のビットコイン財務会社である Strive は積み増しを続けている形です。財務としてビットコインを持つ企業が増えるほど、市場の買い手は ETF だけではなくなります。ただし、こうした企業の買いは株式市場で資金を調達できることが前提であり、株価が下がれば調達も細ります。買い増しのペースが続くかどうかは、各社の資金調達環境がどこまで保たれているかを映す指標としても見ておく価値があります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/strive-buys-more-bitcoin)

### 🚨 スイスのBTC決済業者、侵害受けサーバー停止

非カストディアル型のビットコイン決済処理業者 Swiss Bitcoin Pay が月曜、データ侵害を受けてサーバーを一時的に停止したと発表しました。スイス・ヌーシャテルに拠点を置く同社は、何者かが社内システムへ侵入した可能性が高いとし、調査とインフラの保全を進めるあいだの予防措置だと説明しています。現時点では、顧客のメールアドレス、ビットコインアドレス、IBAN にアクセスされた可能性があるとしています。非カストディアルなので資金そのものは同社が預かっていませんが、メールアドレスとビットコインアドレスと銀行口座番号が結び付いた形で漏れれば、標的型のフィッシングや個人の特定につながります。

[出典: x.com](https://x.com/SwissBitcoinPay/status/2099473448162488618)

### ⚡ Bitcoin Core v32.0rc1、正式版は10月10日目標

Bitcoin Core の v32.0rc1 が 2026年9月14日にタグ付けされ、約4週間のテスト期間に入りました。正式リリースは 10月10日が予定されています。TFTC は、ノード運用者に対してドラフトのリリースノートを読み、正式タグが出る前に問題を報告するよう促しています。リリース候補の期間は、実際の運用環境でしか表に出ない不具合を洗い出すための時間です。Bitcoin Core はネットワークの合意を支える実装であり、正式版が出てから手当てするより、この4週間のうちに見つけるほうがはるかに安全に直せます。

[出典: TFTC](https://www.tftc.io/bitcoin-core-v32-0rc1-release-candidate-october-2026)
