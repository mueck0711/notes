### 🏦 JPMorgan、IBIT連動仕組み債をSECへ継続提出

JPMorgan Chase が、BlackRock の iShares Bitcoin Trust ETF（IBIT）に連動する仕組み債の書類を、米証券取引委員会（SEC）へ継続的に提出していると TFTC が報じました。様式は 424B2 で、提出は2025年から2026年にかけて一定の間隔で続いており、最新は10月2日付です。TFTC が注目するのは個々の書類の中身よりも、提出が繰り返されているという形そのものです。単発の試みにとどまらず、米大手銀行による IBIT 連動商品の提出が定例のように続いている点は、機関投資家の関わり方を見るうえでの材料になります。

[出典: TFTC](https://www.tftc.io/jpmorgan-ibit-linked-structured-notes-sec-424b2-cadence)

### 🇺🇸 TD Cowen「民主党議会ならCLARITY法案2年停滞」

TD Cowen の Jaret Seiberg 氏は、民主党が議会選で圧勝した場合、CLARITY 法案は2年にわたって葬られるとの見方を示しました。Elizabeth Warren 氏が銀行委員会を率いることになり、民主党が Trump 大統領の指名する SEC と CFTC の人事を阻めるようになるとも指摘しています。米国は中間選挙の投票日を迎えたばかりで、金融市場のトレーダーはすでに選挙結果を資産価格に織り込み始めています。選挙の結果次第で法案の行方だけでなく規制当局の人事まで左右されるため、業界の政策面の前提が変わりうる点で重要な見立てです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/td-cowen-democratic-congress-clarity-act)

### 🇺🇸 CFTC、個別株の無期限先物を登録取引所で解禁

CFTC の Michael Selig 委員長は、個別株を対象とする「株式無期限先物」を CFTC 登録の取引所で取引できるようになったと明らかにしました。Bitcoin Magazine によると、個別株の無期限先物が米国の二重登録取引所で認められるのは今回が初めてです。無期限先物は暗号資産の世界で生まれた商品で、Decrypt はこの決定を、その仕組みを伝統的な株式へ広げるものと伝えています。暗号資産発の取引手法が、規制当局の判断によって米国の株式市場へ持ち込まれた形になり、両市場の垣根を考えるうえで重要な動きです。

[出典: Decrypt](https://decrypt.co/382464/cftc-traders-bet-stocks-with-crypto-style-perpetual-futures)

### 🏢 Tether保有BTCは15万枚、準備金報告より5万枚多く

Tether の Paolo Ardoino 最高経営責任者は Lugano で、同社が約15万 BTC を保有していると述べました。金額にすると約115億ドルです。この数量は同社の準備金報告が示す水準より5万 BTC 多く、発言どおりなら報告に表れていない保有が約3分の1にのぼる計算になります。差が生じた理由は、ここでは確認できていません。Tether はビットコインの大口保有者の一角であり、経営トップの発言と公表資料のあいだにこれだけの開きがあることは、保有実態と開示のあり方の両面で注目される材料です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/tether-holds-150000-bitcoin-ceo-says)

### 🚨 Binance流出63.4億ドル、発端は偽の採用面接

Binance は事故報告書で、10月29日に起きた63.4億ドルの盗難が、偽の採用面接と汚染された開発者向けツールから始まった5か月がかりの攻撃だったと明らかにしました。Chainalysis は、この偽採用の手口は北朝鮮のハッカーが Binance 以前に数十件の攻撃で磨き上げたものだと分析しています。Arbitrum の Security Council は10月30日に緊急措置を取り、犯人側の 8,425 ETH と 7,450万 ARB、計約3,000万ドルを凍結しました。被害額の大きさに加え、入り口が採用活動を装った個人への接触だった点が、業界全体の警戒材料になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/binance-says-6-34-billion-hack-job)

### 🚨 Mercado Bitcoin、ハッキング被害の返金を表明

ブラジル最大の暗号資産取引所 Mercado Bitcoin がハッキングを受け、同社は顧客に負担をかけず返金すると表明しました。ただし出金は止まったままで、再開の日程は示されていません。被害額は Decrypt が約4,000万ドル、Chainalysis が約4,900万ドルと伝えており、数字には開きがあります。Chainalysis は、盗まれた資金のうち1,000万ドル近くの凍結を主導したと説明しています。返金の表明で利用者の損失への懸念は和らぐものの、資金をいつ引き出せるかは見えていません。Binance の巨額流出に続く取引所の被害として、再開時期が次の焦点になります。

[出典: Decrypt](https://decrypt.co/382459/brazil-mercado-bitcoin-will-refund-users-40-million-hack)

### ⚡ Dorier氏、AI時代のBTCPayの存在意義を問う

Dorier 氏が自身のブログに「BTCPay Server にまだ存在意義はあるのか」と題する文章を公開し、Stacker News で共有されました。知能がふんだんに手に入る世界では、利用者は開発者の助けがなくても、AI に任せて欲しいものを何でも作れる。それなら自分たちはなぜ役に立つのか、という問いを立てています。ビットコインの世界で広く知られる開発プロジェクトの側から、自らの役割を問い直す発言である点が目を引きます。AI によるソフトウェア作りが広がるなかで、オープンソースの開発者が何を担い続けるのかを考える材料になります。

[出典: blog.nicolas-dorier.com](https://blog.nicolas-dorier.com/posts/does-btcpay-server-still-serve-a-purpose/)
