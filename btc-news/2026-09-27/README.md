# 【2026/09/27】きのうのビットコイン

## きのうのニュース

### 📈 Katie Stockton氏「9.3万ドル突破で強気相場確定」

Fairlead Strategies の Katie Stockton 氏が Bitcoin Magazine の動画に出演し、ビットコインのテクニカルな見立てを語りました。同氏は 8万4,000ドルを当面の上値抵抗とみており、9万3,000ドルを上抜ければ新たな強気相場入りが正式に確認できるとしています。ここ数日の価格はまさに抵抗帯とされる水準の近くにあります。著名なテクニカル分析家が強気相場の「確定ライン」を具体的な価格で示したため、今後の値動きを見るうえで市場参加者が意識する節目になりそうです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/videos/katie-stockton-93k-btc-is-the-key-price-level-for-the-bull-market)

### 📈 Grant Cardone氏、不動産「崩壊」にビットコインで備え

不動産投資家の Grant Cardone 氏が Bitcoin Magazine で、商業不動産に「アルマゲドン（破局）」が来ていると語りました。同氏によれば、商業不動産で起きた大きな変化は、ビットコインを積極的に買い増して富を蓄える絶好の機会を生んでいます。そのうえでビットコインを不動産市場の混乱に対するヘッジと位置づけました。伝統的な実物資産の代表格である不動産で財を成した人物が、その不動産の先行きを悲観し、代わりの保存先としてビットコインを挙げた発言です。資産家層の資金の向かう先を占う材料になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/grant-cardone-real-estate-armageddon-is-here-why-bitcoin-is-the-hedge)

### 🏛️ 戦略的ビットコイン準備法案ARMA、下院委を28対21で通過

米下院金融サービス委員会は9月16日、戦略的ビットコイン準備を定める法案 ARMA（H.R. 8957）を賛成28・反対21で可決しました。戦略的ビットコイン準備の法案が下院の本委員会を通過したのはこれが初めてです。法案は、没収によって政府が保有するビットコインを20年間売却できないようにし、暗号技術を使った準備証明を四半期ごとに行うことを義務づけます。一方、新たなビットコインの取得は認めていません。行政命令にとどまっていた準備の枠組みを、法律に格上げする道筋がついたことになります。

[出典: TFTC](https://www.tftc.io/arma-hr-8957-strategic-bitcoin-reserve-committee-vote-28-21)

### 🇺🇸 SECのPeirce委員が10月2日退任、委員2人体制へ

米証券取引委員会（SEC）の Hester Peirce 委員が9月25日、10月2日付で退任すると発表しました。後任は指名されておらず、SEC は委員2人だけの体制になります。Peirce 氏は暗号資産に理解のある委員として知られ、ビットコイン関連の基盤に対する執行で異論を唱えてきた存在でした。同氏が去ることで、その種の反対意見を出す委員が一人もいなくなります。今後の SEC の執行方針や規則づくりで、業界寄りの歯止めが失われるかどうかが焦点になります。

[出典: TFTC](https://www.tftc.io/hester-peirce-sec-resignation-october-2026)

### 🇺🇸 Samourai開発者Rodriguez氏、「人生最悪の30日」を手記に

プライバシー重視のビットコインウォレット Samourai Wallet の開発者 Keonne Rodriguez 氏が、連載「Samourai Letter」の第7回を公開しました。The Rage から転載された今回の手記「Notes From The Inside」で、同氏は自身の経験を「人生で最悪の30日間」と記しています。Samourai Wallet の開発者は米当局に訴追されており、プライバシー技術の開発者が法的責任を問われた象徴的な事例として注目されてきました。当事者自身が内側から状況を綴った記録として、開発者保護をめぐる議論の材料になります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/culture/samourai-letter-7-notes-from-the-inside)

### ⚡ 自己ホスト型Arkウォレット「Shhark」、Tor専用で公開

自分のサーバーで動かす Ark ウォレット「Shhark」が GitLab で公開されました。bark-web から分岐し、Bark を基盤にしています。バックエンドの通信はすべて Tor を経由し、DNS と IPv6 は安全側で遮断する設計です。ほかに HTTPS、パスワードと TOTP による多要素認証、暗号化バックアップ、P2P の Payjoin、耐量子暗号を組み合わせたメッセージ機能、機能を足せるウォレットアプリ群を備えます。Ark はビットコインの第2層の一つで、プライバシーと自己管理を重視した実装が増えている流れを示しています。

[出典: gitlab.com](https://gitlab.com/PiHiker/shhark/-/tree/shhark-main)
