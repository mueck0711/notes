# 【2026/11/05】きのうのビットコイン

## きのうのニュース

### ⚠️ 民主党圧勝で踏み上げ、BTCは8万ドル近辺へ反発

ビットコイン価格は8万ドル近辺で推移しています。選挙当夜に付けた7万5600ドルの安値から反発した水準です。Bitcoin Magazine は、民主党が議会を制したことに続いて起きた動きとして、売り方の買い戻しが連鎖するショートスクイーズ、株式相場の上昇、原油価格の9%下落の3つを挙げています。重要なのは、選挙結果が暗号資産だけでなく株式と原油にも同時に波及し、その流れの中でビットコインの反発が語られている点です。安値からの戻りは約4400ドルにのぼり、政治日程が相場の大きな材料になった局面といえます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-holds-near-80000-short)

### 🇺🇸 下院民主党、SEC権限拡大の独自市場構造法案を検討

選挙で議会を制した下院民主党が、暗号資産の市場構造について独自の法案を協議しています。土台となるのは、Maxine Waters 議員が提出して退けられた Clarity Act への修正案です。内容は SEC の役割を広げ、CFTC の役割を縮小し、新たな倫理面の制限を設けるものと伝えられています。重要なのは、これまで議論されてきた Clarity Act とは別の枠組みが、新たな多数派の側から出てきた点です。どの当局が暗号資産を監督するのかという市場構造法案の根幹が、選挙結果を受けて改めて争点になる可能性を示しています。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/house-democrats-crypto-market-structure)

### 🏛️ セイラー氏、中間選挙は超党派のBTC準備金信任と主張

Michael Saylor 氏が2026年の中間選挙の結果を取り上げ、ビットコイン準備金の政策が党派の壁を越えた証拠だとの見方を示しました。TFTC が伝えたものです。民主党が議会を制した選挙の直後に、準備金政策は党派を問わず支持されたと読む主張であり、政権や議会の構成が変わっても政策が続くのかという論点に直接関わります。ただし、これはあくまで同氏の解釈です。TFTC は、この読みが正しいかどうかは2027年に続く立法によって確かめられるか、あるいは崩れるかが決まるとしており、判断は今後の法案の動きに委ねられています。

[出典: TFTC](https://www.tftc.io/bitcoin-reserve-bipartisan-saylor-florida-texas-midterms-2026)

### 🏢 Strategy、54億ドル調達もBTC購入は5.88億ドル

Protos によると、Strategy は前四半期に54億ドルの新株を売却しましたが、そのうちビットコインの購入に充てたのは5億8800万ドルにとどまりました。出典は同社自身の四半期報告書である10-Qです。調達額に占める購入額の割合は約1割にすぎません。株式を発行してビットコインを買い増すという同社の事業モデルで知られる企業だけに、調達した資金の大半が購入に回っていないという事実は注目に値します。Protos はこの点を見出しで「ほとんど買っていない」と表現しており、資金の使途が企業財務の面で問われる材料となっています。

[出典: Protos](https://protos.com/strategy-raises-5-4b-but-barely-buys-bitcoin/)

### 🏢 Strive、週6182BTC追加で最大10億ドル調達を計画

Wu Blockchain によると、Strive は1週間で6182BTCを買い増し、6億3000万ドルの SATS 発行を完了したうえで、最大10億ドルの新たな発行計画を発表しました。一方で Strategy は同じ時期にビットコインを売買せず、約2億490万ドルを STRC の買い戻しに充てています。重要なのは、資金を調達してビットコインを買うという同じ手法を採る2社の間で、足元の行動に明確な差が出ている点です。積極的に買い増す Strive と、購入を止めて自社証券の買い戻しに回る Strategy という対比は、企業財務の動向を見るうえで興味深い材料です。

[出典: Wu Blockchain](https://wublock.substack.com/p/why-is-strive-more-aggressive-than)

### 🚨 64億ドルのBinance流出、Coinbaseは影響なしと説明

Coinbase が顧客に対し、64億ドル規模の Binance のハッキングによる影響は受けていないと伝え、自社の安全対策を詳しく説明しました。Decrypt によると、説明の内容は、顧客資産の99%超をオフラインで保管していること、秘密鍵を分割していること、緊急停止の仕組みを備えていることなどです。重要なのは、業界大手で起きた巨額の被害を受けて、他の取引所も自社の資産管理を顧客に説明する必要に迫られている点です。取引所に資産を預ける際に何を確かめるべきかという問いを、利用者に改めて突きつける出来事となっています。

[出典: Decrypt](https://decrypt.co/382570/coinbase-99-percent-customer-crypto-offline-binance-hack)

### ⚡ Linux重大欠陥にCorallo氏が警鐘、LNDは緩和策

Bitcoin Core と Lightning の開発者である Matt Corallo 氏が10月30日、Linux カーネルの深刻な脆弱性 CVE-2026-98432 に注意を促しました。IPv4 の TCP ハンドシェイク処理に含まれる解放後使用の欠陥で、深刻度を示す CVSS の値は9.8と評価されています。これを受けて Lightning Labs は、LND に緩和策を組み込んで公開しました。重要なのは、ビットコインの開発者がプロトコルの外にある基盤ソフトの欠陥にも目を配り、Lightning の実装側が対応に動いている点です。ノードを運用する人にとって、OS の問題も自分の問題になることを示す事例です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/matt-corallo-flags-critical-linux-kernel-flaw-lightning-labs-ships-lnd-mitigation)

### ⚡ 次のソフトフォークは予行演習、Corallo氏が語る4件修正

Matt Corallo 氏が Decrypt の記事で、ビットコインの次のソフトフォークが持つ意味を語りました。このソフトフォークは古くから残る4件の不具合を修正するものですが、同氏はその意義をビットコインの保守だけに置いていません。ソフトフォークを実行するための「筋肉の記憶」を取り戻すことも同じくらい重要だと説明しています。記事はこれを予行演習のようなものになり得ると表現しました。重要なのは、変更の中身と同じ重みで、合意形成から実施までの手順を開発者や利用者が再び経験することに価値が置かれている点です。今後のプロトコル変更の進め方を考えるうえで参考になる見方です。

[出典: Decrypt](https://decrypt.co/382568/why-bitcoin-next-soft-fork-could-feel-like-practice-run)
