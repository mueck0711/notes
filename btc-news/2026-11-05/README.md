### 🇺🇸 下院民主党、独自の市場構造法案を検討 SECの役割を拡大

議会選での民主党の勝利を受け、下院民主党が暗号資産の市場構造について独自の法案を協議しています。土台となるのは、Maxine Waters 議員が提出して退けられた Clarity 法案への修正案です。SEC の役割を大きくして CFTC の役割を小さくする内容で、新たな倫理面の制限も盛り込まれます。退けられた修正案を出発点にする以上、これまでの法案とは監督当局の配分が異なる枠組みを目指す動きといえます。議会の主導権が移ることで、停滞している市場構造の議論が SEC 重視の方向へ傾く可能性を示しており、暗号資産業界にとっては監督の担い手そのものが問われる局面です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/house-democrats-crypto-market-structure)

Michael Saylor 氏が2026年の中間選挙の結果について、ビットコイン準備金政策が党派の壁を越えた証拠だと指摘しました。TFTC が伝えたもので、記事はこの見方を「超党派の信任」という主張として紹介しています。民主党が議会を制し、暗号資産業界には逆風との見方が出ているなかで、準備金については党派を問わず支持があるとする点が注目されます。ただし、これは現時点では発言にとどまり、立法の成果ではありません。TFTC は、2027年に続く立法によってこの読みが裏づけられるか、崩れるかが決まると位置づけており、来年の議会の動きが検証の場になります。

### 🚨 仏Arkéa銀がサイバー攻撃認める、1.33億ドル暗号資産窃取か

フランスの銀行 Crédit Mutuel Arkéa がサイバー攻撃を受けたことを認めました。ZachXBT 氏が同行を1億3,300万ドルの暗号資産窃取の被害者として名指ししたことを受けた形です。銀行は、委託先を経由した攻撃によって自行の口座から不正な送金が行われたと説明していますが、声明で暗号資産には触れておらず、金額もまだ精査中としています。ZachXBT 氏は被害額を1億3,300万ドル超とみていますが、銀行はこの数字を認めていません。銀行本体の口座が委託先経由で狙われた事件であり、TFTC も自己保管を見直す材料の一つとして取り上げています。

### 🚨 Coinbase、顧客資産99%超はオフラインと説明 Binance流出受け

Coinbase が顧客に対し、64億ドル規模とされる Binance のハッキングによる影響は受けていないと伝えました。あわせて自社の安全対策を説明しており、顧客の暗号資産の99%超をオフラインで保管していること、秘密鍵を分割して管理していること、緊急停止の仕組みを備えていることを挙げています。大手取引所で巨額の流出が報じられた直後に、競合する取引所が顧客へ直接説明に動いた形です。取引所に資産を預ける利用者にとって、預け先がどのように資産を守っているのかが改めて問われています。各社の保管体制への関心が高まるなかで、Coinbase が自社の管理方法を具体的に示した発表です。

[出典: Decrypt](https://decrypt.co/382570/coinbase-99-percent-customer-crypto-offline-binance-hack)

### ⚡ Linuxカーネルに重大欠陥、Lightning LabsがLNDで緩和策

Bitcoin Core と Lightning の開発者である Matt Corallo 氏が10月30日、Linux カーネルの深刻な脆弱性 CVE-2026-98432 に注意を促しました。IPv4 の TCP ハンドシェイク処理にある解放後メモリ使用の欠陥で、深刻度を示す CVSS は9.8と評価されています。これを受けて Lightning Labs は LND に緩和策を組み込んで公開しました。ビットコインのプロトコル自体の問題ではありませんが、接続の確立という通信の入り口の処理に関わる欠陥であり、ネットワークに接続して動くノードの運用者にとって無視できません。LND の利用者は、緩和策を含む版への更新とカーネル側の対応を確認する必要があります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/matt-corallo-flags-critical-linux-kernel-flaw-lightning-labs-ships-lnd-mitigation)
