# 【2026/09/22】きのうのビットコイン

## きのうのニュース

### 🏦 ETF保有者、1月以来の含み益に 8.7万ドル迫る

ビットコインの価格が87,000ドルに迫るなか、現物ETFの保有者が今年1月以来はじめて含み益の状態に戻ったとBitcoin Magazineが伝えました。ETF経由でビットコインを持つ投資家は、年初からの下落局面で長く含み損を抱えていたことになります。ETF保有者の損益はウォール街経由の資金の動きを左右しやすく、含み益への転換は追加流入を呼ぶ一方、利益確定売りの起点にもなり得ます。含み損の期間が終わったことで心理面の重しも一つ外れました。今回の急伸が一時的なものか、機関投資家の資金が戻る転換点になるのかを見極めるうえで、ETFの資金フローが当面の注目点です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/bitcoin-etf-holders-back-in-profit)

### ⚠️ FRB数年ぶり利上げでもビットコイン底堅く

先週のFOMCで、FRBは数年ぶりとなる利上げに踏み切りました。インフレは依然として高止まりし、米国債利回りは高水準にあり、当局者はさらなる引き締めの余地も残しています。Ecoinometricsは、ビットコインが苦戦してもおかしくない材料が揃っているにもかかわらず、相場が持ちこたえている点に注目しています。金利上昇はリスク資産に逆風になりやすいのが通例で、本来なら売られやすい局面です。それでも崩れていないのであれば、買い手の顔ぶれや資金の性質が変わってきた可能性があります。今後の追加利上げ観測と価格の関係を注意深く見る必要がある局面です。

[出典: Ecoinometrics](https://ecoinometrics.substack.com/p/bitcoin-is-holding-up-despite-higher)

### 🇺🇸 Clarity Act頓挫も相場は無視、8.6万ドル突破

米国の暗号資産市場構造法案「Clarity Act」が議会で躓き、重要な暗号資産関連法制が後退したにもかかわらず、ビットコイン価格は86,000ドルを突破して急伸しました。Bitcoin Magazineは、法案の失速という悪材料を相場が意に介していない点を報じています。市場構造法案は米国での暗号資産の規制上の位置づけを定めるものとして業界が待ち望んできたもので、成立の遅れは本来なら相場の重しになる材料です。それでも価格が上昇したことは、足元の買いが政策期待とは別の要因で動いていることを示しており、規制の行方と相場の連動が弱まっている点が目を引きます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-blasts-past-86000)

### 🏛️ ロシア中銀、暗号資産業界は年内に合法化の見通し

ロシア中央銀行は、国内の暗号資産業界が年末までに合法的な枠組みの下で営業できるようになる可能性があるとの見通しを示しました。ロシアは今年に入って暗号資産の規制整備を進めており、Bitcoin Magazineはその流れの延長として今回の発言を伝えています。中央銀行が合法化の時期に具体的に言及したことは、制度面での大きな節目です。暗号資産の取り扱いが国として公式に認められれば、事業者は法的な不確実性を抱えずに営業でき、採掘や決済での利用が広がる可能性があります。各国の政策動向のなかでも、規制の空白が埋まる方向へ動いている事例として注目すべき動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/russia-crypto-industry-could-be-operating)

### 🏢 Strategy保有845,050BTC、発行上限の4%超

Strategyが米SECに提出した8-Kで、2026年8月30日時点の保有量が845,050BTCに達したことが確認されました。ビットコインの発行上限2,100万枚の4%を超える規模で、購入資金は株式発行による6億280万ドルの調達で賄われています。株価MSTRは1営業日で約16%急騰し、Alliance Global、B. Riley、Canaccord、Barclaysのアナリストがそろって目標株価を引き上げました。一企業が供給の4%超を握る状況は前例がなく、同社の買い増しペースと株価の反応は、ビットコイン市場全体の需給と企業財務による需要の持続性を語るうえで欠かせない材料です。

[出典: TFTC](https://www.tftc.io/strategy-845050-btc-four-percent-hard-cap-mstr-surge)

### 🚨 スペインで暗号資産強奪狙い監禁、2人逮捕

スペイン・アリカンテで、男性を人質にとって暗号資産を奪おうとしたとして2人が逮捕されました。スペイン治安警備隊（Guardia Civil）が捜査しており、容疑者のカップルはバルセロナとギプスコアで身柄を拘束され、強盗未遂・暴行・脅迫の疑いが持たれています。暗号資産は鍵を握る本人に直接迫れば奪えるため、物理的な脅迫による強奪は世界各地で報告が続いています。取引所のハッキングとは異なり、自己保管をしている個人が標的になる点が特徴です。自己保管を選ぶ保有者にとって、資産の分散や保有を周囲に知られないことの重要性を改めて示す事件です。

[出典: criptonoticias.com](https://www.criptonoticias.com/sucesos/espana-dos-detenidos-robo-criptomonedas-alicante/)

### ⚡ CashuウォレットNumo v1.9、UI刷新とミント探索

Cashu対応のEcashウォレット「Numo」のv1.9がGitHubで公開されました。今回の更新では画面全体のデザインが刷新され、Material 3のスタイルと統一されたアイコンが採用されています。あわせて、ミント（Cashuトークンを発行する事業者）を見つけやすくする機能と、Cashuトークンを送受信する手段の改善が盛り込まれました。CashuはビットコインのLightningを裏付けにしたEcashの仕組みで、少額決済やプライバシーの面で注目されています。ウォレットの使い勝手が上がることは、Ecashを日常的に使う人を増やすうえで地味ながら重要な前進です。

[出典: github.com](https://github.com/cashubtc/Numo/releases/tag/v1.9)

### ⚡ Deribit新マッチングエンジン、マイクロ秒台へ

Coinbase傘下のDeribitが、取引所の中核である新しいマッチングエンジンを稼働させました。大量の注文を処理しつつ、レイテンシをミリ秒からマイクロ秒の水準へ引き下げ、しかもばらつきを抑えて予測しやすくすることを狙った刷新です。Deribit Insightsは、切り替え前後それぞれ6日間の実測を比較し、効果が有意に表れたとしています。Deribitはビットコインのオプション・先物で大きな存在感を持つ取引所で、約定の速さと安定性は裁定取引やマーケットメイカーの行動に直結します。派生商品市場の厚みが増せば、現物価格の値動きにも影響が及ぶことになります。

[出典: Deribit Insights](https://insights.deribit.com/exchange-updates/deribits-new-matching-engine-from-milliseconds-to-microseconds/)
