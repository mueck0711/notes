# 【2026/10/09】きのうのビットコイン

## きのうのニュース

### ⚠️ 原油高とFRBのタカ派姿勢、ビットコイン続落

ビットコイン価格は今週に入ってからも下落が続いています。Bitcoin Magazine によると、背景にあるのは原油価格の急騰と、米連邦準備制度理事会（FRB）が利上げへ傾きつつあるという懸念です。インフレ圧力が再び強まれば金融引き締めが長引き、リスク資産から資金が抜けやすくなります。ビットコインが株式と同じように、金利の見通しというマクロの材料に振らされる局面が続いていることを示す動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-slide-continues-below-81000)

### 🏦 米現物ビットコインETF、6月以来最大の資金流出

Decrypt によると、米国の現物ビットコインETFから1日で6月以来最大の資金が引き揚げられました。10月は例年上がりやすいとして「Uptober」と呼ばれますが、今年は月初から逆風です。記事は、原油が1バレル100ドル近くまで上がり、債券利回りが2002年以来の高水準にあること、FRBの利上げがまだ終わっていないことを背景に挙げています。ETFは機関投資家や資産運用会社の需要を映す窓口で、マクロ環境の悪化がその資金の流れに表れた形です。

[出典: Decrypt](https://decrypt.co/380490/bitcoin-etfs-worst-outflow-since-june-uptober-red)

### 🏦 スタンダードチャータード、シンガポールで暗号資産保管へ

英銀大手のスタンダードチャータードが、シンガポールでデジタル資産のカストディ（保管）業務を提供する計画だと Bitcoin Magazine が報じました。同行はすでに他の国でビットコインの保管業務を提供しており、今回の計画はその地域をシンガポールへ広げるものです。暗号資産の専業会社ではなく伝統的な大手銀行が自ら保管を担うことで、機関投資家がビットコインを持つときの選択肢が増えます。既存の銀行が保管業務を広げる流れがアジアでも続いていることを示しています。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/standard-chartered-singapore-custody-plans)

### 🇪🇺 ギリシャ、暗号資産の譲渡益に15%課税を計画

ギリシャが、暗号資産投資家の譲渡益に15%の税率で課税する法律を計画していると報じられました。Reuters と現地メディアによると、同国の財務省はこの案を盛り込んだ法案をすでに起草しています。ギリシャには現在、暗号資産の利益に課税する法的な枠組みがないとされます。法案が成立すれば、投資家には新たな税負担が生じる一方で、これまで曖昧だった扱いがはっきりします。欧州の一国が暗号資産の課税ルールを明文化する動きとして注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/greece-plans-crypto-capital-gains)

### 🏛️ 米政府系ウォレット、押収BTC約10億ドル分を移動

米政府に関連するウォレットが10月8日、12,267 BTC（約10.1億ドル）をラベルのないアドレスへ移しました。TFTC によると、これで3日間の移動は合計約17,795 BTC（約15億ドル）に達します。売却されたかどうかは確認されておらず、司法省（DOJ）も連邦保安官局（US Marshals）も説明をしていません。政府が持つ押収分が市場で売られれば需給に影響しうるため、移動先と目的に関心が集まっています。

[出典: TFTC](https://www.tftc.io/us-government-bitcoin-bitfinex-seized-funds-transfer-october-2026)

### 🐋 2010年採掘の100BTC、16年ぶりに移動

2010年7月に採掘された100.02 BTCが水曜日、16年ぶりに動きました。Decrypt によると、評価額は約830万ドルです。ただし、取引の中身からは誰が持ち主なのかは分かりません。サトシ・ナカモトがまだ活動していた初期のコインが動くたびに、初期のマイナーが関わっているのか、売却が近いのかといった点に関心が集まります。量は大きくなくても、持ち主が分からないこと自体が話題になるのは、ビットコインならではの出来事です。

[出典: Decrypt](https://decrypt.co/380514/satoshi-era-bitcoin-mined-2010-moves-16-years)

### ⚡ AIエージェント経由、Breez SDKの問い合わせ14倍

ビットコインのソフトウェア企業 Breez によると、開発者向けSDKへの提携の問い合わせが、AIのコーディングエージェントが普及してから約14倍に増えました。そのうち、エージェント自身から届く問い合わせの割合も増えているといいます。TFTC は、AIエージェントが許可を必要としない決済基盤としてビットコインを選んでいると伝えています。人による審査や口座開設を前提にしない送金手段は、自動で動くソフトウェアにとって使いやすく、ビットコインの新しい利用者層として注目されます。

[出典: TFTC](https://www.tftc.io/ai-agents-bitcoin-integration-breez-sdk-14x-surge)

### ⚡ 「AIが数カ月で暗号を破る」説に暗号学者が異論

Ethereum Foundation の研究者 Justin Drake が、ビットコインを守る楕円曲線暗号をAIが「数カ月以内」に破りうると予測し、「バンカーモード」への移行を呼びかけました。TFTC の記事は、筆者が信頼する暗号学者たちはその時間軸に異論を唱えていると紹介しています。そのうえで、アドレスを使い回さなければ危険にさらされる範囲を減らせること、別の署名方式への取り組みもすでに進んでいることを挙げ、慌てずに備えるよう促しています。量子計算に加えてAIも暗号の脅威として語られ始めた点が新しい論点です。

[出典: TFTC](https://www.tftc.io/ecdsa-ai-bunker-mode-bitcoin-address-reuse)
