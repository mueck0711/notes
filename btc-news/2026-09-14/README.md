# 【2026/09/14】きのうのビットコイン

## きのうのニュース

### ⚠️ 9月16日FOMC、PCE改定はその14日後

TFTC は、FOMC が9月16日に金利を決める一方で、米経済分析局（BEA）がその14日後の9月30日に、FRB 自身がインフレ目標に用いる PCE 物価指数を2021年まで遡って改定すると指摘しました。クリストファー・ウォラー理事は、この改定によって直近12か月のコア指数が下方修正される見込みだと既に発言しています。記事は、改定後の数字を見てから動く「1会合待つ」側の根拠のほうが強いと論じています。政策判断の土台となる物価統計が後から書き換わる構図で、ビットコインを含むリスク資産の値動きを左右する論点です。

[出典: TFTC](https://www.tftc.io/fed-hike-september-16-pce-revision-september-30-bea)

### 🇺🇸 米上院、CLARITY法案の手続き投票を15日に

米上院は、暗号資産の市場構造を定める CLARITY 法案について、審議入りの動議に対する討論終結（クローチャー）投票を9月15日に予定しています。休会明け翌日の日程で、ここを通れば本格審議と最終採決へ進みます。下院は2025年7月17日に H.R.3633 を294対134で可決済みですが、上院では倫理規定や法執行、DeFi の扱い、ステーブルコインの報酬をめぐる対立が残り、11月の中間選挙前の成立は不透明です。銀行側は高利回りの報酬が預金流出を招くと警告しています。規制の枠組みが決まる節目の一週間です。

[出典: cnbc.com](https://www.cnbc.com/2026/09/01/crypto-enters-september-with-policy-gamble-hanging-by-a-thread.html)

### ⛏️ ERCOT接続枠、GW競争の得点表と化す

テキサス州の系統運用者 ERCOT が示す「Batch Zero」の分類に、Galaxy、IREN、CleanSpark、Ionic といった各社の案件が相次いで並び、本来は送電網の検討段階を示す区分が、事実上のギガワット競争の得点表になっていると TFTC が報じました。Galaxy の 4.2 ギガワットのように総量ばかりが注目されますが、記事は Base Load と Studied Load では確度がまったく違う点を見落とすなと指摘しています。マイニングとデータセンターの電力確保競争を読むうえで、数字の中身を分けて見る必要があります。

[出典: TFTC](https://www.tftc.io/ercot-batch-zero-galaxy-ai-power-arms-race)

### 🚨 Revolut、偽の政府照会でKYC情報流出

英フィンテックの Revolut は、政府機関を装った偽のドメインからの照会に応じてしまい、顧客の本人確認（KYC）情報とビットコインの取引データが流出したと認めました。同社は影響を受けた顧客へ通知し、該当する政府機関と法執行機関、金融規制当局にも報告したとしています。オンチェーン調査者の ZachXBT は、この事案が富裕層の利用者を狙ったものである可能性を指摘しました。取引所や金融機関に預けた本人確認情報と取引履歴が結びつくと、物理的な脅迫を含む実害につながりうる類型の事故です。

[出典: The Block](https://www.theblock.co/news/business/2026-09-12-revolut-says-customer-kyc-bitcoin-transaction-data-exposed-after-fake-request-from-govt-domain-414516)

### ⚡ Electrum、v4.8.2で再びセキュリティ更新

老舗のビットコインウォレット Electrum が、v4.8.2 をセキュリティ更新として公開しました。Electrum は2011年から継続して開発されている代表的なウォレットのひとつで、Windows、macOS、Linux、Android に対応しています。Stacker News では「またハッキングか詐欺絡みではないか」という受け止めが投稿されていますが、どのような問題への対応なのかは今回の告知からは読み取れません。利用者としては、公式サイトの署名を確認したうえで更新を当てるのが基本の対応になります。

[出典: electrum.org](https://electrum.org/#download)

### ⚡ BIP-110分岐の刻印ファイル閲覧ツール登場

bitfiles という名前のファイルブラウザが公開されました。スパム耐性をうたう BIP-110／BLAKE2b 系のビットコイン分岐チェーン上で、BLAKE2b のトランザクションに書き込まれたファイルを、bpub を経由して閲覧できるというものです。ブロックスペースに任意のデータを載せる是非は本家のビットコインでも続いている論争で、それを前提に設計されたとする分岐チェーン側で、書き込まれた中身を実際に見るための道具が出てきた形になります。分岐そのものの支持や利用の広がりは、この告知からは分かりません。

[出典: bitfiles.io](https://bitfiles.io/btcb2)
