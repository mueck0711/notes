# 【2026/11/18】きのうのビットコイン

## きのうのニュース

### 🏦 Wells Fargo、IBIT保有を倍増し23.5億ドルに

Wells Fargoが11月17日にSECへ提出した第3四半期の13F（機関投資家の保有報告書）によると、9月30日時点でBlackRockのビットコイン現物ETF「IBIT」を4,958万株保有しており、評価額は23億5,000万ドルでした。前の四半期から保有を2倍超に増やしています。この規模は、TeslaやSpaceXが持つビットコインの額に近づく水準だと報じられています。米大手銀行がビットコインETFを大きく積み増したことが四半期ごとの開示で確認できた形で、伝統的な金融機関にビットコインへの投資がどこまで広がっているかを測る材料になります。

[出典: TFTC](https://www.tftc.io/ibit-wells-fargo-q3-13f-bitcoin-etf-holdings)

### 🏦 Cantor、Strategy株を約3倍の4億ドルに買い増し

Cantor Fitzgeraldは2026年第3四半期にStrategy株を1,730,688株買い増し、保有を約195%増の4億89万ドルに拡大しました。同じ期間にNvidia、AMD、Broadcom、Marvellの保有は44〜74%減らしています。一方で、Strategy株のプット・オプション（売る権利）も5倍に増やしており、11月16日提出の13Fは見出しほど単純な強気一辺倒ではないと指摘されています。ビットコインを大量に保有する企業の株を、大手金融機関が現物とヘッジの両面でどう扱っているかがうかがえる開示です。

[出典: TFTC](https://www.tftc.io/cantor-fitzgerald-strategy-stake-triples-q3-2026-13f)

### 🇺🇸 Cato研究所、米CBDC計画巡る訴訟で敗訴

米シンクタンクのCato Instituteが、米国の中央銀行デジタル通貨（CBDC）計画を巡って起こしていた訴訟で敗訴しました。同研究所のNick Anthony氏は「政権が代わったことで請求が認められる可能性が高まると期待していたが、間違っていた」と書いています。政権交代後もCBDCに関する情報を求める動きが司法の場で退けられた形です。CBDCはビットコイン支持者の間で監視や統制の道具になりうるとして警戒されてきたテーマで、米国での扱いを示す一件として注目されます。

[出典: The Rage](https://www.therage.co/cato-institute-loses-lawsuit-over-us-cbdc-plans/)

### 🏛️ FRBウォラー理事、トークン化市場の決済基盤に名乗り

米連邦準備制度理事会（FRB）のChristopher Waller理事が、トークン化された経済において、FRBが欠かせない決済の基盤になるべきだとの立場を公の場で示しました。市場の仕組みが固まる前に、中央銀行が「信頼の層」を担うと主張した形です。実施の時期は示していないものの、狙いは明確だと報じられています。資産のトークン化が広がるなかで、決済を中央銀行が握るのか、ビットコインのような中立的な仕組みが担うのかという論点に関わる発言です。

[出典: TFTC](https://www.tftc.io/fed-waller-central-bank-rails-tokenized-markets-trust-layer)

### ⛏️ AIファンド、マイニング株をほぼ手放す

Leopold Aschenbrenner氏が率いるAIファンドのSituational Awarenessは、第3四半期にIRENの保有を約94%減らし、Core Scientific、Riot、Hiveからは完全に撤退しました。7月にCitadelへ売却した後に残ったマイニング株は3銘柄、計8,080万ドルです。AI向けのデータセンター需要を見込んでマイニング企業に投資していたAI系ファンドが持ち高を大きく縮めたことで、マイニング企業がAIへ事業を転換するという投資テーマへの評価が問われる動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/aschenbrenner-fund-dumps-bitcoin-miners)

### ⛏️ 難易度9.13%低下、主因はテキサスの電力価格

ビットコインのマイニング難易度が9.13%下がり、6月以来最大の引き下げとなりました。Hashrate Indexの分析によると、主な原因はビットコイン価格ではなく、西テキサスで夕方の電力価格が高騰したことでした。採算が合わなくなったマイナーが十分な台数の機械を止めたため難易度が下がり、電力価格が落ち着くとビットコインが下落していてもハッシュレートはすぐに戻ったとしています。マイナーの稼働が電力市場の価格に強く左右されることを示した事例です。

[出典: hashrateindex.com](https://hashrateindex.com/blog/texas-power-prices-not-bitcoin-drove-difficulty-drop/)

### 🚨 Trezor配送委託先で流出、2.7万件の注文情報

ハードウェアウォレット大手のTrezorは、配送を委託しているSkladonで情報流出があり、約2万7,000件の注文について氏名、住所、メールアドレス、電話番号、購入内容が漏れたと明らかにしました。すでに一部の顧客から詐欺電話を受けたとの報告が出ています。ウォレット本体が破られたわけではないものの、ビットコインを自分で保管している人の身元と住所が結び付くと、詐欺や物理的な脅迫の標的になりかねません。委託先経由で自己保管者が狙われる危険を示した事件です。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/trezor-skladon-partner-breach-27000-orders)

### 🚨 Binanceハッキング資金、2週間ぶりに移動

10月に起きた過去最大規模のBinance盗難事件に関連するウォレットが、2週間の沈黙を破って6,300万ドル相当のイーサを動かしました。その後、アナリストはより大きな送金の波を指摘し、ビットコインへの交換も報告されています。米国が資金の回収を進めているさなかの動きです。盗まれた資金がビットコインへ交換されると追跡や回収の難しさが増すため、資金の行方と回収の行方が引き続き注目されます。

[出典: Decrypt](https://decrypt.co/383446/binance-hack-wallets-move-ethereum-after-two-weeks)
