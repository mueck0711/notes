# 【2026/09/12】きのうのビットコイン

## きのうのニュース

### 📈 米インフレ上振れでもビットコイン反発、利上げ観測を無視

Bitcoin Magazine によると、米国のインフレ指標が予想を上回る強い数字だったにもかかわらず、ビットコイン価格は上昇しました。記事は、利上げがすぐ先にあってもおかしくない状況で価格が動じなかった点を指摘しています。通常、インフレの上振れは利上げ観測を通じてリスク資産の重しになりますが、今回はその反応が出ていません。同誌は今回の上昇を、金利引き上げの可能性を市場が織り込み始めるなかでの反発と位置づけています。ビットコインがマクロ面の逆風をどこまで吸収できるかを測る材料として、この動きは注目されます。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-spikes-on-hot-inflation-data)

### 🏦 ETF流出がビットコインの上抜けを試す、企業買いは失速

Ecoinometrics は、米ビットコイン ETF からの資金流出がビットコインのブレイクアウト（上抜け）を試していると指摘しました。あわせて、上場企業によるビットコイン購入が失速していること、高い実質利回りがビットコインと資金を奪い合っていることも論点に挙げています。ETF と企業財務という二つの買い手が同時に鈍る局面では、価格の上値を支える主体が細ります。実質利回りが高い水準にある間は、ビットコインへの資金配分が他の資産との競争にさらされるという見立てです。上抜けが本物かどうかは、この流出が止まるかにかかっているという整理です。

[出典: Ecoinometrics](https://ecoinometrics.substack.com/p/etf-outflows-are-testing-bitcoins)

### 🏦 伊2位UniCredit、暗号資産カストディを検討と報道

Bitcoin Magazine は報道を引用し、イタリア第2位の銀行 UniCredit が暗号資産のカストディ（保管）事業に取り組んでいると伝えました。欧州では他の銀行もデジタル資産関連のサービスを整えつつあり、UniCredit の動きはその流れに沿ったものです。大手銀行が保管業務を担うようになれば、機関投資家や富裕層がビットコインを含むデジタル資産を持つときの入口が増えます。伝統的な金融機関が相次いで参入する動きは、欧州における暗号資産の位置づけが投機対象から金融サービスの一部へ移りつつあることを示しています。記事は報道段階の情報として扱っています。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/unicredit-working-on-crypto-custody)

### 🇺🇸 CLARITY法修正案、上院採決前にDeFi登録条項

Crypto in America によると、上院共和党は8月の休会中の交渉を経て、暗号資産の市場構造を定める CLARITY 法の修正テキストを公表しました。修正では DeFi（分散型金融）と信用組合に関する条項が変更され、Wu Blockchain の伝えるところでは、十分に分散化されていない DeFi プロトコルは CFTC への登録が義務づけられます。ただし火曜日に予定される手続き上の採決は、倫理問題についてホワイトハウスが沈黙を続けており、通過が見通せない状況です。法案の行方は米国の暗号資産規制の枠組みを左右するため、採決の可否が当面の焦点になります。

[出典: Crypto in America](https://www.cryptoinamerica.com/p/new-clarity-act-text-lands-before)

### 🇪🇺 英貴族院、政府を破ってデジタル資産戦略法案を支持

Bitcoin Magazine によると、英国の貴族院（上院）は政府の反対を押し切り、デジタル資産戦略の策定を求める法案を支持しました。この法案が成立すれば、英財務省は暗号資産、ステーブルコイン、トークン化証券、デジタル金融インフラの規制に関する戦略について協議を行うことを義務づけられます。政府が議会で敗北した形で、英国の暗号資産政策をめぐる主導権が議会側から押し出される格好になりました。規制の方向性が法律で明文化されれば、英国で事業を行う暗号資産企業にとって先行きの予見性が高まります。英国が欧州の中でどのような位置を取るかを占う材料にもなります。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/house-of-lords-backs-uk-crypto-bill)

### 🚨 Liquid盗難でBlockstream、身代金拒み返還要求

Blockstream は、サイドチェーン Liquid Network からのビットコイン盗難について公開書簡を出し、盗まれた資金の返還に対して身代金は支払わないと表明しました。Bitcoin Magazine によれば、自称ホワイトハットのハッカーが Liquid を狙って4,000 BTC 超を持ち出し、一部を報奨として手元に残すことを求めています。Blockstream は、無断で資産を取得し返還を差し控えるのは責任ある開示ではなく犯罪であり、ホワイトハット活動ではなく窃盗だと断じました。ビットコインのレイヤー2を担うサイドチェーンで起きた大型事案として、業界の信頼に関わる問題です。

[出典: x.com](https://x.com/Blockstream/status/2098281867908690394)

### 🚨 2.45億ドルのビットコイン強奪、22歳の首謀者が有罪答弁

The Independent と Bitcoin Magazine によると、2億4,500万ドル相当のビットコインを盗んだ事件の首謀者である22歳の Malone Lam 被告が有罪を認めました。Bitcoin Magazine はこの事件を米国史上最大級のビットコイン強奪の一つと位置づけています。有罪答弁により裁判は量刑の段階へ進むことになり、暗号資産を狙った大型窃盗に対する米司法の対応が改めて示される形です。巨額のビットコインが盗まれる事件が続くなかで、捜査当局が首謀者の訴追と有罪答弁まで至った例として注目されます。被害額の大きさは、ビットコインの保管をめぐる安全対策の重要性を改めて浮き彫りにしています。

[出典: independent.co.uk](https://www.independent.co.uk/bulletin/news/malone-lam-cybercrime-bitcoin-guilty-b3048129.html)

### ⚡ hazync、無改変のCore合意コードでzk有効性証明

hazync は、Bitcoin Core の合意（コンセンサス）コードを改変せずにそのまま使い、ビットコインの有効性証明を生成する研究プロジェクトです。証明は RISC0 の zkVM（ゼロ知識仮想マシン）上で行われ、GitHub の bitcoin-ghost/hazync で公開されています。検証ロジックを独自に書き直すのではなく Core のコードをそのまま証明系に載せるため、Core の検証と同じ結果になることが期待できます。まだ研究段階と明記されていますが、ブロックの有効性をゼロ知識証明で示す取り組みは、軽量クライアントやサイドチェーンの検証を置き換える議論に材料を加えます。

[出典: github.com](https://github.com/bitcoin-ghost/hazync/tree/main)
