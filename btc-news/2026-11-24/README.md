# 【2026/11/24】きのうのビットコイン

## きのうのニュース

### ⚠️ エヌビディア急騰でBTC一時6.4万ドル、6.1万ドルへ失速

月曜、エヌビディアの取締役会が辞任から11日でジェンスン・フアン氏をCEOに復帰させ、同社株が約35%急騰しました。ナスダックや半導体株に加え、Coinbase、Strategy、マイニング企業の株も買われ、ビットコイン価格も一時6万4,000ドルを上回りました。しかし午後には上げ幅を失い、6万1,000ドル付近まで押し戻されています。株式と暗号資産関連株が大きな上昇を保ったのとは対照的で、ビットコイン本体は株高の勢いに追随しきれなかった形です。株式市場の材料にビットコインがどこまで連れ高するかを測る一日になりました。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/markets/bitcoin-price-fades-61000-huang)

### 🇪🇺 仏議員、暗号資産利用者の登録簿構想を提案

フランスの議員が、自己管理型（セルフカストディ）の暗号資産保有について報告義務を強める規則を提案しました。The Rageは、これを暗号資産の全利用者の登録簿づくりにつながる構想として報じています。提案者自身も、この措置が保有者を危険にさらしうることを認めています。それでも、フランスの「IT セキュリティへの大幅な投資不足」が措置を妨げる理由にはならないとしています。誰がどれだけ保有しているかを記した名簿は、漏洩すれば保有者自身を危険にさらしかねません。自己管理を選ぶ利用者にとって重い論点で、欧州の規制の行方を占う動きです。

[出典: The Rage](https://www.therage.co/france-proposes-to-build-registry-of-all-cryptocurrency-users/)

### 🏢 American Bitcoin、BTC担保で1.5億ドル融資枠

マイニング企業のAmerican Bitcoinは11月18日、FalconXから1億5,000万ドルのリボルビング型融資枠を確保しました。担保は、連邦認可のAnchorage Digital Bankに保管しているビットコインです。これにより、8,500 BTCを超える保有分を1サトシも売らずに法定通貨を調達できます。採掘したビットコインを売って運転資金に充めるのではなく、手元のビットコインを担保に借りる道を選んだ点が特徴です。同じ週に採掘分を全量売却したBitdeerとは対照的な資金繰りになっています。

[出典: TFTC](https://www.tftc.io/american-bitcoin-150m-falconx-bitcoin-backed-credit-facility)

### ⛏️ Bitdeer、先週の採掘281 BTCを全量売却し保有ゼロ

マイニング企業のBitdeerは、先週採掘した281.1 BTCをすべて売却しました。その結果、11月20日時点で自社保有のビットコインはゼロになっています。Bitcoin Magazineは、American Bitcoinが保有分を担保に借り入れる道を選んだのと対比してこの件を報じました。採掘したビットコインを保持するか売却するかは、各社の財務の余力を映します。相場が軟調な局面で採掘分をすぐに売る企業が増えれば、市場への売り圧力にもなります。業界の資金繰りを見るうえで注目される動きです。

[出典: Bitcoin Magazine](https://bitcoinmagazine.com/news/bitdeer-sells-281-bitcoin-holds-none)

### ⛏️ 11 TH/sのソロマイナー、ブロック発見で19万ドル

単独で採掘するマイナーがSolo CKPoolを通じてブロック977,057を発見し、3.13 BTC（約19万1,000ドル）を手にしました。Bitcoin Magazineによると、このマイナーの計算能力は約11.1 TH/sにすぎません。CKpoolの開発者は、この規模で発見できる確率を年に約1,650分の1と見積もっています。通常は産業規模のマイニング施設が占めるブロック報酬を、宝くじのような確率で個人が引き当てた形です。Decryptは見出しで「再び」と伝えており、ソロマイナーによる発見は今回が初めてではありません。

[出典: Decrypt](https://decrypt.co/383818/solo-bitcoin-miner-scores-again-191000-jackpot)

### 🚨 北朝鮮、Binance流出資金2.47億ドルをミキサーへ

64億ドル規模のBinanceハッキングから約1か月がたちました。北朝鮮は盗んだ資金のうち約2億4,700万ドルを、ビットコインのミキサーに通しています。Ellipticによると、このコインジョインによる混合のほぼすべてを1人の人物が取り仕切っています。その人物は「こうした資金を止めることを拒んでいる」とされます。The Rageの週次まとめでは、同じEllipticの集計として1億4,900万ドル分がコインジョインで混合されたと伝えていました。それから短期間で額が膨らんでおり、洗浄が加速している様子がうかがえます。

[出典: Decrypt](https://decrypt.co/383844/north-korea-247-million-binance-hack-bitcoin-mixers)

### 🚨 Bisq、Javaの深刻な脆弱性で即時更新を呼びかけ

ビットコインの個人間取引ソフトBisqがv2.1.16を公開し、利用者に早急な更新を呼びかけています。対象には、いま取引をしていない利用者も含まれます。今回のリリースでは、同梱するJava 21ランタイムを更新し、深刻な脆弱性「Java4Shell」（CVE-2026-114938）を修正しました。Bisqは利用者が自分の端末で動かすアプリケーションのため、修正が届くかどうかは各自が更新するかにかかっています。リリースノートが「取引していなくても」とわざわざ強調しているのはそのためで、手元に入れたまま古い版を放置している利用者ほど注意が必要です。

[出典: github.com](https://github.com/bisq-network/bisq2/releases/tag/v2.1.16)

### ⚡ Bitcoin Core v31.3公開、不具合修正と性能改善

Bitcoin Coreのバージョン31.3が公開され、bitcoincore.orgから入手できるようになりました。今回のリリースには、各種の不具合修正と性能改善、翻訳の更新が含まれます。不具合はGitHubのイシュートラッカーで報告するよう案内されています。同じ週にBrinkは、Michael Ford（fanquake）氏の在籍4年を祝う記事を公開しました。同氏はBitcoin Coreの保守、リリース、堅牢化を担ってきた開発者です。こうした定期的な保守リリースは、支援を受けて作業を続ける開発者によって支えられています。

[出典: Delving Bitcoin](https://delvingbitcoin.org/t/bitcoin-core-v31-3-released/3110)
